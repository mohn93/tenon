# M14g Styles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SketchUp-like styles: edge settings (profile edges drawn thicker on silhouettes, sketchy edges with jitter and extensions, endpoints, edge colour fixed, by material or by axis), fog (start and end distance, colour or background), background, sky and ground colours; named styles kept in the model, chosen per camera and per scene, edited in a Styles panel; saved in `.skr`. The default (no style chosen) renders exactly as today, so golden images are unchanged. This milestone lifts the spec's v1 non-goal "Profile/silhouette edge rendering".

**Architecture:** The kernel `Scene` gains a named list of `Style`s (ids, names, settings) changed through undoable steps like tags and pages. The camera and each scene's `PageView` hold `style: Option<StyleId>` (None = the built-in default, today's look, which keeps the app's theme-driven background); choosing a style is a camera command (no undo step). The renderer takes a resolved `StyleSettings` each frame: background, sky and ground are drawn by the existing full-screen canvas pass from each pixel's view ray; fog mixes faces and lines toward the fog colour by eye distance; edge colour modes are chosen when the scene's edge vertices are built; profile edges are found on the GPU from the two adjacent face normals carried per edge vertex and drawn through the existing "wide copies" path; sketchy jitter and extensions are screen-space offsets in the edge vertex shader seeded by an edge hash; endpoints are short wide marks at each edge end.

**Tech Stack:** Rust 2024, wgpu 30, egui 0.36.2. No new dependencies.

**Spec:** `docs/superpowers/roadmap.md` row M14g; the spec's non-goal "Profile/silhouette edge rendering" is removed when this milestone lands.

## Spec notes (rulings)

1. **Style settings** (all optional parts off by default): `edges`: `color` (`fixed` with an RGB, default near-black as today | `by_material` | `by_axis`), `profiles` (off or a width 2-10 px), `sketchy` (off or `{jitter: 0-10 px, extension: 0-30 px}`), `endpoints` (off or a length 2-30 px), `show_edges` (default true; false hides all non-profile edges); `background` (RGB); `sky` (off or RGB); `ground` (off or `{color, opacity 0-1, from_below: bool}`); `fog` (off or `{start, end (m, 0 <= start < end), color: background | RGB}`). Colours as `[r,g,b]` 0-255 in the API.
2. **Styles list (model, undoable):** `add_style { name, from?: style id }` (copies settings, default settings otherwise; names unique like scenes: trimmed, 1-100 chars, duplicates refused), `change_style { id, name?, settings? (partial: only given parts change) }`, `delete_style { id }` (views and scenes that chose it fall back to the default), `styles` query (id, name, settings). Outcome ids batch-referable (`s` kind already exists in the batch reference pattern; verify which letter is free).
3. **Choosing:** `set_style { id | null }` camera command (no undo step, not modified), saved with the camera; scenes capture and restore the chosen style; `camera` query reports `style`. Ruling for the default: `null` keeps today's look including the app theme's viewport background; a chosen style's background, sky and ground replace the theme's.
4. **Edge colour:** `fixed` uses the colour for all ordinary edges (selection, hover, ghost, faded-context and section colours unchanged); `by_material`: an edge takes the front material colour of its first adjacent shown face (or the fixed colour when it has none or the face is unpainted), textures use their average colour; `by_axis`: edges parallel (within the angle tolerance) to the current drawing axes (M14c) take the red, green and blue axis colours, others the fixed colour.
5. **Profiles:** an edge is a profile when one adjacent face faces the eye and the other faces away, or it bounds only one face, or it has no faces; in parallel and perspective views; computed in the vertex shader from the adjacent face normals so orbiting needs no rebuild; drawn at the profile width via the wide-copies path; soft edges can be profiles (SketchUp draws silhouettes of smooth surfaces) when `profiles` is on.
6. **Sketchy:** jitter displaces each edge perpendicular to its screen direction by a per-edge pseudo-random amount up to `jitter` px (stable between frames: seeded by the edge's id, not time); extension lengthens each end by up to `extension` px (per-end random, deterministic). **Endpoints:** each edge end gets a wide mark `endpoints` px long along the edge, drawn at 3 px width.
7. **Background, sky, ground:** the canvas pass colours each pixel by its view ray: above the horizon the sky gradient (horizon colour = background, zenith = sky) when sky is on, else the background; below the horizon the ground colour mixed over the background by opacity when ground is on (seen from below only with `from_below`); the grid and axes draw over it as today. Print (white paper) ignores background, sky, ground and fog; raster print keeps edge settings.
8. **Fog:** faces, edges, guides and section fills fade toward the fog colour by `smoothstep(start, end, eye distance)`; fully fogged beyond `end`; the canvas is unaffected (it is the far colour when fog colour is the background).
9. **Outputs:** `render_view`, snapshots and raster print use the chosen style; the hidden-line drawing, SVG and vector PDF ignore styles; library thumbnails ignore styles; the phone viewer draws the saved chosen style.
10. **Window:** a Styles dock tab: list of styles with add (copy of the selected), rename (double-click), delete, a "Default" row (no style) at the top; clicking a row chooses it (set_style); a details editor for the chosen style (Edges: show edges, colour mode and colour, profiles and width, sketchy jitter and extension, endpoints and length; Background: background, sky, ground with opacity and from below; Fog: on, start, end, colour); each edit is one change_style (sliders commit on release, one undo step per edit). View menu: Edge Style submenu toggles for Profiles, Sketchy and Endpoints of the chosen style (disabled for Default).

## Review Focus

1. Golden images, existing render tests and the app's default look unchanged with no style chosen; WebGL2 limits.
2. Profiles correct on boxes, cylinders (soft edges), open surfaces, in perspective and parallel, inside groups (transforms incl. mirrored), no flicker while orbiting; no rebuild per frame.
3. Sketchy and endpoints stable between frames and resolution-aware (logical px).
4. Styles list: undo exact; delete falls back; scenes; `.skr` 18 gating and older output byte-identical.
5. Fog, sky and ground correct in perspective and parallel and with the camera below the ground; performance on a 20k-face model (ignored perf test).
