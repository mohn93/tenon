**Goal:** Circles and arcs are tagged as curves: one click selects a whole curve, Entity Info describes it, pushed curves get soft side edges, and arcs can be drawn by agents (`add_arc`) and in the window (the Arc tool, `a`).

  `curves.rs` has `add_curve`, the derived `Curve` shape (`curve`, `curve_of`), and `upkeep`
  (run by `take_changes`) keeping curves one non-straight chain and soft edges between two
  faces; splits, heals and welds carry tags; stencils carry tags into copies, groups and
  explodes with new curve ids; push/pull extrusion tags the cap curve and softens swept edges;
  `validate` and file loading check the rules; `EdgeData` stores the tags.

## Spec notes (rulings made in this plan)

**Data model**
- **A curve is a tag, not stored geometry.** `Edge` gains `curve: Option<CurveId>` and
  `soft: bool`. The curve's shape (closed or open, center, normal, radius, swept angle, segment
  count, length) is derived from where its edges are, on demand (`Model::curve`). Why: moves,
  rotations, push/pull stretches, weld, undo, copies, groups and explode then need no code to keep
  a center/radius record in sync; only the tag has to survive edits. SketchUp stores ArcCurve
  data, but here nothing can go stale.
- **Curve ids** are `CurveId(u64)` allocated from the same counter as entity ids (so unique in the
  whole scene, checked by `Scene::validate`), shown as `"c12"`. A curve is not an entity: `c` ids
  cannot be selected, erased or used in commands. Allocated after the geometry is drawn, so
  entity ids created by existing commands (docs examples) do not shift.
- **New op `Op::ChangeEdge(EdgeId, Edge, Edge)`** (net effect: `modified`) for retagging an
  existing edge; `insert_edge_like` adds an edge with given attributes. Undo stays exact
  (everything goes through recorded ops).
- **Invariants kept by `Model::upkeep`, run inside every `take_changes`** (so every kernel edit
  ends consistent, without touching each edit path):
  - the edges of a curve form one unbranched chain (open or closed) that turns somewhere;
  - if a curve falls apart into several chains, the chain holding its oldest edge keeps the id and
    the others get new ids (SketchUp: the rest of a curve stays a curve);
  - a chain that branches or is straight (including a lone edge) loses the tag (a single segment
    is a line);
  - a soft edge bounds at least two faces; one left bounding fewer (a neighbour face erased,
    detached, or a soft edge copied without its faces) becomes hard.
  `Model::validate` checks both rules (and so files are refused when they break them).
  Upkeep only looks at curves/soft edges touched by the pending ops (edge ops, removed faces,
  moved vertices), so edits without curves pay one scan of the pending ops.
- **Sticky geometry:** an edge split by a crossing line or vertex keeps its curve and soft flag
  on both pieces; heal (erase) joins two edges keeping what they share (same curve, both soft);
  weld re-joined edges keep the removed edge's attributes. Segment counts ignore collinear split
  points, so a split circle still reports its 24 segments (26 edges).
- **Copies, groups, explode, duplicate** go through the stencil: `Stencil.marks` carries each
  segment's (curve, soft), and `draw_stencil` re-tags the edges along each placed segment, with a
  new curve id per original curve per placement. Copies never share a curve id with the
  original. Moves and rotations keep ids (geometry only).
- **Normal and order:** a curve has no direction, so the reported normal points up (+z; on a
  vertical plane +y; else +x), and edges/vertices are listed counter-clockwise around it. A
  closed curve starts at its oldest vertex (for a drawn circle, the first corner, on the plane's
  u axis); an open one at its counter-clockwise start.
- **Kinds:** `circle` (closed, corners on one circle), `arc` (open, corners on one circle),
  `curve` (corners no longer on one circle after a partial move; no center/radius/angle).
  Circle fit: circumcenter of three spread corner points, then every corner checked within
  `LENGTH_TOL`. Corners use the relative turn tolerance `PLANE_ANGLE_TOL` (1e-6), robust to split
  points and fine for 360-gons.
- **Files:** `.skr` schema version 3; `EdgeData` gains optional `curve` (u64) and `soft` (omitted
  when false). Versions 1 and 2 open (fields default). A v2 build refuses v3 files by version.
  Curve ids count toward `next_id` on load.

**Commands and queries**
- `add_circle` now tags its edges as one curve (via `Model::add_curve(points, closed: true)`).
- **`add_arc {center, start, angle, normal?, segments?}`**: center-based, agent friendly (the tool
  converts its 2-point+bulge input to it). `angle` in degrees, signed, counter-clockwise around
  `normal` (default Z); 0 < |angle| < 360 (whole circles are `add_circle`); `start` must lie in
  the plane through `center` (within `LENGTH_TOL`); segments 2..=360, default 12 whatever the
  angle (SketchUp's arc default); each segment >= 10 * `LENGTH_TOL`; all points within the
  coordinate limit. The first point is exactly `start`, others computed; the polyline is drawn
  with `add_edge` rules (so an arc can close a face with existing edges).
- **Query `{"type": "curve", "id": "e3"}`** (any edge of the curve) returns `CurveInfo {id, kind,
  edges, vertices, segments, length, center?, normal?, radius?, angle? (degrees)}`. A non-edge id
  is `invalid_input`, an unknown one `not_found`, a plain edge `invalid_input` ("not part of a
  curve"). Edge results (`entity`, `entities`) gain `curve: "c12"` and `soft: true`, both omitted
  when absent/false. No per-edge embedding of the whole curve (keeps `entities` small).
- **Push/pull:** when a face is extruded (extrude path, including cuts, openings and the recess
  floor case), each loop side on a curve gets its moved copy on the cap tagged with a new curve
  (one per original curve), and the swept edge at a loop vertex between two sides of the same
  curve is soft. Arc ends (curve meets a straight side) stay hard. The move/stretch path (box top)
  changes no tags. Through-cuts tag the rim on the back face.
- **Smoothing deferred:** faces across soft edges are still flat shaded (no vertex normals, no
  `smooth` flag). Hidden edges make cylinders read right; smooth shading needs per-vertex normals
  in the render mesh and export, left for later (M8 or a dedicated milestone).
- Export unchanged (faces only).

**Window**
- **Soft edges are not drawn** (selected or not), **not picked and not snapped to**: filtered in
  `tools::inference::Near::around` (the one source of edge candidates for picks and snaps), so
  their midpoints/on-edge snaps go; their ends are vertices of the rims and still snap. The kernel
  `Index` still holds them (it describes geometry; push/pull uses triangles only).
- **Select click on a curve edge selects the whole curve** (Shift toggles the whole curve).
  **Box selection is unchanged**: it selects the edges inside/touching it, soft ones included, so
  box-selecting a cylinder and erasing leaves nothing invisible behind.
- Erase tool unchanged: it erases one segment (SketchUp behaviour; the rest stays a curve).
- **Entity Info:** when the selection is exactly the edges of one curve: "1 circle" / "1 arc" /
  "1 curve", then "Radius: 2 m" (round kinds), "Angle: 90°" (arcs), "Segments: n",
  "Length: L" (total edge length). Any other edge selection reads as before ("2 edges").

**Arc tool**
- `a` (free; SketchUp's default), placed after Circle in the toolbar; physical KeyA fallback for
  non-ASCII layouts. SketchUp's 2-point arc: click start (plane: face under the click if the point
  is on it, else horizontal, the Circle tool's rule), click end, move to pull the bulge, click.
- Typed values: before the end click a length sets the chord along the cursor direction; after
  it a length sets the bulge height on the side the cursor is on (left of start->end when on the
  chord). "12s" sets the segment count (2..=360) at any time, kept while the tool is selected
  ("Arcs get 12 segments"). End on the start, or a bulge under `LENGTH_TOL`, is refused with a
  message and keeps the state; Escape starts over.
- Measurement box: "Length" before the end click, "Bulge" (absolute) after. Anchor: start, then
  the chord midpoint (axis inference from the midpoint helps pull a bulge square to the chord).
- The tool emits only `Command::AddArc`, computed by `session::arc_from_bulge` and checked with
  `arc_points` first.
- **Toolbar width:** adding "Arc" takes it to about 1190 pt; it still fits the 1280x800 test
  window (the click-along-the-row UI test now also requires the Arc button). No label changes.

```rust
use std::collections::BTreeSet;
use std::f64::consts::TAU;

use glam::{DAffine3, DVec3};
use kernel::{
    CurveId, CurveKind, DefinitionKind, EdgeId, EntityId, MeshId, Model, Scene, SceneData,
};

fn p(x: f64, y: f64, z: f64) -> DVec3 {
    DVec3::new(x, y, z)
}

/// The corners of a regular polygon with `n` sides around `center`, on the ground, the first
/// one along +X, counter-clockwise.
fn ring(center: DVec3, radius: f64, n: usize) -> Vec<DVec3> {
    (0..n)
        .map(|k| {
            let a = TAU * k as f64 / n as f64;
            center + p(a.cos(), a.sin(), 0.0) * radius
        })
        .collect()
}

/// The points of an arc around `center` from angle 0 sweeping `angle` radians, `n` segments.
fn arc(center: DVec3, radius: f64, angle: f64, n: usize) -> Vec<DVec3> {
    (0..=n)
        .map(|k| {
            let a = angle * k as f64 / n as f64;
            center + p(a.cos(), a.sin(), 0.0) * radius
        })
        .collect()
}

/// The curves of a mesh's edges.
fn curves(m: &Model) -> BTreeSet<CurveId> {
    m.edges().filter_map(|(_, e)| e.curve).collect()
}

fn only_curve(m: &Model) -> CurveId {
    let all = curves(m);
    assert_eq!(all.len(), 1, "{all:?}");
    *all.iter().next().unwrap()
}

fn edge_at(m: &Model, a: DVec3, b: DVec3) -> EdgeId {
    let v = |q: DVec3| {
        m.vertices()
            .find(|(_, v)| v.pos.distance(q) < 1e-9)
            .map(|(id, _)| id)
            .unwrap()
    };
    m.edge_between(v(a), v(b)).unwrap()
}

fn close(a: DVec3, b: DVec3) -> bool {
    a.distance(b) < 1e-9
}

#[test]
fn a_drawn_circle_is_one_curve_whose_shape_comes_from_its_edges() {
    let mut m = Model::new();
    let points = ring(p(1.0, 2.0, 0.0), 2.0, 24);
    let c = m.add_curve(&points, true).unwrap();
    m.validate().unwrap();
    assert_eq!((m.edges().count(), m.faces().count()), (24, 1));
    let id = only_curve(&m);
    assert!(m.edges().all(|(_, e)| e.curve == Some(id) && !e.soft));

    let curve = m.curve(id).unwrap();
    assert_eq!(curve.kind(), CurveKind::Circle);
    assert!(curve.closed);
    assert_eq!(
        (curve.edges.len(), curve.vertices.len(), curve.segments),
        (24, 24, 24)
    );
    let circle = curve.circle.unwrap();
    assert!(close(circle.center, p(1.0, 2.0, 0.0)), "{circle:?}");
    assert!((circle.radius - 2.0).abs() < 1e-9);
    assert_eq!(circle.normal, DVec3::Z);
    assert_eq!(circle.angle, TAU);
    let side = points[0].distance(points[1]);
    assert!((curve.length - 24.0 * side).abs() < 1e-9);
    // It starts at the first corner drawn and runs counter-clockwise.
    assert!(close(m.position(curve.vertices[0]).unwrap(), points[0]));
    assert!(close(m.position(curve.vertices[1]).unwrap(), points[1]));
    let e0 = curve.edges[0];
    assert_eq!(m.curve_of(e0).unwrap(), curve);

    // Undo and redo restore the curve exactly.
    let after = m.clone();
    m.apply(&c.inverse());
    assert_eq!(m, Model::new());
    m.apply(&c);
    assert_eq!(m, after);
}

#[test]
fn a_circle_drawn_clockwise_reports_an_upward_normal() {
    let mut m = Model::new();
    let mut points = ring(DVec3::ZERO, 1.0, 12);
    points.reverse();
    m.add_curve(&points, true).unwrap();
    let curve = m.curve(only_curve(&m)).unwrap();
    assert_eq!(curve.circle.unwrap().normal, DVec3::Z);
    let at = |i: usize| m.position(curve.vertices[i]).unwrap();
    // Counter-clockwise around +Z: the second vertex is ahead of the first.
    assert!(at(0).cross(at(1)).z > 0.0);
}

#[test]
fn an_open_polyline_is_an_arc_and_a_straight_one_is_no_curve() {

#[test]
fn split_curve_edges_stay_on_the_curve_and_heal_back() {
    let mut m = Model::new();
    let points = ring(DVec3::ZERO, 1.0, 24);
    m.add_curve(&points, true).unwrap();
    let id = only_curve(&m);
    // A line across the circle splits two of its edges in their middles.
    let a = (points[3] + points[4]) / 2.0;
    let b = (points[15] + points[16]) / 2.0;
    let line = m.add_edge(a, b).unwrap();
    m.validate().unwrap();
    assert_eq!(m.faces().count(), 2);
    let curve = m.curve(id).unwrap();
    assert_eq!((curve.edges.len(), curve.segments), (26, 24));
    assert!((curve.circle.unwrap().radius - 1.0).abs() < 1e-9);
    let across = line
        .summary()
        .created
        .iter()
        .find_map(|e| match e {
            EntityId::Edge(e) if m.edge(*e).is_some_and(|x| x.curve.is_none()) => Some(*e),
            _ => None,
        })
        .unwrap();

    // Erasing the line heals the split edges back into the circle.
    m.erase(&[across], &[]);
    m.validate().unwrap();
    assert_eq!(m.edges().count(), 24);
    assert_eq!(m.curve(id).unwrap().edges.len(), 24);
}

#[test]
fn erasing_curve_edges_leaves_arcs_and_a_lone_edge_is_no_curve() {
    let mut m = Model::new();
    let points = ring(DVec3::ZERO, 1.0, 12);
    m.add_curve(&points, true).unwrap();
    let id = only_curve(&m);

    let first = m.erase(&[edge_at(&m, points[0], points[1])], &[]);
    m.validate().unwrap();
    let curve = m.curve(id).unwrap();
    assert_eq!(curve.kind(), CurveKind::Arc);
    assert_eq!(curve.segments, 11);
    assert!((curve.circle.unwrap().angle - TAU * 11.0 / 12.0).abs() < 1e-12);
    // The face went with the edge; the rest stays one curve, untouched.
    assert!(first.summary().modified.is_empty());

    // Erasing an edge in the middle splits it in two: the older half keeps the id.
    let second = m.erase(&[edge_at(&m, points[6], points[7])], &[]);
    m.validate().unwrap();
    let all = curves(&m);
    assert_eq!(all.len(), 2);
    assert!(all.contains(&id));
    let other = *all.iter().find(|c| **c != id).unwrap();
    assert!(other.0 > id.0, "the new curve gets a new id");
    let lengths: BTreeSet<usize> = all.iter().map(|c| m.curve(*c).unwrap().segments).collect();
    assert_eq!(lengths, BTreeSet::from([5]));
    assert_eq!(
        second.summary().modified.len(),
        5,
        "the renamed half is modified"
    );

    // Erase down to one edge: it is no curve any more.
    let rest: Vec<EdgeId> = m.curve(other).unwrap().edges[1..].to_vec();
    m.erase(&rest, &[]);
    m.validate().unwrap();
    assert!(!curves(&m).contains(&other));
    assert_eq!(m.edges().filter(|(_, e)| e.curve.is_none()).count(), 1);
}

#[test]
fn moved_turned_and_copied_curves_follow_their_edges() {
    let mut m = Model::new();
    m.add_curve(&ring(DVec3::ZERO, 1.0, 8), true).unwrap();
    let id = only_curve(&m);
    let all: BTreeSet<_> = m.vertices().map(|(v, _)| v).collect();
    m.move_vertices(&all, p(5.0, 0.0, 0.0)).unwrap();
    m.validate().unwrap();
    assert!(close(
        m.curve(id).unwrap().circle.unwrap().center,
        p(5.0, 0.0, 0.0)
    ));

    // Stood up on its side, its normal turns too.
    let turn = DAffine3::from_translation(p(5.0, 0.0, 0.0))
        * DAffine3::from_rotation_x(TAU / 4.0)
        * DAffine3::from_translation(p(-5.0, 0.0, 0.0));
    m.transform_vertices(&all, turn).unwrap();
    let circle = m.curve(id).unwrap().circle.unwrap();
    assert!(close(circle.normal, DVec3::Y), "{circle:?}");

    let edges: Vec<EdgeId> = m.edges().map(|(e, _)| e).collect();
    let faces: Vec<_> = m.faces().map(|(f, _)| f).collect();
    m.copy(&edges, &faces, p(0.0, 3.0, 0.0), 2).unwrap();
    m.validate().unwrap();
    let ids = curves(&m);
    assert_eq!(ids.len(), 3, "each copy is a curve of its own");
    let centers: Vec<DVec3> = ids
        .iter()
        .map(|c| m.curve(*c).unwrap().circle.unwrap().center)
        .collect();
    assert!(close(centers[1], p(5.0, 3.0, 0.0)) && close(centers[2], p(5.0, 6.0, 0.0)));
}

#[test]
fn curves_go_into_groups_and_come_out_of_explode_with_new_ids() {
    let mut m = Model::new();
    m.add_curve(&ring(DVec3::ZERO, 1.0, 12), true).unwrap();
    let id = only_curve(&m);
    let mut s = Scene::from_root(m);
    let edges: Vec<EdgeId> = s.root().edges().map(|(e, _)| e).collect();
    let faces: Vec<_> = s.root().faces().map(|(f, _)| f).collect();
    let (i, _) = s
        .make_group(MeshId::Root, &edges, &faces, &[], DefinitionKind::Group, "")
        .unwrap();
    s.validate().unwrap();
    let d = s.root().instance(i).unwrap().definition;
    let inner = only_curve(&s.definition(d).unwrap().mesh);
    assert_ne!(inner, id);
    assert_eq!(
        s.definition(d).unwrap().mesh.curve(inner).unwrap().kind(),
        CurveKind::Circle
    );

    s.explode(MeshId::Root, i).unwrap();
    s.validate().unwrap();
    let out = only_curve(s.root());
    assert!(out != id && out != inner);
    assert_eq!(s.root().curve(out).unwrap().segments, 12);
}

#[test]
fn curves_and_soft_flags_are_saved_and_checked_on_load() {
    let mut m = Model::new();
```

```rust
//! Curves (chains of edges drawn as one circle or arc) and soft edges.
//!
//! A curve is only a tag on its edges: its shape (center, radius, angle) is worked out from
//! where the edges are, so it follows every move, turn, copy and undo without being stored.
//! Every edit ends with `upkeep`, which keeps two rules: the edges of a curve form one
//! unbranched chain that is not straight, and a soft edge bounds at least two faces.

use std::collections::{BTreeMap, BTreeSet};
use std::f64::consts::TAU;

use glam::DVec3;
use serde::{Deserialize, Serialize};

use crate::edit::{KernelError, check_segment};
use crate::geom::{LENGTH_TOL, PLANE_ANGLE_TOL, project_on_segment};
use crate::ids::{CurveId, EdgeId, VertexId};
use crate::model::{ChangeSet, Face, Model, Op};

/// A curve as its edges trace it now.
#[derive(Clone, Debug, PartialEq)]
pub struct Curve {
    pub id: CurveId,
    /// The edges in order along the curve.
    pub edges: Vec<EdgeId>,
    /// The vertices in order along the curve (counter-clockwise around the circle's normal
    /// when it lies on one). A closed curve's first vertex is not repeated at the end.
    pub vertices: Vec<VertexId>,
    /// True when the chain closes on itself.
    pub closed: bool,
    /// Straight segments: an edge other geometry split in two still counts once.
    pub segments: usize,
    /// Total length of the edges.
    pub length: f64,
    /// The circle through the curve's corners, when they all lie on one.
    pub circle: Option<CurveCircle>,
}

/// The circle a curve's corners lie on.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct CurveCircle {
    pub center: DVec3,
    /// The unit normal of the circle's plane, pointing up: positive z, or on a vertical plane
    /// positive y, else positive x. A curve has no direction of its own.
    pub normal: DVec3,
    pub radius: f64,
    /// The angle the curve sweeps around the center, in radians (TAU when closed).
    pub angle: f64,
}

/// What a curve traces.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize, schemars::JsonSchema)]
#[serde(rename_all = "snake_case")]
pub enum CurveKind {
    /// A closed chain whose corners lie on a circle.
    Circle,
    /// An open chain whose corners lie on a circle.
    Arc,
    /// A chain whose corners no longer lie on one circle (some of its vertices were moved).
    Curve,
}

impl Curve {
    pub fn kind(&self) -> CurveKind {
        match (self.closed, self.circle.is_some()) {
            (true, true) => CurveKind::Circle,
            (false, true) => CurveKind::Arc,
            _ => CurveKind::Curve,
        }
    }
}

impl Model {
    /// Draws the polyline through `points` (closed: the last point joins the first) with the
    /// rules of `add_edge`, and puts the edges along it on one new curve, as one ChangeSet.
    /// A polyline that is straight, or whose edges do not form one chain, gets no curve.
    pub fn add_curve(&mut self, points: &[DVec3], closed: bool) -> Result<ChangeSet, KernelError> {
        let n = points.len();
        let sides = if closed { n } else { n.saturating_sub(1) };
        for i in 0..sides {
            check_segment(points[i], points[(i + 1) % n])?;
        }
        for i in 0..sides {
            self.draw_segment(points[i], points[(i + 1) % n]);
        }
        let curve = self.new_curve();
        for i in 0..sides {
            self.tag_along(points[i], points[(i + 1) % n], Some(curve), false);
        }
        Ok(self.take_changes())
    }

    /// Puts every edge lying along the segment a-b on `curve` and sets its soft flag.
    pub(crate) fn tag_along(&mut self, a: DVec3, b: DVec3, curve: Option<CurveId>, soft: bool) {
        let len = a.distance(b);
        if len < LENGTH_TOL {
            return;
        }
        let on = |p: DVec3| {
            let (t, d) = project_on_segment(p, a, b);
            let tol = LENGTH_TOL / len;
            d < LENGTH_TOL && t > -tol && t < 1.0 + tol
        };
        let along: Vec<EdgeId> = self
            .edges()
            .filter(|(_, e)| on(self.pos(e.v[0])) && on(self.pos(e.v[1])))
            .map(|(id, _)| id)
            .collect();
        for e in along {
            self.set_edge(e, curve, soft);
        }
    }

    /// The curve edge `edge` is part of, if any.
    pub fn curve_of(&self, edge: EdgeId) -> Option<Curve> {
        self.curve(self.edge(edge)?.curve?)
    }

    /// The curve with this id, if any edge of the mesh is on it.
    pub fn curve(&self, id: CurveId) -> Option<Curve> {
        let members: Vec<(EdgeId, [VertexId; 2])> = self
            .edges()
            .filter(|(_, e)| e.curve == Some(id))
            .map(|(e, edge)| (e, edge.v))
            .collect();
        let chain = chain(&members)?;
        let points: Vec<DVec3> = chain.vertices.iter().map(|v| self.pos(*v)).collect();
        let corners = corners(&points, chain.closed);
        let segments = if chain.closed {
            corners.len()
        } else {
            corners.len() + 1
        };
        let length = chain
            .edges
            .iter()
            .map(|e| {
                let [a, b] = self.edge(*e).unwrap().v;
                self.pos(a).distance(self.pos(b))
            })
            .sum();
        let mut curve = Curve {
            id,
            edges: chain.edges,
            vertices: chain.vertices,
            closed: chain.closed,
            segments,
            length,
            circle: None,
        };
        // The corners, plus the ends of an open curve, are the points that lie on the circle.
        let mut key: Vec<usize> = corners.clone();
        if !curve.closed {
            key.insert(0, 0);
            key.push(points.len() - 1);
        }
        let turn: DVec3 = corners.iter().map(|&i| turn_at(&points, i)).sum();
        let Some(mut normal) = turn.try_normalize() else {
            return Some(curve);
        };
        let up = normal.z > 1e-9
            || (normal.z.abs() <= 1e-9 && normal.y > 1e-9)
            || (normal.z.abs() <= 1e-9 && normal.y.abs() <= 1e-9 && normal.x > 0.0);
        if !up {
            normal = -normal;
            curve.vertices.reverse();
            curve.edges.reverse();
            if curve.closed {
                // Keep the same first vertex.
                curve.vertices.rotate_right(1);
            }
        }
        if curve.closed {
            // Start at the oldest vertex: for a drawn circle, the first corner.
            let first = (0..curve.vertices.len())
                .min_by_key(|&i| curve.vertices[i])
                .unwrap();
            curve.vertices.rotate_left(first);
            let start = curve.vertices[0];
            let at = curve
                .edges
                .iter()
                .position(|e| {
                    let [a, b] = self.edge(*e).unwrap().v;
                    let next = curve.vertices[1 % curve.vertices.len()];
                    (a == start && b == next) || (b == start && a == next)
                })
                .unwrap_or(0);
            curve.edges.rotate_left(at);
        }
        let key: Vec<DVec3> = key.iter().map(|&i| points[i]).collect();
        let k = key.len();
        if k < 3 {
            return Some(curve);
        }
        let (a, b, c) = if curve.closed {
            (key[0], key[k / 3], key[2 * k / 3])
        } else {
            (key[0], key[k / 2], key[k - 1])
        };
        let Some(center) = circumcenter(a, b, c) else {
            return Some(curve);
        };
        let radius = a.distance(center);
        let round = key.iter().all(|p| {
            (p.distance(center) - radius).abs() <= LENGTH_TOL
                && (*p - center).dot(normal).abs() <= LENGTH_TOL
        });
        if !round {
            return Some(curve);
        }
        let angle = if curve.closed {
            TAU
        } else {
            let ordered: Vec<DVec3> = curve.vertices.iter().map(|v| self.pos(*v)).collect();
            ordered
                .windows(2)
                .map(|w| {
                    let (u, v) = (w[0] - center, w[1] - center);
                    u.cross(v).dot(normal).atan2(u.dot(v))
                })
                .sum()
        };
        curve.circle = Some(CurveCircle {
            center,
            normal,
            radius,
            angle,
        });
        Some(curve)
    }

    /// Brings the curves and soft edges the pending edit touched back in line: a curve whose
    /// edges fell apart into several chains keeps its id on the oldest chain and the others
    /// become curves of their own; a chain that branches or is straight (a lone edge) stops
    /// being a curve; a soft edge left bounding fewer than two faces stops being soft.
    pub(crate) fn upkeep(&mut self) {
        let mut curves: BTreeSet<CurveId> = BTreeSet::new();
        let mut soft: BTreeSet<EdgeId> = BTreeSet::new();
        let mut lost: BTreeSet<(VertexId, VertexId)> = BTreeSet::new();
        let mut moved: BTreeSet<VertexId> = BTreeSet::new();
        for op in self.pending() {
            match op {
                Op::AddEdge(id, e) => {
                    curves.extend(e.curve);
                    if e.soft {
                        soft.insert(*id);
                    }
                }
                Op::RemoveEdge(_, e) => curves.extend(e.curve),
                Op::ChangeEdge(id, from, to) => {
                    curves.extend(from.curve);
                    curves.extend(to.curve);
                    if to.soft {
                        soft.insert(*id);
                    }
                }
                Op::RemoveFace(_, f) => lost.extend(face_sides(f)),
                Op::MoveVertex(v, _, _) => {
                    moved.insert(*v);
                }
                _ => {}
            }
        }
        if !moved.is_empty() || !lost.is_empty() {
            for (id, e) in self.edges() {
                if e.v.iter().any(|v| moved.contains(v)) {
                    curves.extend(e.curve);
                }
                if e.soft && lost.contains(&side(e.v[0], e.v[1])) {
                    soft.insert(id);
                }
            }
        }
        if !curves.is_empty() {
            self.mend_curves(&curves);
        }
        if !soft.is_empty() {
            let bounding = self.face_counts();
            let hard: Vec<EdgeId> = soft
                .into_iter()
                .filter(|e| {
                    self.edge(*e).is_some_and(|edge| {
                        edge.soft && bounding.get(&side(edge.v[0], edge.v[1])).unwrap_or(&0) < &2
                    })
                })
                .collect();
            for e in hard {
                let curve = self.edge(e).unwrap().curve;
                self.set_edge(e, curve, false);
            }
        }
    }

    fn mend_curves(&mut self, curves: &BTreeSet<CurveId>) {
        let mut members: BTreeMap<CurveId, Vec<(EdgeId, [VertexId; 2])>> = BTreeMap::new();
        for (id, e) in self.edges() {
            if let Some(c) = e.curve.filter(|c| curves.contains(c)) {
                members.entry(c).or_default().push((id, e.v));
            }
        }
        for (c, edges) in members {
            let mut kept = false;
            for part in components(&edges) {
                let fine = chain(&part).is_some_and(|ch| !self.straight(&ch));
                let tag = if !fine {
                    None
                } else if !kept {
                    kept = true;
                    Some(c)
                } else {
                    Some(self.new_curve())
                };
                if tag != Some(c) {
                    for (e, _) in part {
                        let soft = self.edge(e).unwrap().soft;
                        self.set_edge(e, tag, soft);
                    }
                }
            }
        }
    }

    /// True when an open chain does not turn anywhere (a closed one always turns).
    fn straight(&self, chain: &Chain) -> bool {
        let points: Vec<DVec3> = chain.vertices.iter().map(|v| self.pos(*v)).collect();
        !chain.closed && corners(&points, false).is_empty()
    }

    /// How many face loops use each side (a vertex pair, smaller id first).
    fn face_counts(&self) -> BTreeMap<(VertexId, VertexId), usize> {
        let mut counts = BTreeMap::new();
        for (_, f) in self.faces() {
            for s in face_sides(f) {
                *counts.entry(s).or_insert(0) += 1;
            }
        }
        counts
    }

    /// Checks the curve and soft-edge rules `upkeep` keeps.
    pub(crate) fn validate_curves(&self) -> Result<(), String> {

        for (id, e) in self.edges() {
            if let Some(c) = e.curve {
                members.entry(c).or_default().push((id, e.v));
            }
        }

                return Err(format!("soft edge {id:?} bounds fewer than two faces"));
            }
        }

    }
}

/// Edges in order along a chain, with its vertices.
struct Chain {
    edges: Vec<EdgeId>,
    vertices: Vec<VertexId>,
    closed: bool,
}

/// The edges as one unbranched chain (open or closed), or None if they branch, fall apart,
/// or are none.
fn chain(edges: &[(EdgeId, [VertexId; 2])]) -> Option<Chain> {
    let mut at: BTreeMap<VertexId, Vec<usize>> = BTreeMap::new();
    for (i, (_, [a, b])) in edges.iter().enumerate() {
        at.entry(*a).or_default().push(i);
        at.entry(*b).or_default().push(i);
    }
    if edges.is_empty() || at.values().any(|e| e.len() > 2) {
        return None;
    }
    let ends: Vec<VertexId> = at
        .iter()
        .filter(|(_, e)| e.len() == 1)
        .map(|(v, _)| *v)
        .collect();
    let (start, closed) = match ends[..] {
        [] => (edges[0].1[0], true),
        [first, _] => (first, false),
        _ => return None,
    };
    let mut used = vec![false; edges.len()];
    let mut out = Chain {
        edges: Vec::new(),
        vertices: vec![start],
        closed,
    };
    let mut v = start;
    while let Some(&i) = at[&v].iter().find(|&&i| !used[i]) {
        used[i] = true;
        let (e, [a, b]) = edges[i];
        out.edges.push(e);
        v = if a == v { b } else { a };
        out.vertices.push(v);
    }
    if closed {
        out.vertices.pop();
    }
    (out.edges.len() == edges.len()).then_some(out)
}

/// The edges split into groups connected through shared vertices, oldest edge's group first.
fn components(edges: &[(EdgeId, [VertexId; 2])]) -> Vec<Vec<(EdgeId, [VertexId; 2])>> {
    let mut at: BTreeMap<VertexId, Vec<usize>> = BTreeMap::new();
    for (i, (_, [a, b])) in edges.iter().enumerate() {
        at.entry(*a).or_default().push(i);
        at.entry(*b).or_default().push(i);
    }
    let mut group = vec![usize::MAX; edges.len()];
    let mut parts: Vec<Vec<(EdgeId, [VertexId; 2])>> = Vec::new();
    for first in 0..edges.len() {
        if group[first] != usize::MAX {
            continue;
        }
        let g = parts.len();
        parts.push(Vec::new());
        let mut stack = vec![first];
        group[first] = g;
        while let Some(i) = stack.pop() {
            parts[g].push(edges[i]);
            for v in edges[i].1 {
                for &j in &at[&v] {
                    if group[j] == usize::MAX {
                        group[j] = g;
                        stack.push(j);
                    }
                }
            }
        }
    }
    for p in &mut parts {
        p.sort();
    }
    parts.sort();
    parts
}

/// Indices of the points where the polyline turns (for an open one, not counting its ends).
fn corners(points: &[DVec3], closed: bool) -> Vec<usize> {
    let n = points.len();
    let range = if closed { 0..n } else { 1..n.saturating_sub(1) };
    range
        .filter(|&i| {
            let (d1, d2) = in_out(points, i);
            d1.cross(d2).length() > PLANE_ANGLE_TOL * d1.length() * d2.length()
        })
        .collect()
}

/// The directions into and out of point `i` of a polyline (wrapping around).
fn in_out(points: &[DVec3], i: usize) -> (DVec3, DVec3) {
    let n = points.len();
    let (prev, next) = (points[(i + n - 1) % n], points[(i + 1) % n]);
    (points[i] - prev, next - points[i])
}

/// The turn at point `i`: along the normal the polyline turns counter-clockwise around.
fn turn_at(points: &[DVec3], i: usize) -> DVec3 {
    let (d1, d2) = in_out(points, i);
    d1.cross(d2)
}

/// The center of the circle through three points, or None if they are in a line.
fn circumcenter(a: DVec3, b: DVec3, c: DVec3) -> Option<DVec3> {
    let (ab, ac) = (b - a, c - a);
    let n = ab.cross(ac);
    let n2 = n.length_squared();
    if n2 <= f64::EPSILON * ab.length_squared() * ac.length_squared() {
        return None;
    }
    Some(a + (n.cross(ab) * ac.length_squared() + ac.cross(n) * ab.length_squared()) / (2.0 * n2))
}

/// The vertex pair of a side, smaller id first.
fn side(a: VertexId, b: VertexId) -> (VertexId, VertexId) {
    (a.min(b), a.max(b))
}

/// Every side of a face's loops.
fn face_sides(f: &Face) -> Vec<(VertexId, VertexId)> {
    std::iter::once(&f.outer)
        .chain(&f.holes)
        .flat_map(|l| (0..l.len()).map(move |i| side(l[i], l[(i + 1) % l.len()])))
        .collect()
}
```

```rust
use glam::DVec3;
use kernel::geom::LENGTH_TOL;

use crate::circle::MAX_CIRCLE_SEGMENTS;

/// Segments an arc gets when none are asked for, whatever its angle (as in SketchUp).
pub const DEFAULT_ARC_SEGMENTS: u32 = 12;

/// The points, in order, of the arc around `center` that starts at `start` and turns `angle`
/// degrees counter-clockwise around `normal` (Z when absent; negative angles turn clockwise),
/// as `segments` equal straight segments: `segments + 1` points, the first exactly `start`.
/// `start` must lie in the plane through `center` with that normal; the angle must be between
/// 0 and 360 degrees in size, both excluded, and each segment at least 10 times the merge
/// tolerance long.
pub fn arc_points(
    center: DVec3,
    start: DVec3,
    angle: f64,
    normal: Option<DVec3>,
    segments: u32,
) -> Result<Vec<DVec3>, CommandError> {
    let invalid = |m: String| CommandError::new(ErrorKind::InvalidInput, m);
    let normal = match normal {
        None => DVec3::Z,
        Some(n) => match n.try_normalize() {
            Some(n) => n,
            None => return Err(invalid("normal must be a non-zero vector".into())),
        },
    };
    if !(2..=MAX_CIRCLE_SEGMENTS).contains(&segments) {
        return Err(invalid(format!(
            "segments must be between 2 and {MAX_CIRCLE_SEGMENTS}"
        )));
    }
    if !angle.is_finite() || angle.abs() < 1e-9 || angle.abs() > 360.0 - 1e-9 {
        return Err(invalid(
            "angle must be more than 0 and less than 360 degrees in size (use add_circle for \
             a whole circle)"
                .into(),
        ));
    }
    let r = start - center;
    if r.dot(normal).abs() > LENGTH_TOL {
        return Err(invalid(
            "start must lie in the plane through center with the normal".into(),
        ));
    }
    let r = r - normal * r.dot(normal);
    let radius = r.length();
    let step = angle.to_radians() / segments as f64;
    let side = 2.0 * radius * (step.abs() / 2.0).sin();
    if side < 10.0 * LENGTH_TOL {
        return Err(invalid(
            "start must be far enough from center for the segments".into(),
        ));
    }
    let across = normal.cross(r);
    Ok((0..=segments)
        .map(|k| {
            if k == 0 {
                return start;
            }
            let a = step * k as f64;
            center + r * a.cos() + across * a.sin()
        })
        .collect())
}

/// The center and angle (degrees, counter-clockwise around `normal`) of the arc from `start`
/// to `end` in the plane with unit `normal` whose middle lies `bulge` meters from the middle
/// of the chord: to the left of start-to-end looking down the normal when positive, to the
/// right when negative. None when the chord or the bulge is too short.
pub fn arc_from_bulge(start: DVec3, end: DVec3, bulge: f64, normal: DVec3) -> Option<(DVec3, f64)> {
    let chord = end - start;
    let half = chord.length() / 2.0;
    if half < LENGTH_TOL || !bulge.is_finite() || bulge.abs() < LENGTH_TOL {
        return None;
    }
    let left = normal.cross(chord / (2.0 * half));
    let radius = (half * half + bulge * bulge) / (2.0 * bulge.abs());
    let middle = (start + end) / 2.0 + left * bulge;
    let center = middle - left * bulge.signum() * radius;
    let angle = -bulge.signum() * 4.0 * (bulge.abs() / half).atan();
    Some((center, angle.to_degrees()))
}
```

```rust
//! The Arc tool (SketchUp's 2-point arc): click the start, click the end, then pull the bulge
//! out and click (or type its height). The arc lies on the face under the start click, or on a
//! horizontal plane. Before the end click, a typed length sets the chord along the cursor's
//! direction. Typing "12s" sets the number of segments, before or during an arc; the count is
//! kept while the Arc tool stays selected.

use glam::DVec3;
use kernel::geom::LENGTH_TOL;
use session::{Command, DEFAULT_ARC_SEGMENTS, arc_from_bulge, arc_points};

use crate::rectangle::{on_plane, plane_normal};
use crate::tool::{Tool, ToolContext, ToolEvent, ToolOutput};
use crate::vcb::{format_length, parse_length, parse_segments};

#[derive(Clone, Debug)]
pub struct ArcTool {
    /// The start and the normal of the plane the arc lies in.
    start: Option<(DVec3, DVec3)>,
    /// The end, once clicked.
    end: Option<DVec3>,
    /// The cursor's point on the arc's plane.
    hover: Option<DVec3>,
    segments: u32,
}

impl Default for ArcTool {
    fn default() -> Self {
        ArcTool {
            start: None,
            end: None,
            hover: None,
            segments: DEFAULT_ARC_SEGMENTS,
        }
    }
}

impl ArcTool {
    pub fn new() -> Self {
        Self::default()
    }

    /// The unit direction across the chord, to the left of start-to-end looking down the
    /// normal: positive bulges go this way.
    fn left(&self) -> Option<DVec3> {
        let ((start, normal), end) = (self.start?, self.end?);
        normal.cross(end - start).try_normalize()
    }

    /// The bulge the cursor pulls: its distance from the chord, signed by side.
    fn bulge(&self) -> Option<f64> {
        let ((start, _), end, hover) = (self.start?, self.end?, self.hover?);
        Some((hover - (start + end) / 2.0).dot(self.left()?))
    }

    /// The `AddArc` command for the arc with `bulge`, or why it cannot be drawn.
    fn command(&self, bulge: f64) -> Result<Command, String> {
        let ((start, normal), end) = (
            self.start.ok_or("Click the start first")?,
            self.end.ok_or("Click the end first")?,
        );
        let (center, angle) = arc_from_bulge(start, end, bulge, normal)
            .ok_or("Pull the arc away from the line between its ends")?;
        arc_points(center, start, angle, Some(normal), self.segments).map_err(|e| e.message)?;
        Ok(Command::AddArc {
            center: center.to_array(),
            start: start.to_array(),
            angle,
            normal: Some(normal.to_array()),
            segments: Some(self.segments),
        })
    }

    /// Emits the arc with `bulge` and starts over, or explains why it cannot be drawn.
    fn finish(&mut self, bulge: f64, out: &mut ToolOutput) {
        match self.command(bulge) {
            Ok(c) => {
                out.commands.push(c);
                self.on_external_change();
            }
            Err(message) => out.message = Some(message),
        }
    }

    /// Sets the end, unless it is on the start.
    fn set_end(&mut self, end: DVec3, out: &mut ToolOutput) {
        let Some((start, _)) = self.start else {
            return;
        };
        if end.distance(start) < 10.0 * LENGTH_TOL {
            out.message = Some("The end must be away from the start".into());
        } else {
            self.end = Some(end);
        }
    }
}

impl Tool for ArcTool {
    fn name(&self) -> &'static str {
        "Arc"
    }

    fn prompt(&self) -> &'static str {
        match (self.start, self.end) {
            (None, _) => "Click the start of the arc; type 12s for 12 segments",
            (Some(_), None) => "Click the end of the arc, or type the distance to it",
            (Some(_), Some(_)) => "Pull out the bulge and click, or type its height",
        }
    }

    fn measurement(&self) -> (&'static str, Option<String>) {
        match (self.start, self.end, self.hover) {
            (Some(_), Some(_), _) => ("Bulge", self.bulge().map(|b| format_length(b.abs()))),
            (Some((s, _)), None, Some(h)) => ("Length", Some(format_length(s.distance(h)))),
            _ => ("Length", None),
        }
    }

    fn anchor(&self) -> Option<DVec3> {
        match (self.start, self.end) {
            (Some((s, _)), Some(e)) => Some((s + e) / 2.0),
            (Some((s, _)), None) => Some(s),
            _ => None,
        }
    }

    fn handle(&mut self, event: ToolEvent, ctx: &ToolContext) -> ToolOutput {
        let mut out = ToolOutput::default();
        match event {
            ToolEvent::Move(hit) => {
                if let Some((start, normal)) = self.start {
                    self.hover = on_plane(start, normal, &hit, ctx);
                }
            }
            ToolEvent::Click(hit) => match (self.start, self.end) {
                (None, _) => self.start = Some((hit.point, plane_normal(&hit, ctx))),
                (Some((start, normal)), None) => {
                    if let Some(p) = on_plane(start, normal, &hit, ctx) {
                        self.set_end(p, &mut out);
                    }
                }
                (Some((start, normal)), Some(_)) => {
                    self.hover = on_plane(start, normal, &hit, ctx);
                    if let Some(b) = self.bulge() {
                        self.finish(b, &mut out);
                    }
                }
            },
            ToolEvent::Value(text) => {
                if let Some(n) = parse_segments(&text) {
                    match arc_points(DVec3::ZERO, DVec3::X, 90.0, None, n) {
                        Ok(_) => {
                            self.segments = n;
                            out.message = Some(format!("Arcs get {n} segments"));
                        }
                        Err(e) => out.message = Some(e.message),
                    }
                } else {
                    match (self.start, self.end, parse_length(&text)) {
                        (None, _, _) => {
                            out.message = Some("Click the start first, or type 12s".into());
                        }
                        (_, _, None) => {
                            out.message = Some(format!("Not a length or a segment count: {text}"));
                        }
                        (Some((start, _)), None, Some(d)) => {
                            match self.hover.and_then(|h| (h - start).try_normalize()) {
                                Some(dir) => self.set_end(start + dir * d, &mut out),
                                None => {
                                    out.message =
                                        Some("Point toward the end, then type the distance".into())
                                }
                            }
                        }
                        (Some(_), Some(_), Some(h)) => {
                            // The bulge keeps the side the cursor is on (left when on the chord).
                            let side = self.bulge().filter(|b| *b < 0.0).map_or(1.0, |_| -1.0);
                            self.finish(h.abs() * side, &mut out);
                        }
                    }
                }
            }
            ToolEvent::Release(_) | ToolEvent::DoubleClick(_) | ToolEvent::ToggleCopy => {}
            ToolEvent::Cancel => self.on_external_change(),
        }
        match (self.start, self.end, self.hover) {
            (Some(_), Some(_), _) => {
                if let Some(Command::AddArc {
                    center,
                    start,
                    angle,
                    normal,
                    ..
                }) = self.bulge().and_then(|b| self.command(b).ok())
                    && let Ok(points) = arc_points(
                        DVec3::from(center),
                        DVec3::from(start),
                        angle,
                        normal.map(DVec3::from),
                        self.segments,
                    )
                {
                    out.preview = points.windows(2).map(|w| [w[0], w[1]]).collect();
                } else if let (Some((s, _)), Some(e)) = (self.start, self.end) {
                    out.preview = vec![[s, e]];
                }
            }
            (Some((s, _)), None, Some(h)) => out.preview = vec![[s, h]],
            _ => {}
        }
        out
    }

    fn on_external_change(&mut self) {
        self.start = None;
        self.end = None;
        self.hover = None;
    }
}
```
