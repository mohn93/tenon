# M9c Lights Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A material can glow (`emission` 0 to 10 on `add_material` / `change_material`, saved in `.skr` schema 8); glowing faces are drawn unshaded and every placement of a mesh whose own faces glow lights its surroundings as one point light; a `day` / `night` lighting mode (`set_lighting`, `lighting` on `render_view`, Camera > Night lighting, saved with the camera); glTF and OBJ exports carry the glow.

**Architecture:**
- Kernel: `Material.emission` (`MAX_EMISSION` = 10), checked like the opacity; `Scene::add_material_from(Material)` and `Scene::change_material_with(id, MaterialEdit)` take every part at once (the older helpers forward to them), so each command stays one undo step. `MaterialData.emission` is written only when above 0.
- Session: `emission` on the two commands; the `materials` query reports it. `session::Lighting { Day, Night }` lives in `Document.lighting` (beside the camera, not in `Camera`); `set_lighting` is a view command like `set_projection`; the `camera` query reports `lighting`; `.skr` stores it in the camera object when it is night. Schema 8 when a material glows or the view is lit by night. `export.rs` writes `emissiveFactor` (and `KHR_materials_emissive_strength`) and `Ke`.
- Render: `lights.rs` (`Light`, `Glow`, `strongest`, `MAX_LIGHTS` = 128). `scene_base` works out each mesh's glow once per inherited material while it walks the placements and lists a light per placement (`SceneBase.lights`). Face vertices gain `glow: [f32; 2]`. A second uniform buffer (binding 3) holds the mode (ambient, headlight, night flag), the background and the 128 strongest lights at the eye, rewritten each frame; the fragment shader adds each light by Lambert's cosine with a smooth falloff and shows glowing sides unshaded. `Renderer::set_lighting`; `Snapshotter::capture` and `api::Host::render_view` take a `Lighting`.
- App: Camera > Night lighting checkbox, a Glow slider in the Materials list, `Editor::set_lighting` and `set_material_emission`.

**Tech Stack:** Rust 2024; wgpu 30, egui 0.36. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-10-tenon-design.md` (Milestones, "Post-v1 milestones", M9c).

## Spec notes (rulings made in this plan)

- **Emission.** An `f32` from 0 to 10 (`kernel::MAX_EMISSION`); anything else (negative, over 10, not finite) is `invalid_input` naming emission, and nothing changes. `add_material` without `emission` makes a material that does not glow; `change_material` without it keeps it. The `materials` query always reports `emission` (0 when it does not glow). Undo restores it with the rest of the material.
- **Kernel API.** `Scene::add_material_from(Material)` checks every part (name, opacity, texture, emission); `Scene::change_material_with(id, MaterialEdit { name, color, opacity, texture, emission })` changes the parts given. `add_material_with_texture` and `change_material_with_texture` forward to them, so existing callers are unchanged.
- **Files.** `MaterialData.emission` is written only when above 0. The camera object gains `"lighting": "night"`, written only at night. `schema_version` is 8 (`SCHEMA_VERSION`) when a material glows or the view is lit by night, else 7 (`TEXTURED_SCHEMA_VERSION`, new) when a material has a texture, else 6, else 5: files without glow and lit by day are written exactly as before. Older files open without glow and lit by day; `new` starts by day; `open` takes the file's lighting.
- **Lighting mode.** `session::Lighting { Day, Night }` in `Document.lighting`, not a field of `Camera` (31 `Camera` literals and every tool camera would carry it for nothing). `set_lighting {mode}` is a view command: `Command::is_camera` is true for it, so it is not an undo step, does not change the revision or mark the model modified, and a failed atomic batch puts it back. The `camera` query reports `lighting`.
- **Which sides glow.** A face side glows when its material (its own, or the nearest painted instance's, as for color) has an emission above 0. A glowing side is drawn unshaded at its color, or its texture when it has one; the selection tint and the opacity still apply. For lights, a face glows with its stronger side's emission and color (the front's on a tie).
- **Which placements give light.** "Each placed instance (and the open context's loose geometry)" is ruled as: each placement of a mesh whose own faces glow is one light. The root's loose faces give one light; every group or component gives one wherever it is placed, at any depth, from its own faces only; groups that only hold glowing instances give none of their own. So a lamp component inside furniture inside a house lights from each placed house. Lights do not depend on the open context (opening an instance for editing does not move them). A painted instance can make its definition's unpainted faces glow, so a mesh's glow is worked out once per (mesh, inherited material) while `scene_base` walks the placements, and the light list is rebuilt whenever the scene base is (`Renderer::set_model`). When no material glows, nothing is looked for.
- **A light.** Position: the area-weighted center of the glowing triangles, placed. Color: the glowing sides' colors (sRGB, as the renderer shades; a textured material's color is its image's average) weighted by emission times area. Strength `S`: emission times area in square meters, summed, times `|det|^(2/3)` of a scaling placement. Range: `6 * sqrt(S)` meters (`LIGHT_REACH`), so a 0.6 x 0.6 m panel at emission 6 reaches 8.8 m and a 0.07 m² lamp disc at 10 reaches 5 m. A surface at distance `d` facing the light at angle `a` takes `color * (1 - (d/r)^2)^2 / (1 + (4d/r)^2) * max(cos a, 0)`, times its own color, using the M9a smooth normals; no shadows. Lights add in the same sRGB space as the existing shading.
- **128 strongest.** Each frame the renderer keeps the 128 lights with the largest `S / (1 + d^2)`, `d` the eye's distance to the light (all of them with 128 or fewer), and writes them to a uniform buffer (binding 3; 16 + 16 + 128 x 32 bytes).
- **Day and night.** Day: ambient 0.6 and headlight 0.4 as before, plus the lights (a scene without lights renders exactly as before; every existing golden image still matches). Night: ambient 0.08, headlight 0.12, background `[0.05, 0.06, 0.09]` (`render::grid::NIGHT_BACKGROUND`).
- **Lines at night.** Unselected model edges (faded ones and the open instance's box too), the grid and the axes are mixed 80% toward the night background in the vertex shaders, so they read as quiet outlines instead of bright lines on the dark; black edges stay dark outlines that show against lit surfaces. Selected edges, guides and tool previews keep their colors.
- **render_view.** An optional top-level `lighting` (`day` or `night`) beside `camera`, defaulting to the document's; it never changes the document. `api::Host::render_view` and `render::Snapshotter::capture` take a `Lighting`.
- **Window.** The spec's "View > Night lighting" is a Night lighting checkbox in the Camera menu (the window's view menu; a further top-level menu would break the toolbar fitting a 1280-point window, see M7a). The Materials list gains a Glow slider (0 to 10, steps of 0.1, one change per drag) under Opacity so a window user can make a material glow; `UiAction::SetMaterialEmission` carries tenths so `UiAction` stays `Eq`. A lighting change from the API repaints the window.
- **Export.** glTF: a glowing material gets `emissiveFactor` = its linear color times `min(emission, 1)` (white times that, and `emissiveTexture` = its `baseColorTexture`, when textured); an emission above 1 adds `"extensions": {"KHR_materials_emissive_strength": {"emissiveStrength": e}}` and `extensionsUsed`. OBJ: `Ke` = linear color times emission, and `map_Ke` naming the same image when textured. STL is unchanged; back-side materials are still not exported.
- **Vertex format.** `BaseFaceVertex` and `FaceVertex` gain `glow: [f32; 2]` (1 on a glowing front / back side): 88 bytes a corner (80 before), attribute location 8.

//! Glowing materials: emission set when adding or changing a material, checked, undone and
//! kept in plain data.

use kernel::{KernelError, MAX_EMISSION, Material, MaterialEdit, Scene, SceneData};

const WHITE: [u8; 3] = [255, 250, 240];

fn lamp(emission: f32) -> Material {
    Material {
        name: "Lamp".into(),
        color: WHITE,
        opacity: 1.0,
        texture: None,
        emission,
    }
}

#[test]
fn materials_glow_from_zero_to_the_maximum_as_exact_undo_steps() {
    let mut s = Scene::new();
    let (plain, _) = s.add_material("Plain", WHITE).unwrap();
    assert_eq!(s.material(plain).unwrap().emission, 0.0);
    assert!(!s.material(plain).unwrap().glows());

    let empty = s.clone();
    let (id, added) = s.add_material_from(lamp(4.0)).unwrap();
    assert_eq!(s.material(id).unwrap().emission, 4.0);
    assert!(s.material(id).unwrap().glows());
    assert_eq!(added.summary().materials, vec![id]);

    let before = s.clone();
    let edit = MaterialEdit {
        emission: Some(MAX_EMISSION),
        ..MaterialEdit::default()
    };
    let changed = s.change_material_with(id, edit.clone()).unwrap();
    assert_eq!(s.material(id).unwrap().emission, MAX_EMISSION);
    assert_eq!(changed.summary().materials, vec![id]);
    // The same emission again changes nothing.
    assert!(s.change_material_with(id, edit).unwrap().is_empty());
    let mut undone = s.clone();
    undone.apply(&changed.inverse());
    assert_eq!(undone, before);
    // Other parts keep the emission.
    s.change_material(id, Some("Bright lamp"), None, None)
        .unwrap();
    assert_eq!(s.material(id).unwrap().emission, MAX_EMISSION);
    s = before;
    s.apply(&added.inverse());
    assert_eq!(s, empty);
}

#[test]
fn emission_outside_zero_to_the_maximum_is_refused_and_changes_nothing() {
    let mut s = Scene::new();
    let (id, _) = s.add_material_from(lamp(1.0)).unwrap();
    let before = s.clone();
    for bad in [-0.5, MAX_EMISSION + 0.01, f32::NAN, f32::INFINITY] {
        let other = Material {
            name: "Other".into(),
            ..lamp(bad)
        };
        let err = s.add_material_from(other).unwrap_err();
        assert!(
            matches!(&err, KernelError::MaterialEmission(m) if m.contains("emission")),
            "{bad}: {err:?}"
        );
        let edit = MaterialEdit {
            emission: Some(bad),
            ..MaterialEdit::default()
        };
        assert!(matches!(
            s.change_material_with(id, edit),
            Err(KernelError::MaterialEmission(_))
        ));
    }
    assert_eq!(s, before);
}

#[test]
fn emission_is_kept_in_plain_data_and_absent_when_zero() {
    let mut s = Scene::new();
    s.add_material("Plain", WHITE).unwrap();
    s.add_material_from(lamp(2.5)).unwrap();
    let data = s.to_data();
    let json = serde_json::to_string(&data).unwrap();
    // Only the glowing material writes it, so files without glow read as before.
    assert_eq!(json.matches("emission").count(), 1, "{json}");
    let back: SceneData = serde_json::from_str(&json).unwrap();
    assert_eq!(Scene::from_data(&back).unwrap(), s);

    let mut bad = data.clone();
    bad.materials[1].emission = 11.0;
    assert!(Scene::from_data(&bad).unwrap_err().contains("emission"));
}

//! Glowing materials and the lighting mode, driven through JSON commands and queries.

use std::path::PathBuf;

use glam::DVec2;
use serde_json::{Value, json};
use session::{Command, Document, ErrorKind, Query};

fn doc() -> Document {
    Document::new(DVec2::new(800.0, 600.0))
}

fn run(d: &mut Document, v: Value) -> Result<Value, (ErrorKind, String)> {
    let cmd: Command = serde_json::from_value(v).expect("valid command json");
    d.execute(cmd)
        .map(|o| serde_json::to_value(o).unwrap())
        .map_err(|e| (e.kind, e.message))
}

fn ask(d: &Document, q: Value) -> Value {
    let q: Query = serde_json::from_value(q).unwrap();
    serde_json::to_value(d.query(&q).unwrap()).unwrap()
}

fn materials(d: &Document) -> Vec<Value> {
    ask(d, json!({"type": "materials"}))["materials"]
        .as_array()
        .unwrap()
        .clone()
}

/// A fresh path in the test scratch directory.
fn scratch(name: &str) -> PathBuf {
    // The process id keeps concurrent test runs (sharing a target directory) apart.
    let dir = PathBuf::from(env!("CARGO_TARGET_TMPDIR"))
        .join(format!("session-lights-{}", std::process::id()));
    std::fs::create_dir_all(&dir).unwrap();
    let path = dir.join(name);
    let _ = std::fs::remove_file(&path);
    path
}

    let mut zip = zip::ZipArchive::new(std::fs::File::open(path).unwrap()).unwrap();
    serde_json::from_reader(zip.by_name("document.json").unwrap()).unwrap()
}

//! Point lights from glowing faces.
//!
//! Each placement of a mesh whose own faces glow (the root once, every instance wherever it is
//! placed, at any depth) is one light: at the area-weighted center of those faces, colored like
//! them, as strong as their emission times their area. Faces of nested instances belong to the
//! instances' own lights, so a lamp deep inside a house still gives its own. What a mesh gives
//! is worked out once per mesh and inherited material (see `Glow`), however often it is placed.

use glam::{DAffine3, DVec3};

/// The most lights the renderer uses at once: the strongest at the camera (see `strongest`).
pub const MAX_LIGHTS: usize = 128;

/// How far a light of strength 1 (1 m² glowing at emission 1) reaches, in meters; the reach
/// grows with the square root of the strength.
pub const LIGHT_REACH: f64 = 6.0;

/// A point light in root coordinates.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Light {
    pub position: DVec3,
    /// sRGB, 0 to 1: the glowing faces' colors, weighted by emission and area.
    pub color: [f32; 3],
    /// The faces' emission times their area in square meters, summed.
    pub strength: f64,
}

impl Light {
    /// How far the light reaches, in meters: its light falls to zero there.
    pub fn range(&self) -> f64 {
        LIGHT_REACH * self.strength.sqrt()
    }
}

/// What a mesh's own glowing faces give, in the mesh's coordinates.
#[derive(Clone, Copy, Debug, Default, PartialEq)]
pub(crate) struct Glow {
    /// Sums over the glowing faces: area times center, area, emission times area times color,
    /// emission times area.
    weighted_center: DVec3,
    area: f64,
    weighted_color: DVec3,
    strength: f64,
}

impl Glow {
    /// Adds a triangle glowing at `emission` in `color` (sRGB, 0 to 1).
    pub(crate) fn add_triangle(&mut self, [a, b, c]: [DVec3; 3], emission: f32, color: [f32; 3]) {
        let area = 0.5 * (b - a).cross(c - a).length();
        if emission <= 0.0 || area <= 0.0 {
            return;
        }
        let strength = f64::from(emission) * area;
        self.weighted_center += area * (a + b + c) / 3.0;
        self.area += area;
        self.weighted_color += strength * DVec3::from(color.map(f64::from));
        self.strength += strength;
    }

    /// The light this glow gives placed by `t` (None when nothing glows). The strength grows
    /// with the area a scaling placement gives the faces.
    pub(crate) fn placed(&self, t: DAffine3) -> Option<Light> {
        if self.strength <= 0.0 {
            return None;
        }
        let scale = t.matrix3.determinant().abs().powf(2.0 / 3.0);
        Some(Light {
            position: t.transform_point3(self.weighted_center / self.area),
            color: (self.weighted_color / self.strength).as_vec3().to_array(),
            strength: self.strength * scale,
        })
    }
}

/// At most `n` of `lights`, the strongest as seen from `eye`: by strength over (1 + d²), d being
/// the light's distance from the eye. With `n` or fewer lights, all of them, in order.
pub fn strongest(lights: &[Light], eye: DVec3, n: usize) -> Vec<Light> {
    if lights.len() <= n {
        return lights.to_vec();
    }
    let score = |l: &Light| l.strength / (1.0 + l.position.distance_squared(eye));
    let mut ranked: Vec<&Light> = lights.iter().collect();
    ranked.sort_by(|a, b| score(b).total_cmp(&score(a)));
    ranked.into_iter().take(n).copied().collect()
}
