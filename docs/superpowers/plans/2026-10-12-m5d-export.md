# M5d Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The model can be exported as OBJ, STL or glTF (`.glb` or `.gltf`), by agents with an `export` command and in the window from File > Export.

**Architecture:**
- **kernel:** `Scene::triangles()` lists every face of the scene as triangles in root coordinates. It covers the root's faces and, placed by their transforms, every instance's faces at any depth, each triangle wound around its face's normal (`triangles.rs`).
- **session:**
  - `export.rs` turns triangles into OBJ text, binary STL, or glTF 2.0 (binary GLB, or JSON with an embedded base64 buffer).
  - `Command::Export { path, format }` takes the format from the command, or from the path's extension.
  - The file is written with the same safe replace as `.skr` saves (`file::replace_file`, split out of `file::write`).
- **app:** File > Export... (Shift+Cmd+E) opens a save dialog with one filter per format. The editor's `export_file` runs the command and reports the result in the status bar.
- **docs:** `agent-api.md` gets an Export section; the spec's M5d line is updated.

**Tech Stack:** Rust 2024. No new dependencies: `base64 = "=0.23.1"`, already a workspace dependency used by the api crate, becomes a session dependency for the embedded glTF buffer.

## Spec notes (rulings made in this plan)

- **What is exported.** Every face of the whole model, as triangles in root coordinates, whatever instance is open:
  - a component placed twice is written twice;
  - edges without faces are not exported;
  - each triangle is wound counter-clockwise around its face's normal (its front).

  Materials come in M7b; until then there is one untextured mesh.
- **Axes and units.** Units are meters. OBJ and glTF are Y-up, which glTF requires and most OBJ readers expect: a model point (x, y, z) is written as (x, z, -y). STL keeps the model's Z-up, as 3D-printing tools expect.
- **OBJ:**
  - a comment header and one object `o model`;
  - positions and normals are shared (deduplicated by exact value);
  - faces are triangles, `f v//n v//n v//n`.
- **STL:** binary; the 80-byte header begins "sketchup-alt export, meters", then one 50-byte record per triangle (normal, three corners as f32, zero attribute).
- **glTF:**
  - one node, one mesh, one primitive of non-indexed triangles with flat `POSITION` and `NORMAL` accessors (f32 VEC3);
  - the position accessor carries `min` and `max`, computed on the stored f32 values as glTF requires;
  - `.glb` has a JSON chunk padded with spaces and a BIN chunk padded with zeros;
  - `.gltf` is pretty JSON with the buffer as a `data:application/octet-stream;base64,` URI.
- **Format choice.** `format` (`obj`, `stl`, `glb`, `gltf`) defaults to the path's extension, in any case. Any other extension without `format`, and a model with no faces, are `invalid_input`. Write failures are the error kind `file`.
- **Safe writes.** `file::write` now builds the zip in memory and calls a shared `replace_file(path, bytes)` (write `.partial`, fsync, rename, best-effort fsync of the directory). Saves and exports go through it. The on-disk result of a save is unchanged.
- **Atomic batches.** `export` is not allowed in them, like `save`.
- **Window.** File > Export... (Shift+Cmd+E) opens a save dialog with filters OBJ, STL, glTF binary and glTF, proposing `<model name>.obj`. The extension the user picks decides the format. The status bar says "Exported <path>", or why it failed.

```rust
use glam::DVec3;
use kernel::{DefinitionKind, MeshId, Model, Scene};

fn p(x: f64, y: f64, z: f64) -> DVec3 {
    DVec3::new(x, y, z)
}

fn box_model() -> Model {
    let mut m = Model::new();
    m.add_polygon(&[
        p(0.0, 0.0, 0.0),
        p(1.0, 0.0, 0.0),
        p(1.0, 1.0, 0.0),
        p(0.0, 1.0, 0.0),
    ])
    .unwrap();
    let base = m.faces().next().unwrap().0;
    m.push_pull(base, 1.0).unwrap();
    m
}

#[test]
fn a_box_gives_twelve_triangles_facing_out() {
    let s = Scene::from_root(box_model());
    let tris = s.triangles();
    assert_eq!(tris.len(), 12);
    let centre = p(0.5, 0.5, 0.5);
    for t in &tris {
        let [a, b, c] = t.corners;
        let winding = (b - a).cross(c - a).normalize();
        assert!(
            winding.abs_diff_eq(t.normal, 1e-9),
            "wound around its normal"
        );
        let mid = (a + b + c) / 3.0;
        assert!((mid - centre).dot(t.normal) > 0.0, "faces out of the box");
    }
}
```

```rust
//! Every face of a scene as triangles in root coordinates, for export.

use glam::{DAffine3, DVec3};

use crate::scene::{MeshId, Scene};

/// One triangle of a face, wound counter-clockwise around `normal` (the face's front).
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Triangle {
    pub corners: [DVec3; 3],
    pub normal: DVec3,
}

impl Scene {
    /// Every face the scene shows, as triangles in root coordinates: the root's faces and,
    /// placed by their transforms, the faces of every instance at any depth. A component
    /// placed twice gives its faces twice. Edges without faces give nothing. The order is
    /// fixed: faces by id, then instances by id, depth first.
    pub fn triangles(&self) -> Vec<Triangle> {
        let mut out = Vec::new();
        self.collect_triangles(MeshId::Root, DAffine3::IDENTITY, &mut out);
        out
    }

    fn collect_triangles(&self, id: MeshId, place: DAffine3, out: &mut Vec<Triangle>) {
        let Some(model) = self.mesh(id) else { return };
        for (fid, face) in model.faces() {
            let normal = place.transform_vector3(face.normal).normalize();
            for tri in model.triangulate(fid).unwrap_or_default() {
                out.push(Triangle {
                    corners: tri.map(|p| place.transform_point3(p)),
                    normal,
                });
            }
        }
        for (_, instance) in model.instances() {
            self.collect_triangles(
                MeshId::Definition(instance.definition),
                place * instance.transform,
                out,
            );
        }
    }
}
```

```rust
use std::path::PathBuf;

use glam::DVec2;
use serde_json::{Value, json};
use session::{Command, Document, ErrorKind, Query};

    Document::new(DVec2::new(800.0, 600.0))

fn run(d: &mut Document, v: Value) -> Result<Value, (ErrorKind, String)> {
    let cmd: Command = serde_json::from_value(v).expect("valid command json");
    d.execute(cmd)
        .map(|o| serde_json::to_value(o).unwrap())
        .map_err(|e| (e.kind, e.message))
}

fn ask(d: &Document, q: Value) -> Value {
    let q: Query = serde_json::from_value(q).unwrap();
    serde_json::to_value(d.query(&q).unwrap()).unwrap()
}
```

```rust
//! Exporting the model's faces as triangles: OBJ, STL, and glTF (binary `.glb` or `.gltf`
//! with its buffer embedded). Units are meters. OBJ and glTF are Y-up (x, z, -y); STL keeps
//! the model's Z-up coordinates.

use std::collections::HashMap;
use std::fmt::Write as _;
use std::path::Path;

use base64::Engine;
use glam::DVec3;
use kernel::Triangle;
use schemars::JsonSchema;
use serde::{Deserialize, Serialize};
use serde_json::json;

/// An export file format.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize, JsonSchema)]
#[serde(rename_all = "snake_case")]
pub enum ExportFormat {
    /// Wavefront OBJ (text).
    Obj,
    /// Binary STL.
    Stl,
    /// Binary glTF 2.0.
    Glb,
    /// glTF 2.0 JSON with the buffer embedded as base64.
    Gltf,
}

impl ExportFormat {
    /// The format a file name's extension asks for (`.obj`, `.stl`, `.glb`, `.gltf`, any case).
    pub fn from_path(path: &Path) -> Option<Self> {
        let ext = path.extension()?.to_str()?.to_ascii_lowercase();
        Some(match ext.as_str() {
            "obj" => ExportFormat::Obj,
            "stl" => ExportFormat::Stl,
            "glb" => ExportFormat::Glb,
            "gltf" => ExportFormat::Gltf,
            _ => return None,
        })
    }
}

/// The bytes of `triangles` in `format`.
pub(crate) fn encode(triangles: &[Triangle], format: ExportFormat) -> Vec<u8> {
    match format {
        ExportFormat::Obj => obj(triangles).into_bytes(),
        ExportFormat::Stl => stl(triangles),
        ExportFormat::Glb => glb(triangles),
        ExportFormat::Gltf => gltf(triangles).into_bytes(),
    }
}

/// Z-up model coordinates to Y-up.
fn y_up(p: DVec3) -> DVec3 {
    DVec3::new(p.x, p.z, -p.y)
}

/// OBJ with shared positions and normals; faces are triangles.
fn obj(triangles: &[Triangle]) -> String {
    let mut out = String::from("# sketchup-alt export: meters, Y up\no model\n");
    let mut positions: HashMap<[u64; 3], usize> = HashMap::new();
    let mut normals: HashMap<[u64; 3], usize> = HashMap::new();
    let mut faces = String::new();
    let key = |p: DVec3| p.to_array().map(|c| (c + 0.0).to_bits());
    for t in triangles {
        let n = y_up(t.normal);
        let next = normals.len() + 1;
        let ni = *normals.entry(key(n)).or_insert_with(|| {
            let _ = writeln!(out, "vn {} {} {}", n.x, n.y, n.z);
            next
        });
        let mut ids = [0; 3];
        for (k, c) in t.corners.iter().enumerate() {
            let p = y_up(*c);
            let next = positions.len() + 1;
            ids[k] = *positions.entry(key(p)).or_insert_with(|| {
                let _ = writeln!(out, "v {} {} {}", p.x, p.y, p.z);
                next
            });
        }
        let _ = writeln!(
            faces,
            "f {}//{ni} {}//{ni} {}//{ni}",
            ids[0], ids[1], ids[2]
        );
    }
    out.push_str(&faces);
    out
}

/// Binary STL: an 80-byte header, the triangle count, then per triangle its normal, its three
/// corners (f32, little-endian) and a zero attribute word.
fn stl(triangles: &[Triangle]) -> Vec<u8> {
    let mut out = Vec::with_capacity(84 + 50 * triangles.len());
    let mut header = [0u8; 80];
    let title = b"sketchup-alt export, meters";
    header[..title.len()].copy_from_slice(title);
    out.extend_from_slice(&header);
    out.extend_from_slice(&(triangles.len() as u32).to_le_bytes());
    for t in triangles {

/// The vertex buffer (positions then normals, f32 little-endian, Y-up) and the glTF document
/// describing it, its buffer without a `uri` (a `.glb`'s own chunk).
fn gltf_parts(triangles: &[Triangle]) -> (Vec<u8>, serde_json::Value) {
    let count = triangles.len() * 3;
    let mut buffer = Vec::with_capacity(count * 24);
    let (mut lo, mut hi) = (DVec3::splat(f64::INFINITY), DVec3::splat(f64::NEG_INFINITY));
    for t in triangles {
        for c in t.corners {
            // The bounds must hold the stored f32 values, so round before comparing.
            let p = y_up(c).as_vec3();
            lo = lo.min(p.as_dvec3());
            hi = hi.max(p.as_dvec3());
            for x in p.to_array() {
                buffer.extend_from_slice(&x.to_le_bytes());
            }
        }
    }
    for t in triangles {
        let n = y_up(t.normal);
        for _ in 0..3 {
            for x in n.to_array() {
                buffer.extend_from_slice(&(x as f32).to_le_bytes());
            }
        }
    }
    let half = count * 12;
    let doc = json!({
        "asset": {"version": "2.0", "generator": "sketchup-alt"},
        "scene": 0,
        "scenes": [{"nodes": [0]}],
        "nodes": [{"mesh": 0, "name": "model"}],
        "meshes": [{"primitives": [{"attributes": {"POSITION": 0, "NORMAL": 1}, "mode": 4}]}],
        "buffers": [{"byteLength": buffer.len()}],
        "bufferViews": [
            {"buffer": 0, "byteOffset": 0, "byteLength": half, "target": 34962},
            {"buffer": 0, "byteOffset": half, "byteLength": half, "target": 34962}
        ],
        "accessors": [
            {"bufferView": 0, "componentType": 5126, "count": count, "type": "VEC3",
             "min": lo.to_array().map(|x| x as f32), "max": hi.to_array().map(|x| x as f32)},
            {"bufferView": 1, "componentType": 5126, "count": count, "type": "VEC3"}
        ]
    });
    (buffer, doc)
}

/// Binary glTF: a 12-byte header, a JSON chunk padded with spaces and a BIN chunk padded with
/// zeros, each to a multiple of 4 bytes.
fn glb(triangles: &[Triangle]) -> Vec<u8> {
    let (mut bin, doc) = gltf_parts(triangles);
    let mut json = serde_json::to_vec(&doc).expect("a JSON value serializes");
    while json.len() % 4 != 0 {
        json.push(b' ');
    }
    while bin.len() % 4 != 0 {
        bin.push(0);
    }
    let total = 12 + 8 + json.len() + 8 + bin.len();
    let mut out = Vec::with_capacity(total);
    out.extend_from_slice(b"glTF");
    out.extend_from_slice(&2u32.to_le_bytes());
    out.extend_from_slice(&(total as u32).to_le_bytes());
    out.extend_from_slice(&(json.len() as u32).to_le_bytes());
    out.extend_from_slice(b"JSON");
    out.extend_from_slice(&json);
    out.extend_from_slice(&(bin.len() as u32).to_le_bytes());
    out.extend_from_slice(b"BIN\0");
    out.extend_from_slice(&bin);
    out
}

/// glTF JSON with the buffer embedded as a base64 data URI.
fn gltf(triangles: &[Triangle]) -> String {
    let (bytes, mut doc) = gltf_parts(triangles);
    doc["buffers"][0]["uri"] = json!(format!(
        "data:application/octet-stream;base64,{}",
        base64::engine::general_purpose::STANDARD.encode(&bytes)
    ));
    serde_json::to_string_pretty(&doc).expect("a JSON value serializes")
}
```
