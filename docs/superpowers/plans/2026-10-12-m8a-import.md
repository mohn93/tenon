# M8a Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** OBJ and STL files can be imported, by agents (`import`) and in the window (File > Import..., Cmd+I), as a group, a component or into the open context, as one undo step; export then import round-trips.

**Architecture:**
- Two layers: the kernel builds faces from indexed polygons (`Scene::import_mesh`, no file knowledge, no sticky geometry, O(n) with hash maps); the session reads files (`session::import`: OBJ, MTL, STL readers returning file-space `ReadMesh`) and turns a `Command::Import` into a `SceneChange` (`document/import.rs`: axes, scale, limits, materials, placement, selection, report).
- `import` is an editing command routed through `Document::edit`, so it is one undo step, joins atomic batches and rolls back with them; materials it adds are in the same change.
- `as: context` reuses `Scene::explode` (the M5a path) on the freshly built group, so merging with existing geometry follows the existing sticky rules; capped at 2,000 faces because that path is quadratic.
- The outcome report is carried by `Document::import_report` from `import_changes` to the outcome in `execute` and in atomic batches; `Outcome` gains an optional `import`, and the API's `execute` result now serializes the whole outcome plus `revision`.
- Axis conventions mirror the exporter (`UpAxis::Y.to_model` is the inverse of `export::y_up`); MTL colors are converted back from linear with the exact inverse of `export::linear`.
- The window adds one menu item and one shortcut; everything goes through the command (the interface-only rule holds).
- No new dependencies (`earcutr` was already a kernel dependency).

**Tech Stack:** Rust 2024; no dependency changes.

**Spec:** `docs/superpowers/specs/2026-10-10-tenon-design.md`: import (section 2), commands (section 5), the milestone list (Task 3 splits M8 into M8a-d and adds the M8a line).

## Spec notes (rulings made in this plan)

- **One command**: `import {path, format?, as?, scale?, up?, merge_coplanar?}`. `format` is `obj` or `stl`, defaulting to the path's extension (any case); another extension without `format` is `invalid_input` ("give a format, or a path ending in .obj or .stl"); a `.skr` path is `invalid_input` ("use open, not import"). The JSON field is `as` (Rust field `place: ImportAs`, `#[serde(default, rename = "as")]`).
- **Placement** (`as`): `group` (default) or `component`, a new definition named after the file stem (blank stem: "Import"), placed by one instance with an identity transform in the open context (file origin at the context origin) and selected; `context` builds the same group and explodes it with `Scene::explode`, so the faces merge with what they touch (sticky drawing); what comes out is selected and the group's definition is pruned. Always one undo step; `import` goes through `Document::edit`, so it is allowed in atomic batches (unlike new/open/save/export).
- **Context limit**: sticky drawing is quadratic (measured in debug: 800 polygons 1.3 s, 3,200 polygons 20 s), so `as: context` refuses a file making more than `MAX_CONTEXT_IMPORT_FACES` = 2,000 faces with `invalid_input` ("import it as a group or component"), checked after building, rolled back.
- **Units and axes**: file units are meters times `scale` (default 1; must be positive and finite, else `invalid_input`). `up` is `y` or `z`, default `y` for OBJ and `z` for STL, matching the exporter, so export then import round-trips: a Y-up file's (x, y, z) becomes (x, -z, y) (the inverse of `export::y_up`). No units picker in the window (deferred).
- **Building faces (kernel, not sticky)**: `Scene::import_mesh` builds a new definition straight from polygons with recorded primitives (`insert_vertex/insert_edge/insert_face`), O(n) with hash maps, never `add_edge`: points closer than `LENGTH_TOL` (1e-6 m, after scaling) weld (grid of `LENGTH_TOL` cells, the same scheme as `Model::validate`, so kept vertices stay at least `LENGTH_TOL` apart); consecutive repeated corners collapse; a polygon with fewer than 3 distinct corners, a repeated corner, height under `LENGTH_TOL` (2 x area / longest side), an out-of-range corner index, or the same corner set as an earlier polygon (either winding) makes no face and counts as `skipped`; a flat (within `LENGTH_TOL / 2` of its plane), simple polygon is one face with its vector-area normal; a bent or self-crossing one becomes earcut triangles (each oriented to the polygon's normal). Nothing is split at crossings or T-junctions and no face is added the file lacks (no auto faces on open loops).
- **Front side**: each polygon's front is the side its corners turn counter-clockwise around; STL stored normals are ignored.
- **Coplanar merge** (`merge_coplanar`, default true, SketchUp's "merge coplanar faces"): faces sharing an edge that exactly two faces use, traversing it in opposite directions, with normals facing the same way, every corner of each within `LENGTH_TOL / 2` of the other's plane, and the same material, are joined (union-find). A joined set's outline is traced with the kernel's `PlaneGraph::regions` over its boundary edges (holes kept; regions not covered by the set's faces, such as the inside of a hole, are dropped); a set whose kept regions' area differs from the faces' total (1e-9 relative) or has a corner off the plane stays unmerged. Interior edges and vertices used only by them are not created. Collinear vertices along a merged outline stay.
- **OBJ reading**: `v` (extra numbers ignored), `f` with `v`, `v/vt`, `v/vt/vn`, `v//vn` corners, negative indices relative to positions so far, index 0 or out of range is an error naming the line, `usemtl` (rest of the line; empty means none), `mtllib` (whitespace-separated names, relative to the OBJ's folder), `#` comments, `\` line continuation; `vt`, `vn`, `l`, `p`, `g`, `o`, `s` and anything else ignored (not errors). Text read lossily as UTF-8.
- **OBJ materials** (imported, not deferred): a used name equal to a model material's name is that material (the model's color wins); a name only a library defines with `Kd` (linear) becomes a new material with that sRGB color (exact byte round trip with the exporter's 6-decimal linear values, tested for all 256 values); `default` (any case, the exporter's name for unpainted faces) and names neither knows are the default material. Missing, unreadable or over-16 MiB libraries are ignored. Materials go on the front side. New materials are part of the same undo step and are listed in `changes.materials`; an invalid name (over 256 characters) leaves the faces unpainted.
- **STL reading**: binary when the file is exactly 84 + 50 x (header count) bytes (so a binary file whose header starts with "solid" is still binary), else ASCII if it starts with `solid` (`vertex` triples collected until `endloop`, one polygon per loop), else a `file` error "not an STL file". Each triangle has its own three points; the weld joins them. f32 values are widened to f64.
- **Errors and limits**: a file that cannot be read, is over `MAX_IMPORT_BYTES` (128 MiB), has more than `MAX_IMPORT_POLYGONS` (200,000) polygons or `MAX_IMPORT_POINTS` (1,000,000) OBJ positions, has a broken line (message names it), a non-finite number, a position beyond `MAX_COORDINATE` after scaling (refused, not rescaled), or no polygon making a face (`KernelError::NothingToImport`) is `ErrorKind::File` with the path in the message; the model, materials, selection and revision stay as they were (ids may be consumed, as for any failed command).
- **Outcome**: `Outcome` gains `import: Option<ImportReport>` (skipped when None): `instance` and `definition` (absent for `as: context`), `polygons` (read), `faces` (made, after merging), `vertices` (made), `skipped`, `materials` (added). The API's `execute` result becomes the serialized outcome plus `revision` (`{changes, import?, revision}`); `batch` outcomes carry it too (atomic batches included). The report travels through `Document::import_report`, taken when the outcome is built.
- **Window**: File > Import... (Cmd+I; free, plain Cmd without Shift) opens an rfd picker with filters "OBJ or STL", "OBJ", "STL", and imports as a group with the defaults; the status says "Imported chair.obj: 12 faces" (plus "; N polygons skipped") or the command's error message. The tool's operation and typed text are dropped first, as for other selection commands.
- **Spec**: the status amendment line gains "M8 split into M8a-d, M8a import"; the milestone list gains M8a (full scope) and M8b-d (one line each, as the roadmap has them).

```rust
//! Building a mesh straight from polygons read from a file (OBJ, STL): points closer than
//! `LENGTH_TOL` are welded, each polygon becomes a face as it is wound, and neighbouring faces
//! in one plane can merge into one. No sticky geometry: nothing is split at crossings and no
//! face is added that the file does not have.

use std::collections::{BTreeMap, HashMap, HashSet};

use glam::{DAffine3, DVec2, DVec3};

use crate::edit::KernelError;
use crate::geom::{LENGTH_TOL, Plane, point_in_polygon, signed_area2, vector_area};
use crate::ids::{InstanceId, MaterialId, VertexId};
use crate::model::{Face, Instance, Model};
use crate::regions::PlaneGraph;
use crate::scene::{DefinitionKind, MeshId, Scene, SceneChange};

/// A polygon of an imported mesh: its corners as indices into the mesh's points, wound
/// counter-clockwise around its front, and the material of its front side.
#[derive(Clone, Debug, PartialEq)]
pub struct MeshPolygon {
    pub corners: Vec<usize>,
    pub material: Option<MaterialId>,
}

/// What building a mesh from polygons made.
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct MeshReport {
    /// Vertices made: the points faces use, coincident points welded into one.
    pub vertices: usize,
    /// Faces made.
    pub faces: usize,
    /// Polygons that made no face: fewer than three distinct corners after welding, no area,
    /// a corner index out of range, or the same corners as an earlier polygon.
    pub skipped: usize,
}

/// Corners within this distance of a polygon's plane count as on it. Half the kernel's
/// tolerance, so the faces made pass `Model::validate` with room for rounding.
const FLAT_TOL: f64 = 0.5 * LENGTH_TOL;

impl Scene {
    /// Builds a new definition from `points` and `polygons` (see [`build_mesh`]) and places
    /// one instance of it, with an identity transform, in mesh `parent`. With `merge`, faces
    /// that share an edge, lie in one plane, face the same way and have the same material
    /// become one face (interior edges and the vertices only they used go). Fails with
    /// `NotFinite` for a point that is not finite, `MaterialNotFound` for a material the scene
    /// lacks and `NothingToImport` when no polygon makes a face; nothing changes then.
    pub fn import_mesh(
        &mut self,
        parent: MeshId,
        points: &[DVec3],
        polygons: &[MeshPolygon],
        merge: bool,
        kind: DefinitionKind,
        name: &str,
    ) -> Result<(InstanceId, MeshReport, SceneChange), KernelError> {
        if points.iter().any(|p| !p.is_finite()) {
            return Err(KernelError::NotFinite);
        }
        if polygons
            .iter()
            .any(|p| p.material.is_some_and(|m| self.material(m).is_none()))
        {
            return Err(KernelError::MaterialNotFound);
        }
        let built = build_mesh(points, polygons, merge);
        if built.faces.is_empty() {
            return Err(KernelError::NothingToImport);
        }
        let (definition, added) = self.add_definition(name, kind);
        let mut vertices = 0;
        let filled = self.edit(MeshId::Definition(definition), |m| {
            vertices = m.add_built(&built);
            Ok(m.take_changes())
        })?;
        let mut placed = None;
        let left = self.edit(parent, |m| {
            placed = Some(m.insert_instance(Instance::new(definition, DAffine3::IDENTITY)));
            Ok(m.take_changes())
        })?;
        let report = MeshReport {
            vertices,
            faces: built.faces.len(),
            skipped: built.skipped,
        };
        let change = SceneChange::join([SceneChange::from(added), filled, left]);
        Ok((placed.expect("instance placed"), report, change))
    }
}

impl Model {
    /// Inserts the built faces with their vertices and edges; returns how many vertices.
    fn add_built(&mut self, built: &Built) -> usize {
        let mut vertex: HashMap<usize, VertexId> = HashMap::new();
        let mut edges: HashSet<(usize, usize)> = HashSet::new();
        for f in &built.faces {
            let mut loops: Vec<Vec<VertexId>> = Vec::new();
            for l in &f.loops {
                let ids = l
                    .iter()
                    .map(|&p| {
                        *vertex
                            .entry(p)
                            .or_insert_with(|| self.insert_vertex(built.points[p]))
                    })
                    .collect();
                for i in 0..l.len() {
                    let (a, b) = (l[i], l[(i + 1) % l.len()]);
                    if edges.insert((a.min(b), a.max(b))) {
                        self.insert_edge(vertex[&a], vertex[&b]);
                    }
                }
                loops.push(ids);
            }
            let outer = loops.remove(0);
            let mut face = Face::new(outer, loops, f.normal);
            face.front = f.material;
            self.insert_face(face);
        }
        vertex.len()
    }
}

/// Faces ready to insert: corner indices into `points` (welded positions).
#[derive(Clone, Debug, Default, PartialEq)]
pub(crate) struct Built {
    pub points: Vec<DVec3>,
    pub faces: Vec<BuiltFace>,
    pub skipped: usize,
}

#[derive(Clone, Debug, PartialEq)]
pub(crate) struct BuiltFace {
    /// The outer loop (counter-clockwise around `normal`), then holes (clockwise).
    pub loops: Vec<Vec<usize>>,
    pub normal: DVec3,
    pub material: Option<MaterialId>,
}

/// Welds the points, turns each polygon into a face (a polygon that is not flat, or whose
/// sides cross, into triangles), drops the ones that make none, and with `merge` joins
/// neighbouring faces in one plane.
pub(crate) fn build_mesh(points: &[DVec3], polygons: &[MeshPolygon], merge: bool) -> Built {
    let (welded, map) = weld(points);
    let mut faces: Vec<BuiltFace> = Vec::new();
    let mut seen: HashSet<Vec<usize>> = HashSet::new();
    let mut skipped = 0;
    for polygon in polygons {
        let Some(corners) = polygon
            .corners
            .iter()
            .map(|&c| map.get(c).copied())
            .collect::<Option<Vec<usize>>>()
        else {
            skipped += 1;
            continue;
        };
        let before = faces.len();
        for (l, normal) in pieces(&welded, corners) {
            let mut key = l.clone();
            key.sort_unstable();
            if seen.insert(key) {
                faces.push(BuiltFace {
                    loops: vec![l],
                    normal,
                    material: polygon.material,
                });
            }
        }
        if faces.len() == before {
            skipped += 1;
        }
    }
    if merge {
        faces = merge_coplanar(&welded, faces);
    }
    Built {
        points: welded,
        faces,
        skipped,
    }
}

/// Positions with points closer than `LENGTH_TOL` to an earlier kept one dropped, and for
/// each point the index of the position it became. Kept positions are at least `LENGTH_TOL`
/// apart: a grid of `LENGTH_TOL` cells finds the near ones.
fn weld(points: &[DVec3]) -> (Vec<DVec3>, Vec<usize>) {
    let cell = |p: DVec3| (p / LENGTH_TOL).floor().to_array().map(|c| c as i64);
    let mut grid: HashMap<[i64; 3], Vec<usize>> = HashMap::new();
    let mut kept: Vec<DVec3> = Vec::new();
    let mut map = Vec::with_capacity(points.len());
    for &p in points {
        let [x, y, z] = cell(p);
        let mut near = None;
        'search: for dx in -1..=1 {
            for dy in -1..=1 {
                for dz in -1..=1 {
                    let key = [
                        x.saturating_add(dx),
                        y.saturating_add(dy),
                        z.saturating_add(dz),
                    ];
                    if let Some(k) = grid
                        .get(&key)
                        .into_iter()
                        .flatten()
                        .find(|k| kept[**k].distance(p) < LENGTH_TOL)
                    {
                        near = Some(*k);
                        break 'search;
                    }
                }
            }
        }
        let k = near.unwrap_or_else(|| {
            kept.push(p);
            grid.entry([x, y, z]).or_default().push(kept.len() - 1);
            kept.len() - 1
        });
        map.push(k);
    }
    (kept, map)
}

/// The faces one polygon makes, as (loop, unit normal): itself when it is flat and simple,
/// else the triangles of its projection; none when it has no area.
fn pieces(points: &[DVec3], mut corners: Vec<usize>) -> Vec<(Vec<usize>, DVec3)> {
    corners.dedup();
    while corners.len() > 1 && corners.first() == corners.last() {
        corners.pop();
    }
    let mut distinct = corners.clone();
    distinct.sort_unstable();
    distinct.dedup();
    if corners.len() < 3 || distinct.len() != corners.len() {
        return Vec::new();
    }
    let pts: Vec<DVec3> = corners.iter().map(|&c| points[c]).collect();
    let Some(normal) = normal_of(&pts) else {
        return Vec::new();
    };
    let flat = pts
        .iter()
        .all(|p| (*p - pts[0]).dot(normal).abs() <= FLAT_TOL);
    let plane = Plane::through(pts[0], normal);
    let flat2: Vec<DVec2> = pts.iter().map(|p| plane.project(*p)).collect();
    if flat && (pts.len() == 3 || is_simple(&flat2)) {
        return vec![(corners, normal)];
    }
    let coords: Vec<f64> = flat2.iter().flat_map(|q| [q.x, q.y]).collect();
    let Ok(indices) = earcutr::earcut(&coords, &[], 2) else {
        return Vec::new();
    };
    indices
        .as_chunks::<3>()
        .0
        .iter()
        .filter_map(|t| {
            let mut tri = vec![corners[t[0]], corners[t[1]], corners[t[2]]];
            let tp: Vec<DVec3> = tri.iter().map(|&c| points[c]).collect();
            let n = normal_of(&tp)?;
            if n.dot(normal) < 0.0 {
                tri.swap(1, 2);
                return Some((tri, -n));
            }
            Some((tri, n))
        })
        .collect()
}

/// The unit normal of a polygon by its vector area, or None when it is narrower than
/// `LENGTH_TOL` (twice its area over its longest side).
fn normal_of(pts: &[DVec3]) -> Option<DVec3> {
    let area = vector_area(pts);
    let longest = (0..pts.len())
        .map(|i| pts[i].distance(pts[(i + 1) % pts.len()]))
        .fold(0.0, f64::max);
    (2.0 * area.length() > LENGTH_TOL * longest).then(|| area.normalize())
}

/// True when no two sides of the closed 2D polygon cross or touch, apart from neighbours
/// meeting at their shared corner.
fn is_simple(poly: &[DVec2]) -> bool {
    let n = poly.len();
    for i in 0..n {
        for j in i + 1..n {
            if j == i + 1 || (i == 0 && j == n - 1) {
                continue;
            }
            let (a, b) = (poly[i], poly[(i + 1) % n]);
            let (c, d) = (poly[j], poly[(j + 1) % n]);
            if segments_meet(a, b, c, d) {
                return false;
            }
        }
    }
    true
}

/// True when closed 2D segments a-b and c-d share a point.
fn segments_meet(a: DVec2, b: DVec2, c: DVec2, d: DVec2) -> bool {
    let side = |p: DVec2, q: DVec2, r: DVec2| (q - p).perp_dot(r - p);
    let (d1, d2) = (side(c, d, a), side(c, d, b));
    let (d3, d4) = (side(a, b, c), side(a, b, d));
    if ((d1 > 0.0 && d2 < 0.0) || (d1 < 0.0 && d2 > 0.0))
        && ((d3 > 0.0 && d4 < 0.0) || (d3 < 0.0 && d4 > 0.0))
    {
        return true;
    }
    let on = |p: DVec2, q: DVec2, r: DVec2| crate::geom::segment_distance_2d(r, p, q) < LENGTH_TOL;
    on(c, d, a) || on(c, d, b) || on(a, b, c) || on(a, b, d)
}

/// Joins faces that share an edge used by no other face, lie in one plane, face the same way
/// and have the same material. A set of joined faces whose outline cannot be traced back
/// exactly (same area, every corner on the plane) stays as it was.
fn merge_coplanar(points: &[DVec3], faces: Vec<BuiltFace>) -> Vec<BuiltFace> {
    // Each side of each face, keyed by its ends in order: (face, forward).
    let mut users: HashMap<(usize, usize), Vec<(usize, bool)>> = HashMap::new();
    for (i, f) in faces.iter().enumerate() {
        let l = &f.loops[0];
        for k in 0..l.len() {
            let (a, b) = (l[k], l[(k + 1) % l.len()]);
            users
                .entry((a.min(b), a.max(b)))
                .or_default()
                .push((i, a < b));
        }
    }
    let mut parent: Vec<usize> = (0..faces.len()).collect();
    fn root(parent: &mut [usize], mut i: usize) -> usize {
        while parent[i] != i {
            parent[i] = parent[parent[i]];
            i = parent[i];
        }
        i
    }
    let on_plane = |f: &BuiltFace, g: &BuiltFace| {
        let o = points[f.loops[0][0]];
        g.loops[0]
            .iter()
            .all(|&c| (points[c] - o).dot(f.normal).abs() <= FLAT_TOL)
    };
    let mut keys: Vec<&(usize, usize)> = users.keys().collect();
    keys.sort_unstable();
    for key in keys {
        let [(f, df), (g, dg)] = users[key][..] else {
            continue;
        };
        let (ff, gg) = (&faces[f], &faces[g]);
        if df != dg
            && ff.material == gg.material
            && ff.normal.dot(gg.normal) > 0.0
            && on_plane(ff, gg)
            && on_plane(gg, ff)
        {
            let (rf, rg) = (root(&mut parent, f), root(&mut parent, g));
            if rf != rg {
                parent[rg.max(rf)] = rf.min(rg);
            }
        }
    }
    let mut groups: BTreeMap<usize, Vec<usize>> = BTreeMap::new();
    for i in 0..faces.len() {
        let r = root(&mut parent, i);
        groups.entry(r).or_default().push(i);
    }
    let mut out = Vec::new();
    for members in groups.values() {
        if members.len() == 1 {
            out.push(faces[members[0]].clone());
            continue;
        }
        match merged(points, &faces, members, &users) {
            Some(joined) => out.extend(joined),
            None => out.extend(members.iter().map(|&i| faces[i].clone())),
        }
    }
    out
}

/// The faces covering the joined faces `members`, or None when they cannot be traced.
fn merged(
    points: &[DVec3],
    faces: &[BuiltFace],
    members: &[usize],
    users: &HashMap<(usize, usize), Vec<(usize, bool)>>,
) -> Option<Vec<BuiltFace>> {
    let area = |i: usize| {
        let pts: Vec<DVec3> = faces[i].loops[0].iter().map(|&c| points[c]).collect();
        vector_area(&pts).length()
    };
    let largest = *members
        .iter()
        .max_by(|a, b| area(**a).total_cmp(&area(**b)))?;
    let normal = faces[largest].normal;
    let plane = Plane::through(points[faces[largest].loops[0][0]], normal);
    let inside: HashSet<usize> = members.iter().copied().collect();
    // A side is interior when exactly two faces use it and both are members.
    let mut boundary: Vec<[VertexId; 2]> = Vec::new();
    let mut pos: BTreeMap<VertexId, DVec2> = BTreeMap::new();
    let mut done: HashSet<(usize, usize)> = HashSet::new();
    for &i in members {
        let l = &faces[i].loops[0];
        for k in 0..l.len() {
            let (a, b) = (l[k], l[(k + 1) % l.len()]);
            let key = (a.min(b), a.max(b));
            let u = &users[&key];
            if u.len() == 2 && u.iter().all(|(f, _)| inside.contains(f)) {
                continue;
            }
            if done.insert(key) {
                boundary.push([VertexId(a as u64), VertexId(b as u64)]);
                for c in [a, b] {
                    pos.insert(VertexId(c as u64), plane.project(points[c]));
                }
            }
        }
    }
    let graph = PlaneGraph {
        pos,
        edges: boundary,
    };
    let polys: Vec<Vec<DVec2>> = members
        .iter()
        .map(|&i| {
            faces[i].loops[0]
                .iter()
                .map(|&c| plane.project(points[c]))
                .collect()
        })
        .collect();
    let total: f64 = members.iter().map(|&i| area(i)).sum();
    let mut covered = 0.0;
    let mut out = Vec::new();
    for r in graph.regions() {
        let p = graph.interior_point(&r)?;
        if !polys.iter().any(|poly| point_in_polygon(p, poly)) {
            continue;
        }
        covered += signed_area2(&graph.poly(&r.outer)) * 0.5;
        covered += r
            .holes
            .iter()
            .map(|h| signed_area2(&graph.poly(h)) * 0.5)
            .sum::<f64>();
        let index = |l: &Vec<VertexId>| -> Vec<usize> { l.iter().map(|v| v.0 as usize).collect() };
        let mut loops: Vec<Vec<usize>> = std::iter::once(&r.outer)
            .chain(&r.holes)
            .map(index)
            .collect();
        // Regions wind counter-clockwise around the plane's own normal.
        if normal.dot(plane.normal) < 0.0 {
            loops.iter_mut().for_each(|l| l.reverse());
        }
        let o = points[loops[0][0]];
        if loops
            .iter()
            .flatten()
            .any(|&c| (points[c] - o).dot(normal).abs() > FLAT_TOL)
        {
            return None;
        }
        out.push(BuiltFace {
            loops,
            normal,
            material: faces[largest].material,
        });
    }
    ((covered - total).abs() <= 1e-9 * total.max(1.0)).then_some(out)
}
```

```rust
/// Asserts two sets of triangles show the same surface, however it is cut: the same corners
/// (to `tol`) and, for each normal direction, the same area.
fn same_surface(a: &[Triangle], b: &[Triangle], tol: f64) {
    let corners = |tris: &[Triangle]| {
        let mut out: Vec<glam::DVec3> = Vec::new();
        for p in tris.iter().flat_map(|t| t.corners) {
            if !out.iter().any(|q| q.distance(p) < tol) {
                out.push(p);
            }
        }
        out
    };
    let (ca, cb) = (corners(a), corners(b));
    assert_eq!(ca.len(), cb.len());
    assert!(ca.iter().all(|p| cb.iter().any(|q| q.distance(*p) < tol)));
    let areas = |tris: &[Triangle]| {
        let mut out: Vec<(glam::DVec3, f64)> = Vec::new();
        for t in tris {
            let [p, q, r] = t.corners;
            let area = (q - p).cross(r - p).length() / 2.0;
            match out.iter_mut().find(|(n, _)| n.distance(t.normal) < 1e-4) {
                Some((_, s)) => *s += area,
                None => out.push((t.normal, area)),
            }
        }
        out
    };
    let (aa, ab) = (areas(a), areas(b));
    assert_eq!(aa.len(), ab.len());
    for (n, s) in aa {
        let other = ab
            .iter()
            .find(|(m, _)| m.distance(n) < 1e-4)
            .expect("same normals");
        assert!((other.1 - s).abs() < tol, "{n}: {s} vs {}", other.1);
    }
}

fn export_import(name: &str) -> (Document, Document, Value) {

    model(&mut d);
    let path = scratch(name);
    let path = path.to_str().unwrap();

    let mut e = doc();
    let r = run(&mut e, json!({"type": "import", "path": path})).unwrap();
    e.scene().validate().unwrap();
    (d, e, r)
}
```

```rust
/// Reads an OBJ: `v` positions (extra numbers ignored), `f` polygons (corners `v`, `v/vt`,
/// `v/vt/vn` or `v//vn`; negative indices count back from the last position), `usemtl` and
/// `mtllib`; lines may continue with a trailing backslash. Everything else (normals, texture
/// coordinates, lines, groups, smoothing) is ignored.
pub(crate) fn read_obj(bytes: &[u8]) -> Result<ReadMesh, String> {
    let text = String::from_utf8_lossy(bytes);
    let mut mesh = ReadMesh::default();
    let mut material: Option<String> = None;
    let mut pending = String::new();
    let mut start = 0;
    for (n, raw) in text.lines().enumerate() {
        let raw = raw.split('#').next().unwrap_or("");
        if pending.is_empty() {
            start = n + 1;
        }
        if let Some(cont) = raw.trim_end().strip_suffix('\\') {
            pending.push_str(cont);
            pending.push(' ');
            continue;
        }
        pending.push_str(raw);
        let line = std::mem::take(&mut pending);
        let at = |what: String| format!("line {start}: {what}");
        let mut tokens = line.split_whitespace();
        match tokens.next() {
            Some("v") => {
                let mut xyz = [0.0; 3];
                for c in &mut xyz {
                    let t = tokens
                        .next()
                        .ok_or_else(|| at("a position needs x, y and z".into()))?;
                    *c = number(t).map_err(at)?;
                }
                if mesh.points.len() == MAX_IMPORT_POINTS {
                    return Err(format!("more than {MAX_IMPORT_POINTS} positions"));
                }
                mesh.points.push(DVec3::from(xyz));
            }
            Some("f") => {
                let mut corners = Vec::new();
                for t in tokens {
                    let index = t.split('/').next().unwrap_or("");
                    let i: i64 = index
                        .parse()
                        .map_err(|_| at(format!("{t:?} is not a corner index")))?;
                    let count = mesh.points.len() as i64;
                    let resolved = if i > 0 { i - 1 } else { count + i };
                    if i == 0 || !(0..count).contains(&resolved) {
                        return Err(at(format!("corner {i} names no position")));
                    }
                    corners.push(resolved as usize);
                }
                if mesh.polygons.len() == MAX_IMPORT_POLYGONS {
                    return Err(format!("more than {MAX_IMPORT_POLYGONS} polygons"));
                }
                mesh.polygons.push(ReadPolygon {
                    corners,
                    material: material.clone(),
                });
            }
            Some("usemtl") => {
                let name = line.trim_start()["usemtl".len()..].trim();
                material = (!name.is_empty()).then(|| name.to_string());
            }
            Some("mtllib") => mesh.libraries.extend(tokens.map(str::to_string)),
            _ => {}
        }
    }
    Ok(mesh)
}

}

    for line in text.lines() {
        let line = line.split('#').next().unwrap_or("").trim();
        if let Some(name) = line.strip_prefix("newmtl") {
            let name = name.trim();
            current = (!name.is_empty()).then(|| name.to_string());
        } else if let Some(rgb) = line.strip_prefix("Kd ")
            && let Some(name) = &current
        {
            let values: Vec<f64> = rgb
                .split_whitespace()
                .take(3)
                .filter_map(|t| number(t).ok())
                .collect();
            if let [r, g, b] = values[..] {
                out.retain(|(n, _)| n != name);
                out.push((name.clone(), [r, g, b].map(srgb_byte)));
            }
        }
    }
    out
}

/// A linear color component (0 to 1, clamped) as an sRGB byte.
fn srgb_byte(linear: f64) -> u8 {
    let l = linear.clamp(0.0, 1.0);
    let s = if l <= 0.003_130_8 {
        12.92 * l
    } else {
        1.055 * l.powf(1.0 / 2.4) - 0.055
    };
    (s * 255.0).round().clamp(0.0, 255.0) as u8
}

/// Reads an STL: binary when its size is 84 bytes plus 50 per triangle its header counts,
/// else ASCII (`solid ... facet ... outer loop vertex x y z ... endloop ... endsolid`). Each
/// triangle has corners of its own (import welds them); stored normals are ignored, the
/// corner order gives the front.
pub(crate) fn read_stl(bytes: &[u8]) -> Result<ReadMesh, String> {
    let binary_count = (bytes.len() >= 84)
        .then(|| u32::from_le_bytes(bytes[80..84].try_into().expect("4 bytes")) as u64)
        .filter(|n| 84 + 50 * n == bytes.len() as u64);
    let triangles = match binary_count {
        Some(n) => {
            if n as usize > MAX_IMPORT_POLYGONS {
                return Err(format!("more than {MAX_IMPORT_POLYGONS} triangles"));
            }
            let mut out = Vec::with_capacity(n as usize);
            for k in 0..n as usize {
                let record = &bytes[84 + 50 * k..84 + 50 * (k + 1)];
                let value = |i: usize| {
                    let at = 12 + 4 * i;
                    f64::from(f32::from_le_bytes(
                        record[at..at + 4].try_into().expect("4 bytes"),
                    ))
                };
                let corner =
                    |c: usize| DVec3::new(value(3 * c), value(3 * c + 1), value(3 * c + 2));
                let t = vec![corner(0), corner(1), corner(2)];
                if !t.iter().all(|p| p.is_finite()) {
                    return Err(format!(
                        "triangle {} has a number that is not finite",
                        k + 1
                    ));
                }
                out.push(t);
            }
            out
        }
        None => read_ascii_stl(bytes)?,
    };
    let mut mesh = ReadMesh::default();
    for t in triangles {
        let first = mesh.points.len();
        mesh.polygons.push(ReadPolygon {
            corners: (first..first + t.len()).collect(),
            material: None,
        });
        mesh.points.extend(t);
    }
    Ok(mesh)
}

fn read_ascii_stl(bytes: &[u8]) -> Result<Vec<Vec<DVec3>>, String> {
    let text = String::from_utf8_lossy(bytes);
    if !text.trim_start().starts_with("solid") {
        return Err(if bytes.len() >= 84 {
            "not an STL file: binary size does not match its triangle count, and it does not \
             start with \"solid\""
                .into()
        } else {
            "not an STL file".into()
        });
    }
    let mut out = Vec::new();
    let mut corners: Vec<DVec3> = Vec::new();
    let mut tokens = text.split_whitespace();
    while let Some(t) = tokens.next() {
        match t {
            "vertex" => {
                let mut xyz = [0.0; 3];
                for c in &mut xyz {
                    let t = tokens.next().ok_or("a vertex needs x, y and z")?;
                    *c = number(t).map_err(|e| format!("facet {}: {e}", out.len() + 1))?;
                }
                corners.push(DVec3::from(xyz));
            }
            "endloop" => {
                if out.len() == MAX_IMPORT_POLYGONS {
                    return Err(format!("more than {MAX_IMPORT_POLYGONS} triangles"));
                }
                out.push(std::mem::take(&mut corners));
            }
            _ => {}
        }
    }
    Ok(out)
}
```

## Self-review notes

- **Spec coverage:** kernel mesh import (Task 1), the import command and parsers (Task 2), File > Import (Task 3).
- **Deferred** (from the scratch build):

- OBJ `g`/`o` groups as separate groups or components (everything lands in one definition today), `l` lines as edges, texture coordinates and textures, smoothing groups as soft edges, back-side materials.
- A units choice in the window (Import options dialog: units, up axis, merge, as component); the window always imports meters, default up, as a group. A millimeter STL comes in 1000x too big and there is no Scale tool yet.
- Matching OBJ material names against the exporter's sanitized names (`Brick wall` exported as `Brick_wall` comes back as a new material `Brick_wall`).
- Large imports: the kernel's adjacency is still by scanning (`edge_between`, `edges_at`, `find_vertex`), so a 100k-face imported definition imports in seconds (5.5 s for 180k triangles in debug) but later edits inside it, `Model::validate` and sticky operations are slow; an adjacency index is a kernel item for M8c. The `as: context` path is quadratic and capped at 2,000 faces.
- STL winding is taken from corner order only; files whose stored normals disagree with their winding are not fixed (no normal-based flipping or consistent-orientation repair).
- glTF import (the exporter writes glTF; the spec lists only OBJ and STL for import).
- Merging is limited to faces sharing an edge exactly two faces use; T-junctions (a vertex lying on a neighbour's edge) prevent merging and are not split.
