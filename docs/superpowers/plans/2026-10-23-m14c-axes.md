# M14c Component and Axes Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SketchUp's Make Unique, Flip Along (red, green, blue; the drawing axes or a component's own axes) and the Axes tool (move and turn the model's drawing axes, or, inside an open group or component, its own axes, which moves its definition's origin without moving its geometry), with inference, Shift and arrow-key locks, the origin snap, standard views and the axis lines following the current drawing axes. Commands, queries, `tool_input`, `.skr` and the window.

**Architecture:** The model's drawing axes are a rigid frame `Axes { origin, x, y, z }` (orthonormal, right-handed) stored on the kernel `Scene` (default: world), changed by an undoable scene op and saved in `.skr` (schema 15, written only when not world). The *current drawing axes* are the model axes at the root, and the open context's own local frame (identity in local coordinates) inside a group or component. Tools and inference read the current drawing axes from `ToolContext` instead of the fixed `Axis::dir`. Setting the axes inside an open context re-origins its definition: the definition's geometry is transformed by `A^-1` and every instance of it (in every mesh) is right-multiplied by `A`, one undo step, nothing moves in the world. Make Unique deep-copies a definition with the existing private `Scene::duplicate` and repoints the selected instances. Flip Along is the scale path with a factor of -1 in a chosen frame about the selection's center.

**Tech Stack:** Rust 2024, wgpu 30, egui 0.36.2. No new dependencies.

## Spec notes (rulings)

1. **Make Unique:** `make_unique { ids }` (ids default to the selection): selected component instances whose definition has more than one instance (counting every mesh) get a new definition; all selected instances of one definition share one new definition (as SketchUp). The copy is deep for nested groups and shares nested components (as `Scene::duplicate`). Name: the source name without a trailing `#<digits>`, then `#N` with the smallest N >= 2 not used by any definition. Groups and sole instances are left alone. One undo step; outcome `definitions: [new definition ids]` (batch-referable); nothing to do is success with no undo step.
2. **Flip Along:** `flip { ids, axis: "red" | "green" | "blue", frame: "axes" | "own" }`. `axes` (default): mirror the selection about the plane through the center of its box in the current drawing axes, normal to the chosen drawing axis. `own`: only for exactly one selected instance: mirror it about its own center along its definition's own axis (the instance transform's column), placed back where it was. Faces keep facing out (the existing mirror rule); instances may become mirrored (negative determinant). One undo step; outcome `changed`.
3. **Model axes:** `set_axes { origin, x_axis, y_axis }` at the root: x normalized, y made perpendicular to x (Gram-Schmidt) and normalized, z = x cross y; zero or parallel vectors are `invalid_input`. `reset_axes {}` restores world axes. Both one undo step (a scene op), saved in `.skr` (schema 15 when not world), reported by a new `axes` field in the `camera` query (origin, x, y, z) and by `model_info`. Scenes do not store axes (documented). `.skp` import and export ignore model axes (documented).
4. **Context axes:** `set_axes` / `reset_axes` inside an open group or component change that definition's axes, in the open context's coordinates: the new frame `A` (from origin and axes as in ruling 3) becomes the definition's origin and axes: geometry (vertices, guides, annotations, section planes, nested instances) is transformed by `A^-1` and every instance of the definition in every mesh gets `transform * A`, so nothing moves in the world; the open context's path stays valid and the view does not jump. `reset_axes` inside a context is a no-op success (a definition's axes are its local frame; there is nothing to reset to). One undo step.
5. **Following the axes:** the current drawing axes (model axes at the root; local identity inside a context) drive: inference axis directions and colours, Shift and arrow-key locks and their status text, the origin snap (at the axes origin), the Rectangle's axis-aligned sides on axis planes, the Rotate tool's plane lock, standard views (Top looks down the current z with the current y up, etc.; inside a context the context's axes in world, orthonormalized), and the drawn axis lines (at the current axes origin, along the current axes; the ground grid stays on world z = 0). The `camera` query's standard view and the `set_view` command follow the same rule.
6. **Axes tool (`axes`, shortcut Y):** click the origin (with inference), click a point on the red axis, click a point fixing the green axis (the plane), as SketchUp; Esc cancels; preview of the three axis lines; arrow-key locks as other tools; `tool_input` drives it like other tools. Emits `set_axes`.
7. **Window:** Tools > Axes, rail button and icon, cursor; Group menu: Make Unique (enabled with a component instance of a shared definition selected), Flip Along > Red / Green / Blue (selection) and Component's Red / Green / Blue (one instance); viewport right-click menu: Make Unique, Flip Along items (same rules), Reset Axes (at the root when the axes are moved); Entity Info for a component instance shows its definition's instance count ("3 instances"). Status lines: "Made 2 components unique", "Flipped along red", "Axes moved", "Axes reset".

## Review Focus

1. Make Unique: shared definitions split correctly (nested groups deep-copied, nested components shared), names `#N` unique, undo exact, ids batch-referable; nothing else changes.
2. Flip: faces keep facing out at every depth; own-axes flip of a rotated, scaled, already-mirrored instance; selections mixing geometry and instances; inside an open group.
3. Context axes: nothing moves in the world (vertex world positions, instance world transforms of every instance, including instances nested in other definitions and placed twice); undo exact; the open context remains open and correct.
4. With moved model axes: inference directions, locks, origin snap, rectangle, rotate lock, standard views and axis lines follow; with world axes everything is unchanged (goldens).
5. `.skr` round trip; schema 15 only when axes moved; older files unchanged.
