# M2.5 Agent API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agents can fully drive the app through JSON-RPC 2.0, in the window (Unix socket) or headless (stdio or socket): execute and batch commands, query the model, get change notifications, render PNG views, and discover everything via `describe`.

**Architecture:** `session` hardens the wire contract (coordinate limit, canonical ids, revision in queries, a bounded change-event log, atomic batches, `camera_for`). `render` gains a `Snapshotter` for offscreen RGBA capture. New `api` crate: protocol helpers, a `Host` trait with method dispatch (`execute`, `batch`, `query`, `render_view`, `describe`), a `HeadlessHost`, a `Hub` that owns connections and `subscribe` notifications, and stream transports (Unix socket, stdio). `app` gains CLI modes, `Editor::execute` (API edits cancel an in-progress line), a `WindowHost`, and winit wake-ups through `EventLoopProxy`.

**Tech Stack:** Rust 2024; new pins schemars 1.2.2, png 0.18.1, base64 0.23.1; existing crates unchanged.

**Spec:** `docs/superpowers/specs/2026-10-10-tenon-design.md` section 5 (Agent control) and milestone M2.5.

## Global Constraints

- Every request goes through `session::Command`/`Query` (window mode: through `Editor::execute`). No API-only state changes.
- The `Document` is only touched on the thread that owns it; transports run on their own threads and talk to the `Hub` through channels.
- JSON-RPC 2.0, one JSON object per line; replies carry the request `id`; requests without `id` are notifications (no reply).
- Error codes: -32700 parse, -32600 invalid request, -32601 method not found, -32602 invalid params, -32000 command failed (data = `CommandError`), -32001 batch failed (data = `BatchError`), -32002 rendering unavailable.
- Coordinates must be finite and within +/-1e6 m (`MAX_COORDINATE`); entity ids parse only in canonical form (`v0`, `e12`; not `v007`, `v+5`).
- Socket: mode 0600; a stale socket file is replaced, any other existing file is an error; default path is per-process in the temp dir, falling back to `/tmp` when the path would exceed 100 bytes (macOS limit is about 104).
- `render_view` never moves the document camera; image sides 1..=4096.
- Pins: schemars `=1.2.2`, png `=0.18.1`, base64 `=0.23.1` (new); everything else unchanged.
- Git: work on `dev`; stage only files you changed; short plain commit messages, no emoji; `cargo fmt --all` before each commit.

## Spec notes

- Batches are a separate `batch` method and `Document::execute_batch`, not a `Command` variant; atomic batches reject `undo`/`redo` and roll back model and camera on error.
- `subscribe` streams `changed` notifications (`{revision, changes}`); if the bounded log (1024 events) dropped changes, a single `resync` notification asks the client to re-read the model. `Query::Events {since}` offers the same data by polling.
- MCP adapter remains out of scope.

```rust
use std::fmt;

use kernel::{ChangeSummary, EntityId};
use serde::{Deserialize, Serialize};

/// Every state change a client can make. Values are explicit (meters, degrees, entity ids);
/// commands never refer to screen positions or cursor state.
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Command {
    /// Draw a straight edge. Sticky-geometry rules apply (merging, splitting, auto faces).
    AddEdge {
        start: [f64; 3],
        end: [f64; 3],
    },
    Undo,
    Redo,
    /// Place the camera. Not recorded in undo history.
    SetCamera {
        eye: [f64; 3],
        target: [f64; 3],
        fov_y_deg: Option<f64>,
    },
}

/// What a successful command changed.
#[derive(Clone, Debug, Default, PartialEq, Serialize, Deserialize)]
pub struct Outcome {
    pub changes: ChangeSummary,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ErrorKind {
    InvalidInput,
    NothingToUndo,
    NothingToRedo,
    NotFound,
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct CommandError {
    pub kind: ErrorKind,
    pub message: String,
    /// Entities the error refers to, when there are any.
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub ids: Vec<EntityId>,
}

impl CommandError {
    pub fn new(kind: ErrorKind, message: impl Into<String>) -> Self {
        Self {
            kind,
            message: message.into(),
            ids: Vec::new(),
        }
    }

    pub fn with_ids(mut self, ids: Vec<EntityId>) -> Self {
        self.ids = ids;
        self
    }
}

impl fmt::Display for CommandError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{:?}: {}", self.kind, self.message)
    }
}

impl std::error::Error for CommandError {}

/// A batch stopped at command `index`. `completed` holds the outcomes of the commands before it;
/// for an atomic batch they were rolled back and nothing changed.
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct BatchError {
    pub index: usize,
    pub error: CommandError,
    pub completed: Vec<Outcome>,
    pub rolled_back: bool,
}
```

`crates/session/src/document.rs`:
```rust
use std::collections::VecDeque;

use glam::{DVec2, DVec3};
use kernel::{ChangeSet, EdgeId, EntityId, FaceId, Model, VertexId};

use crate::camera::Camera;
use crate::command::{BatchError, Command, CommandError, ErrorKind, Outcome};
use crate::query::{ChangeEvent, EdgeInfo, FaceInfo, Query, QueryResult, VertexInfo};

/// Largest coordinate magnitude (meters) accepted from commands.
pub const MAX_COORDINATE: f64 = 1.0e6;

/// How many recent model changes `Query::Events` can return.
const EVENT_LOG_LEN: usize = 1024;

/// The open model plus everything needed to edit it: camera and undo history.
pub struct Document {
    model: Model,
    pub camera: Camera,
    undo: Vec<ChangeSet>,
    redo: Vec<ChangeSet>,
    revision: u64,
    events: VecDeque<ChangeEvent>,
}

impl Document {
    pub fn new(viewport: DVec2) -> Self {
        Self {
            model: Model::new(),
            camera: Camera::new(viewport),
            undo: Vec::new(),
            redo: Vec::new(),
            revision: 0,
            events: VecDeque::new(),
        }
    }

    pub fn model(&self) -> &Model {
        &self.model
    }

    /// Increases every time the model changes (edits, undo, redo). Clients compare it to decide
    /// whether to rebuild anything derived from the model.
    pub fn revision(&self) -> u64 {
        self.revision
    }

    /// Model changes after `since`, oldest first, and whether older ones were dropped.
    pub fn events_since(&self, since: u64) -> (Vec<ChangeEvent>, bool) {
        let truncated = self
            .events
            .front()
            .is_some_and(|first| first.revision > since + 1);
        let events = self
            .events
            .iter()
            .filter(|e| e.revision > since)
            .cloned()
            .collect();
        (events, truncated)
    }

    /// Runs one command. Each modeling command is one undo step; camera commands are not recorded.
    pub fn execute(&mut self, command: Command) -> Result<Outcome, CommandError> {
        match command {
            Command::AddEdge { start, end } => {
                let changes = self.add_edge_changes(start, end)?;
                Ok(self.record(changes))
            }
            Command::Undo => {
                let changes = self.undo.pop().ok_or_else(|| {
                    CommandError::new(ErrorKind::NothingToUndo, "nothing to undo")
                })?;
                let inverse = changes.inverse();
                self.model.apply(&inverse);
                self.redo.push(changes);
                Ok(self.changed(&inverse))
            }
            Command::Redo => {
                let changes = self.redo.pop().ok_or_else(|| {
                    CommandError::new(ErrorKind::NothingToRedo, "nothing to redo")
                })?;
                self.model.apply(&changes);
                let outcome = self.changed(&changes);
                self.undo.push(changes);
                Ok(outcome)
            }
            Command::SetCamera {
                eye,
                target,
                fov_y_deg,
            } => {
                self.camera = self.camera_for(eye, target, fov_y_deg)?;
                Ok(Outcome::default())
            }
        }
    }

    /// The current camera moved to `eye`/`target` (and `fov_y_deg` if given), after the same
    /// checks `SetCamera` applies. Does not change the document.
    pub fn camera_for(
        &self,
        eye: [f64; 3],
        target: [f64; 3],
        fov_y_deg: Option<f64>,
    ) -> Result<Camera, CommandError> {
        check_coordinates(&[eye, target])?;
        let (eye, target) = (DVec3::from(eye), DVec3::from(target));
        let fov = fov_y_deg.unwrap_or(self.camera.fov_y.to_degrees());
        if eye.distance(target) < 1e-6 {
            return Err(CommandError::new(
                ErrorKind::InvalidInput,
                "eye and target must be distinct points",
            ));
        }
        if (target - eye).normalize().cross(DVec3::Z).length() < 1e-9 {
            return Err(CommandError::new(
                ErrorKind::InvalidInput,
                "view direction must not be vertical",
            ));
        }
        if !(1.0..=170.0).contains(&fov) {
            return Err(CommandError::new(
                ErrorKind::InvalidInput,
                "fov_y_deg must be between 1 and 170",
            ));
        }
        let mut camera = self.camera.clone();
        camera.eye = eye;
        camera.target = target;
        camera.fov_y = fov.to_radians();
        Ok(camera)
    }

    /// Runs commands in order, stopping at the first error.
    ///
    /// Non-atomic: each command is its own undo step and earlier commands stay applied.
    /// Atomic: all modeling commands become one undo step, and on error everything (model and
    /// camera) is rolled back. Undo and redo are not allowed inside an atomic batch.
    pub fn execute_batch(
        &mut self,
        commands: Vec<Command>,
        atomic: bool,
    ) -> Result<Vec<Outcome>, BatchError> {
        let mut outcomes = Vec::new();
        if !atomic {
            for (index, command) in commands.into_iter().enumerate() {
                match self.execute(command) {
                    Ok(o) => outcomes.push(o),
                    Err(error) => {
                        return Err(BatchError {
                            index,
                            error,
                            completed: outcomes,
                            rolled_back: false,
                        });
                    }
                }
            }
            return Ok(outcomes);
        }

        let camera_before = self.camera.clone();
        let mut applied: Vec<ChangeSet> = Vec::new();
        for (index, command) in commands.into_iter().enumerate() {
            let result = match command {
                Command::AddEdge { start, end } => self.add_edge_changes(start, end).map(|c| {
                    let summary = c.summary();
                    applied.push(c);
                    Outcome { changes: summary }
                }),
                Command::Undo | Command::Redo => Err(CommandError::new(
                    ErrorKind::InvalidInput,
                    "undo and redo are not allowed in an atomic batch",
                )),
                camera @ Command::SetCamera { .. } => self.execute(camera),
            };
            match result {
                Ok(o) => outcomes.push(o),
                Err(error) => {
                    for c in applied.iter().rev() {
                        self.model.apply(&c.inverse());
                    }
                    self.camera = camera_before;
                    return Err(BatchError {
                        index,
                        error,
                        completed: outcomes,
                        rolled_back: true,
                    });
                }
            }
        }
        let merged = ChangeSet {
            ops: applied.into_iter().flat_map(|c| c.ops).collect(),
        };
        self.record(merged);
        Ok(outcomes)
    }

    fn add_edge_changes(
        &mut self,
        start: [f64; 3],
        end: [f64; 3],
    ) -> Result<ChangeSet, CommandError> {
        check_coordinates(&[start, end])?;
        self.model
            .add_edge(DVec3::from(start), DVec3::from(end))
            .map_err(|e| CommandError::new(ErrorKind::InvalidInput, e.to_string()))
    }

    fn record(&mut self, changes: ChangeSet) -> Outcome {
        if changes.is_empty() {
            return Outcome::default();
        }
        let outcome = self.changed(&changes);
        self.undo.push(changes);
        self.redo.clear();
        outcome
    }

    /// Bumps the revision and logs the change.
    fn changed(&mut self, changes: &ChangeSet) -> Outcome {
        self.revision += 1;
        let summary = changes.summary();
        self.events.push_back(ChangeEvent {
            revision: self.revision,
            changes: summary.clone(),
        });
        if self.events.len() > EVENT_LOG_LEN {
            self.events.pop_front();
        }
        Outcome { changes: summary }
    }

    pub fn query(&self, query: &Query) -> Result<QueryResult, CommandError> {
        let m = &self.model;
        Ok(match query {
            Query::Entities => QueryResult::Entities {
                vertices: m.vertices().map(|(id, _)| self.vertex_info(id)).collect(),
                edges: m.edges().map(|(id, _)| self.edge_info(id)).collect(),
                faces: m.faces().map(|(id, _)| self.face_info(id)).collect(),
            },
            Query::Entity { id } => {
                let missing = || {
                    CommandError::new(ErrorKind::NotFound, format!("no entity {id}"))
                        .with_ids(vec![*id])
                };
                match *id {
                    EntityId::Vertex(v) => QueryResult::Vertex(
                        m.vertex(v)
                            .map(|_| self.vertex_info(v))
                            .ok_or_else(missing)?,
                    ),
                    EntityId::Edge(e) => {
                        QueryResult::Edge(m.edge(e).map(|_| self.edge_info(e)).ok_or_else(missing)?)
                    }
                    EntityId::Face(f) => {
                        QueryResult::Face(m.face(f).map(|_| self.face_info(f)).ok_or_else(missing)?)
                    }
                }
            }
            Query::Camera => QueryResult::Camera {
                eye: self.camera.eye.to_array(),
                target: self.camera.target.to_array(),
                fov_y_deg: self.camera.fov_y.to_degrees(),
            },
            Query::Stats => QueryResult::Stats {
                vertices: m.vertices().count(),
                edges: m.edges().count(),
                faces: m.faces().count(),
                revision: self.revision,
            },
            Query::History => QueryResult::History {
                undo_depth: self.undo.len(),
                redo_depth: self.redo.len(),
                revision: self.revision,
            },
            Query::Events { since } => {
                let (events, truncated) = self.events_since(*since);
                QueryResult::Events {
                    revision: self.revision,
                    events,
                    truncated,
                }
            }
        })
    }

    fn vertex_info(&self, id: VertexId) -> VertexInfo {
        VertexInfo {
            id: EntityId::Vertex(id),
            position: self.model.position(id).unwrap().to_array(),
        }
    }

    fn edge_info(&self, id: EdgeId) -> EdgeInfo {
        let [a, b] = self.model.edge(id).unwrap().v;
        EdgeInfo {
            id: EntityId::Edge(id),
            vertices: [EntityId::Vertex(a), EntityId::Vertex(b)],
            start: self.model.position(a).unwrap().to_array(),
            end: self.model.position(b).unwrap().to_array(),
        }
    }

    fn face_info(&self, id: FaceId) -> FaceInfo {
        let f = self.model.face(id).unwrap();
        let ids = |l: &Vec<VertexId>| l.iter().map(|v| EntityId::Vertex(*v)).collect();
        FaceInfo {
            id: EntityId::Face(id),
            outer: ids(&f.outer),
            holes: f.holes.iter().map(ids).collect(),
            normal: f.normal.to_array(),
            area: self.model.area(id).unwrap(),
        }
    }
}

/// Rejects non-finite or out-of-range coordinates before they reach the kernel or camera.
fn check_coordinates(points: &[[f64; 3]]) -> Result<(), CommandError> {
    let ok = points
        .iter()
        .flatten()
        .all(|c| c.is_finite() && c.abs() <= MAX_COORDINATE);
    if ok {
        Ok(())
    } else {
        Err(CommandError::new(
            ErrorKind::InvalidInput,
            format!("coordinates must be finite and within +/-{MAX_COORDINATE} m"),
        ))
    }
}
```

```rust
//! Offscreen rendering to RGBA pixels, for headless mode and the API's `render_view`.

use kernel::Model;
use session::Camera;

use crate::Renderer;

/// Renders models to memory with its own offscreen renderer.
pub struct Snapshotter {
    device: wgpu::Device,
    queue: wgpu::Queue,
    renderer: Renderer,
}

const FORMAT: wgpu::TextureFormat = wgpu::TextureFormat::Rgba8Unorm;

impl Snapshotter {
    /// Creates its own GPU device. None when no adapter is available.
    pub fn new_headless() -> Option<Self> {
        let instance = wgpu::Instance::default();
        let adapter =
            pollster::block_on(instance.request_adapter(&wgpu::RequestAdapterOptions::default()))
                .ok()?;
        let (device, queue) =
            pollster::block_on(adapter.request_device(&wgpu::DeviceDescriptor::default())).ok()?;
        Some(Self::with_device(&device, &queue))
    }

    /// Shares an existing device, e.g. the window's.
    pub fn with_device(device: &wgpu::Device, queue: &wgpu::Queue) -> Self {
        Self {
            device: device.clone(),
            queue: queue.clone(),
            renderer: Renderer::new(device, queue, FORMAT),
        }
    }

    /// Renders `model` as seen by `camera` (its viewport is replaced by the image size) into
    /// tightly packed RGBA8 pixels, top row first.
    pub fn capture(&mut self, model: &Model, camera: &Camera, width: u32, height: u32) -> Vec<u8> {
        let (width, height) = (width.max(1), height.max(1));
        let mut camera = camera.clone();
        camera.viewport = glam::DVec2::new(width as f64, height as f64);

        let size = wgpu::Extent3d {
            width,
            height,
            depth_or_array_layers: 1,
        };
        let texture = self.device.create_texture(&wgpu::TextureDescriptor {
            label: Some("snapshot"),
            size,
            mip_level_count: 1,
            sample_count: 1,
            dimension: wgpu::TextureDimension::D2,
            format: FORMAT,
            usage: wgpu::TextureUsages::RENDER_ATTACHMENT | wgpu::TextureUsages::COPY_SRC,
            view_formats: &[],
        });
        let view = texture.create_view(&wgpu::TextureViewDescriptor::default());
        self.renderer.set_model(model);
        self.renderer.render(&view, (width, height), &camera, &[]);

        // Texture-to-buffer copies need rows padded to a multiple of 256 bytes.
        let row = width * 4;
        let padded_row =
            row.div_ceil(wgpu::COPY_BYTES_PER_ROW_ALIGNMENT) * wgpu::COPY_BYTES_PER_ROW_ALIGNMENT;
        let buffer = self.device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("snapshot readback"),
            size: (padded_row * height) as u64,
            usage: wgpu::BufferUsages::COPY_DST | wgpu::BufferUsages::MAP_READ,
            mapped_at_creation: false,
        });
        let mut encoder = self
            .device
            .create_command_encoder(&wgpu::CommandEncoderDescriptor { label: None });
        encoder.copy_texture_to_buffer(
            wgpu::TexelCopyTextureInfo {
                texture: &texture,
                mip_level: 0,
                origin: wgpu::Origin3d::ZERO,
                aspect: wgpu::TextureAspect::All,
            },
            wgpu::TexelCopyBufferInfo {
                buffer: &buffer,
                layout: wgpu::TexelCopyBufferLayout {
                    offset: 0,
                    bytes_per_row: Some(padded_row),
                    rows_per_image: Some(height),
                },
            },
            size,
        );
        self.queue.submit([encoder.finish()]);
        buffer
            .slice(..)
            .map_async(wgpu::MapMode::Read, |r| r.expect("map snapshot buffer"));
        self.device
            .poll(wgpu::PollType::wait_indefinitely())
            .expect("poll");
        let mapped = buffer.slice(..).get_mapped_range().expect("mapped range");
        mapped
            .chunks(padded_row as usize)
            .flat_map(|r| &r[..row as usize])
            .copied()
            .collect()
    }
}
```

```rust
//! JSON-RPC 2.0 message helpers.

use serde_json::{Value, json};

/// Error codes: the JSON-RPC standard ones plus application errors in -32000..-32099.
pub mod codes {
    pub const PARSE_ERROR: i64 = -32700;
    pub const INVALID_REQUEST: i64 = -32600;
    pub const METHOD_NOT_FOUND: i64 = -32601;
    pub const INVALID_PARAMS: i64 = -32602;
    /// A command or query failed; `data` is the session `CommandError`.
    pub const COMMAND_FAILED: i64 = -32000;
    /// A batch stopped; `data` is the session `BatchError`.
    pub const BATCH_FAILED: i64 = -32001;
    /// `render_view` was asked for but no GPU is available.
    pub const RENDER_UNAVAILABLE: i64 = -32002;
}

/// An error to send back: code, message and optional structured data.
#[derive(Debug, PartialEq)]
pub struct RpcError {
    pub code: i64,
    pub message: String,
    pub data: Option<Value>,
}

impl RpcError {
    pub fn new(code: i64, message: impl Into<String>) -> Self {
        Self {
            code,
            message: message.into(),
            data: None,
        }
    }

    pub fn with_data(mut self, data: Value) -> Self {
        self.data = Some(data);
        self
    }
}

pub fn success(id: &Value, result: Value) -> String {
    json!({"jsonrpc": "2.0", "id": id, "result": result}).to_string()
}

pub fn failure(id: &Value, error: RpcError) -> String {
    let mut e = json!({"code": error.code, "message": error.message});
    if let Some(data) = error.data {
        e["data"] = data;
    }
    json!({"jsonrpc": "2.0", "id": id, "error": e}).to_string()
}

pub fn notification(method: &str, params: Value) -> String {
    json!({"jsonrpc": "2.0", "method": method, "params": params}).to_string()
}

/// A parsed request: `id` is None for notifications (no reply expected).
pub struct Request {
    pub id: Option<Value>,
    pub method: String,
    pub params: Value,
}

/// Parses one line. On failure returns the reply to send (with a null id when unknown).
pub fn parse(line: &str) -> Result<Request, String> {
    let v: Value = serde_json::from_str(line).map_err(|e| {
        failure(
            &Value::Null,
            RpcError::new(codes::PARSE_ERROR, format!("parse error: {e}")),
        )
    })?;
    let invalid = |id: &Value, why: &str| {
        failure(
            id,
            RpcError::new(codes::INVALID_REQUEST, format!("invalid request: {why}")),
        )
    };
    let Some(obj) = v.as_object() else {
        return Err(invalid(&Value::Null, "expected a JSON object"));
    };
    let id = obj.get("id").cloned();
    let reply_id = id.clone().unwrap_or(Value::Null);
    if obj.get("jsonrpc") != Some(&json!("2.0")) {
        return Err(invalid(&reply_id, "jsonrpc must be \"2.0\""));
    }
    let Some(method) = obj.get("method").and_then(Value::as_str) else {
        return Err(invalid(&reply_id, "method must be a string"));
    };
    Ok(Request {
        id,
        method: method.to_string(),
        params: obj.get("params").cloned().unwrap_or(Value::Null),
    })
}
```

```rust
//! Method dispatch: maps JSON-RPC methods onto session commands, queries and rendering.

use base64::Engine;
use schemars::schema_for;
use serde::Deserialize;
use serde::de::DeserializeOwned;
use serde_json::{Value, json};
use session::{
    BatchError, Camera, ChangeEvent, Command, CommandError, Document, Outcome, Query, QueryResult,
};

use crate::protocol::{RpcError, codes, failure, parse, success};

/// Largest image side `render_view` accepts, in pixels.
pub const MAX_IMAGE_SIDE: u32 = 4096;

/// What the API needs from the program it runs in (the window app or headless mode).
pub trait Host {
    fn document(&self) -> &Document;
    /// Runs one command the same way the UI would.
    fn execute(&mut self, command: Command) -> Result<Outcome, CommandError>;
    fn execute_batch(
        &mut self,
        commands: Vec<Command>,
        atomic: bool,
    ) -> Result<Vec<Outcome>, BatchError>;
    /// Renders the current model from `camera` to tightly packed RGBA8 pixels, or None when no
    /// GPU is available.
    fn render_view(&mut self, camera: &Camera, width: u32, height: u32) -> Option<Vec<u8>>;
}

/// Handles one request line and returns the reply line (None for notifications).
/// `subscribe` is connection-level and handled by `Hub`.
pub fn handle(host: &mut dyn Host, line: &str) -> Option<String> {
    let request = match parse(line) {
        Ok(r) => r,
        Err(reply) => return Some(reply),
    };
    let result = call(host, &request.method, request.params);
    let id = request.id?;
    Some(match result {
        Ok(value) => success(&id, value),
        Err(error) => failure(&id, error),
    })
}

fn call(host: &mut dyn Host, method: &str, params: Value) -> Result<Value, RpcError> {
    match method {
        "execute" => {
            let command: Command = params_as(params)?;
            let outcome = host.execute(command).map_err(command_failed)?;
            Ok(json!({"changes": outcome.changes, "revision": host.document().revision()}))
        }
        "batch" => {
            #[derive(Deserialize)]
            struct Params {
                commands: Vec<Command>,
                #[serde(default)]
                atomic: bool,
            }
            let p: Params = params_as(params)?;
            let outcomes = host.execute_batch(p.commands, p.atomic).map_err(|e| {
                RpcError::new(
                    codes::BATCH_FAILED,
                    format!("batch stopped at command {}", e.index),
                )
                .with_data(json!(e))
            })?;
            Ok(json!({"outcomes": outcomes, "revision": host.document().revision()}))
        }
        "query" => {
            let query: Query = params_as(params)?;
            let result = host.document().query(&query).map_err(command_failed)?;
            Ok(json!(result))
        }
        "render_view" => render_view(host, params),
        "describe" => Ok(describe()),
        "subscribe" => Err(RpcError::new(
            codes::INVALID_REQUEST,
            "subscribe needs a connection (use the socket or stdio transport)",
        )),
        other => Err(RpcError::new(
            codes::METHOD_NOT_FOUND,
            format!("unknown method {other:?}; call \"describe\" for the list"),
        )),
    }
}

fn render_view(host: &mut dyn Host, params: Value) -> Result<Value, RpcError> {
    #[derive(Deserialize)]
    struct View {
        eye: [f64; 3],
        target: [f64; 3],
        fov_y_deg: Option<f64>,
    }
    #[derive(Deserialize)]
    struct Params {
        width: u32,
        height: u32,
        camera: Option<View>,
    }
    let p: Params = params_as(params)?;
    let sides = 1..=MAX_IMAGE_SIDE;
    if !sides.contains(&p.width) || !sides.contains(&p.height) {
        return Err(RpcError::new(
            codes::INVALID_PARAMS,
            format!("width and height must be between 1 and {MAX_IMAGE_SIDE}"),
        ));
    }
    let doc = host.document();
    let camera = match p.camera {
        Some(v) => doc
            .camera_for(v.eye, v.target, v.fov_y_deg)
            .map_err(command_failed)?,
        None => doc.camera.clone(),
    };
    let rgba = host
        .render_view(&camera, p.width, p.height)
        .ok_or_else(|| {
            RpcError::new(codes::RENDER_UNAVAILABLE, "no GPU available for rendering")
        })?;
    let png = encode_png(&rgba, p.width, p.height);
    Ok(json!({
        "width": p.width,
        "height": p.height,
        "png_base64": base64::engine::general_purpose::STANDARD.encode(png),
    }))
}

fn encode_png(rgba: &[u8], width: u32, height: u32) -> Vec<u8> {
    let mut out = Vec::new();
    let mut encoder = png::Encoder::new(&mut out, width, height);
    encoder.set_color(png::ColorType::Rgba);
    encoder.set_depth(png::BitDepth::Eight);
    let mut writer = encoder.write_header().expect("png header to memory");
    writer.write_image_data(rgba).expect("png data to memory");
    drop(writer);
    out
}
```

```rust
//! Connections, request routing and change notifications.
//!
//! Transports (socket, stdio, tests) feed lines into an `Inbox` from any thread. The program
//! that owns the document calls `Hub::process` on its own thread; that is the only place
//! requests touch the document.

use std::collections::{HashMap, HashSet};
use std::sync::Arc;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::mpsc::{Receiver, Sender, channel};

use serde_json::json;

use crate::dispatch::{Host, handle};
use crate::protocol::{notification, parse, success};

enum Event {
    Opened { conn: u64, out: Sender<String> },
    Line { conn: u64, line: String },
    Closed { conn: u64 },
}

/// The sending side used by transports. Cheap to clone; usable from any thread.
#[derive(Clone)]
pub struct Inbox {
    tx: Sender<Event>,
    next_conn: Arc<AtomicU64>,
    wake: Arc<dyn Fn() + Send + Sync>,
}

impl Inbox {
    /// Registers a connection. Replies and notifications for it arrive on the returned receiver.
    pub fn open(&self) -> (u64, Receiver<String>) {
        let conn = self.next_conn.fetch_add(1, Ordering::Relaxed);
        let (out, rx) = channel();
        self.send(Event::Opened { conn, out });
        (conn, rx)
    }

    pub fn send_line(&self, conn: u64, line: String) {
        self.send(Event::Line { conn, line });
    }

    pub fn close(&self, conn: u64) {
        self.send(Event::Closed { conn });
    }

    fn send(&self, event: Event) {
        if self.tx.send(event).is_ok() {
            (self.wake)();
        }
    }
}

pub struct Hub {
    rx: Receiver<Event>,
    inbox: Inbox,
    outs: HashMap<u64, Sender<String>>,
    subscribers: HashSet<u64>,
    /// Last revision subscribers were told about.
    notified: Option<u64>,
}

impl Hub {
    /// `wake` is called (from transport threads) whenever input arrives, so a window event loop
    /// can schedule `process`. Pass a no-op when blocking in `process_blocking`.
    pub fn new(wake: impl Fn() + Send + Sync + 'static) -> Self {
        let (tx, rx) = channel();
        Self {
            rx,
            inbox: Inbox {
                tx,
                next_conn: Arc::new(AtomicU64::new(1)),
                wake: Arc::new(wake),
            },
            outs: HashMap::new(),
            subscribers: HashSet::new(),
            notified: None,
        }
    }

    pub fn inbox(&self) -> Inbox {
        self.inbox.clone()
    }

    pub fn open_connections(&self) -> usize {
        self.outs.len()
    }

    /// Handles everything waiting without blocking, then notifies subscribers.
    pub fn process(&mut self, host: &mut dyn Host) {
        while let Ok(event) = self.rx.try_recv() {
            self.on_event(host, event);
        }
        self.notify(host);
    }

    /// Waits for at least one event, then handles everything waiting. Returns false if every
    /// inbox has been dropped (no more input can arrive).
    pub fn process_blocking(&mut self, host: &mut dyn Host) -> bool {
        match self.rx.recv() {
            Ok(event) => {
                self.on_event(host, event);
                self.process(host);
                true
            }
            Err(_) => false,
        }
    }

    /// Sends `changed` notifications for model changes subscribers have not seen yet (including
    /// changes made through the UI). Call after any edit outside `process`.
    pub fn notify(&mut self, host: &dyn Host) {
        let doc = host.document();
        let Some(since) = self.notified else {
            self.notified = Some(doc.revision());
            return;
        };
        if doc.revision() == since {
            return;
        }
        let (events, truncated) = doc.events_since(since);
        let lines: Vec<String> = if truncated {
            vec![notification("resync", json!({"revision": doc.revision()}))]
        } else {
            events
                .iter()
                .map(|e| notification("changed", json!(e)))
                .collect()
        };
        for conn in &self.subscribers {
            if let Some(out) = self.outs.get(conn) {
                for line in &lines {
                    let _ = out.send(line.clone());
                }
            }
        }
        self.notified = Some(doc.revision());
    }

    fn on_event(&mut self, host: &mut dyn Host, event: Event) {
        match event {
            Event::Opened { conn, out } => {
                self.outs.insert(conn, out);
            }
            Event::Closed { conn } => {
                self.outs.remove(&conn);
                self.subscribers.remove(&conn);
            }
            Event::Line { conn, line } => {
                let reply = match parse(&line) {
                    Ok(req) if req.method == "subscribe" => {
                        // Notify about anything earlier before this connection joins.
                        self.notify(host);
                        self.subscribers.insert(conn);
                        req.id
                            .map(|id| success(&id, json!({"revision": host.document().revision()})))
                    }
                    _ => handle(host, &line),
                };
                if let (Some(reply), Some(out)) = (reply, self.outs.get(&conn)) {
                    let _ = out.send(reply);
                }
                // Notify right after each request: a connection may close in the same batch of
                // events, and its notifications must go out before it is dropped.
                self.notify(host);
            }
        }
    }
}
```

```rust
//! Byte-stream transports: newline-delimited JSON over a Unix socket or stdin/stdout.

use std::io::{self, BufRead, BufReader, Read, Write};
use std::os::unix::fs::{FileTypeExt, PermissionsExt};
use std::os::unix::net::UnixListener;
use std::path::Path;
use std::thread::{self, JoinHandle};

use crate::hub::Inbox;

/// Serves one connection: lines read from `reader` go to the hub, replies and notifications are
/// written to `writer`. Returns the connection id and the writer thread, which finishes once the
/// hub is dropped and every queued reply has been written.
pub fn serve_stream<R, W>(inbox: Inbox, reader: R, mut writer: W) -> (u64, JoinHandle<()>)
where
    R: Read + Send + 'static,
    W: Write + Send + 'static,
{
    let (conn, replies) = inbox.open();
    let writer_thread = thread::spawn(move || {
        for line in replies {
            if writer
                .write_all(line.as_bytes())
                .and_then(|_| writer.write_all(b"\n"))
                .and_then(|_| writer.flush())
                .is_err()
            {
                break;
            }
        }
    });
    thread::spawn(move || {
        for line in BufReader::new(reader).lines() {
            match line {
                Ok(line) if line.trim().is_empty() => continue,
                Ok(line) => inbox.send_line(conn, line),
                Err(_) => break,
            }
        }
        inbox.close(conn);
    });
    (conn, writer_thread)
}

/// Serves the API on stdin/stdout as a single connection. Join the returned thread after
/// dropping the hub so the last replies reach stdout before the process exits.
pub fn serve_stdio(inbox: Inbox) -> JoinHandle<()> {
    serve_stream(inbox, io::stdin(), io::stdout()).1
}

/// Listens on a Unix socket readable only by the current user. A stale socket file at `path` is
/// replaced; any other existing file is an error.
pub fn listen_unix(path: &Path, inbox: Inbox) -> io::Result<()> {
    if let Ok(meta) = std::fs::symlink_metadata(path) {
        if meta.file_type().is_socket() {
            std::fs::remove_file(path)?;
        } else {
            return Err(io::Error::new(
                io::ErrorKind::AlreadyExists,
                format!("{} exists and is not a socket", path.display()),
            ));
        }
    }
    let listener = UnixListener::bind(path)?;
    std::fs::set_permissions(path, std::fs::Permissions::from_mode(0o600))?;
    thread::spawn(move || {
        for stream in listener.incoming().flatten() {
            if let Ok(reader) = stream.try_clone() {
                serve_stream(inbox.clone(), reader, stream);
            }
        }
    });
    Ok(())
}
```

```rust
//! Command-line modes.

use std::path::PathBuf;

pub const USAGE: &str =
    "usage: app [--socket PATH]                 window, agent API on a Unix socket
       app --headless --stdio               no window, agent API on stdin/stdout
       app --headless [--socket PATH]       no window, agent API on a Unix socket";

#[derive(Debug, PartialEq)]
pub enum Transport {
    Stdio,
    Socket(PathBuf),
}

#[derive(Debug, PartialEq)]
pub enum Mode {
    Window { socket: PathBuf },
    Headless { transport: Transport },
}

/// Unix socket paths are limited to about 104 bytes on macOS.
const MAX_SOCKET_PATH: usize = 100;

/// Default socket path: per-process, in the user's temp directory, or in /tmp when the temp
/// directory is too deep for a socket path.
pub fn default_socket() -> PathBuf {
    let name = format!("tenon-{}.sock", std::process::id());
    let preferred = std::env::temp_dir().join(&name);
    if preferred.as_os_str().len() <= MAX_SOCKET_PATH {
        preferred
    } else {
        PathBuf::from("/tmp").join(name)
    }
}

pub fn parse(args: impl IntoIterator<Item = String>) -> Result<Mode, String> {
    let (mut headless, mut stdio, mut socket) = (false, false, None);
    let mut args = args.into_iter();
    while let Some(arg) = args.next() {
        match arg.as_str() {
            "--headless" => headless = true,
            "--stdio" => stdio = true,
            "--socket" => {
                let path = args.next().ok_or("--socket needs a path")?;
                socket = Some(PathBuf::from(path));
            }
            other => return Err(format!("unknown argument {other:?}")),
        }
    }
    if stdio && socket.is_some() {
        return Err("choose either --stdio or --socket".into());
    }
    if stdio && !headless {
        return Err("--stdio needs --headless (the window keeps stdout for logs)".into());
    }
    let socket = socket.unwrap_or_else(default_socket);
    Ok(if !headless {
        Mode::Window { socket }
    } else if stdio {
        Mode::Headless {
            transport: Transport::Stdio,
        }
    } else {
        Mode::Headless {
            transport: Transport::Socket(socket),
        }
    })
}
```

```rust
//! Window-independent editing state: routes input to navigation or the active tool, runs the
//! resulting commands on the document, and produces the overlay to draw.

use glam::{DVec2, DVec3};
use render::grid::LineVertex;
use session::{BatchError, Command, CommandError, Document, ErrorKind, Outcome};
use tools::overlay::overlay;
use tools::{Inference, LineTool, ToolEvent, ToolOutput, infer};

use crate::navigation::{Button, Navigation};

/// Snap radius in logical pixels (scaled to physical pixels by the display scale factor).
const PICK_RADIUS_LOGICAL_PX: f64 = 8.0;

pub struct Editor {
    doc: Document,
    nav: Navigation,
    tool: LineTool,
    cursor: DVec2,
    hit: Option<Inference>,
    preview: Vec<[DVec3; 2]>,
    /// Physical pixels per logical pixel.
    scale_factor: f64,
}

impl Editor {
    pub fn new(viewport: DVec2, scale_factor: f64) -> Self {
        Self {
            doc: Document::new(viewport),
            nav: Navigation::default(),
            tool: LineTool::new(),
            cursor: DVec2::ZERO,
            hit: None,
            preview: Vec::new(),
            scale_factor,
        }
    }

    pub fn doc(&self) -> &Document {
        &self.doc
    }

    /// Runs a command from outside the UI (the agent API). A modeling command cancels the line
    /// being drawn so the tool never continues from geometry that may have changed.
    pub fn execute(&mut self, command: Command) -> Result<Outcome, CommandError> {
        if !matches!(command, Command::SetCamera { .. }) {
            self.abandon_chain();
        }
        let result = self.doc.execute(command);
        self.update_hover();
        result
    }

    /// Batch version of `execute`.
    pub fn execute_batch(
        &mut self,
        commands: Vec<Command>,
        atomic: bool,
    ) -> Result<Vec<Outcome>, BatchError> {
        if commands
            .iter()
            .any(|c| !matches!(c, Command::SetCamera { .. }))
        {
            self.abandon_chain();
        }
        let result = self.doc.execute_batch(commands, atomic);
        self.update_hover();
        result
    }

    pub fn resize(&mut self, viewport: DVec2) {
        self.doc.camera.viewport = viewport;
    }

    pub fn set_scale_factor(&mut self, scale_factor: f64) {
        self.scale_factor = scale_factor;
    }

    pub fn set_modifiers(&mut self, shift: bool, alt: bool) {
        self.nav.set_modifiers(shift, alt);
    }

    pub fn focus_lost(&mut self) {
        self.nav.reset();
    }

    /// Returns true if anything visible changed.
    pub fn cursor_moved(&mut self, pos: DVec2) -> bool {
        self.cursor = pos;
        let camera_moved = self.nav.cursor_moved(&mut self.doc.camera, pos);
        self.update_hover() || camera_moved
    }

    pub fn button(&mut self, button: Button, pressed: bool) -> bool {
        if self.nav.button(&self.doc.camera, button, pressed) {
            return false;
        }
        if button != Button::Left || !pressed {
            return false;
        }
        self.update_hover();
        let Some(hit) = self.hit else { return false };
        let out = self.tool.handle(ToolEvent::Click(hit));
        self.apply(out);
        self.update_hover();
        true
    }

    pub fn scroll(&mut self, steps: f64) -> bool {
        let zoomed = self.nav.scroll(&mut self.doc.camera, steps);
        if zoomed {
            self.update_hover();
        }
        zoomed
    }

    /// Escape: abandon the line being drawn.
    pub fn cancel(&mut self) -> bool {
        let out = self.tool.handle(ToolEvent::Cancel);
        self.apply(out);
        self.update_hover();
        true
    }

    pub fn undo(&mut self) -> bool {
        self.abandon_chain();
        self.run(Command::Undo);
        self.update_hover();
        true
    }

    pub fn redo(&mut self) -> bool {
        self.abandon_chain();
        self.run(Command::Redo);
        self.update_hover();
        true
    }

    /// Line pairs for the renderer's overlay pass.
    pub fn overlay(&self) -> Vec<LineVertex> {
        overlay(
            &self.preview,
            self.hit.as_ref(),
            &self.doc.camera,
            self.scale_factor,
        )
        .into_iter()
        .flat_map(|s| {
            [s.a, s.b].map(|p| LineVertex {
                pos: p.as_vec3().to_array(),
                color: s.color,
            })
        })
        .collect()
    }

    fn apply(&mut self, out: ToolOutput) {
        for command in out.commands {
            self.run(command);
        }
        self.preview = out.preview;
    }

    /// Drops the line being drawn so history changes can't leave it pointing at stale geometry.
    fn abandon_chain(&mut self) {
        self.tool.handle(ToolEvent::Cancel);
        self.preview.clear();
    }

    fn run(&mut self, command: Command) {
        match self.doc.execute(command) {
            Ok(_) => {}
            Err(e) if matches!(e.kind, ErrorKind::NothingToUndo | ErrorKind::NothingToRedo) => {}
            Err(e) => eprintln!("command failed: {e}"),
        }
    }

    /// Recomputes the inference under the cursor and the tool preview. True if either changed.
    fn update_hover(&mut self) -> bool {
        let hit = infer(
            self.doc.model(),
            &self.doc.camera,
            self.cursor,
            self.tool.anchor(),
            PICK_RADIUS_LOGICAL_PX * self.scale_factor,
        );
        let out = self.tool.handle(ToolEvent::Move(hit));
        let changed = self.hit != Some(hit) || self.preview != out.preview;
        self.hit = Some(hit);
        self.preview = out.preview;
        changed
    }
}
```

```rust
//! The agent API's view of the window app: commands go through the Editor (so the active tool
//! stays consistent) and `render_view` uses an offscreen renderer on the window's GPU device.

use api::Host;

use session::{BatchError, Camera, Command, CommandError, Document, Outcome};

pub struct WindowHost<'a> {
    pub editor: &'a mut Editor,
    pub snapshotter: &'a mut Snapshotter,
}

impl Host for WindowHost<'_> {
    fn document(&self) -> &Document {
        self.editor.doc()
    }

    fn execute(&mut self, command: Command) -> Result<Outcome, CommandError> {
        self.editor.execute(command)
    }

    fn execute_batch(
        &mut self,
        commands: Vec<Command>,
        atomic: bool,
    ) -> Result<Vec<Outcome>, BatchError> {

        )
```

```rust
//! Running without a window: the agent API on stdio or a Unix socket.

use api::{HeadlessHost, Hub, listen_unix, serve_stdio};

use crate::cli::Transport;

/// Serves until stdin closes (stdio) or forever (socket). Returns the process exit code.
pub fn run(transport: Transport) -> i32 {
    let mut host = HeadlessHost::new();
    let mut hub = Hub::new(|| {});
    match transport {
        Transport::Stdio => {
            let writer = serve_stdio(hub.inbox());
            while hub.process_blocking(&mut host) && hub.open_connections() > 0 {}
            // Dropping the hub ends the writer once every queued reply is on stdout.
            drop(hub);
            let _ = writer.join();
            0
        }
        Transport::Socket(path) => {
            if let Err(e) = listen_unix(&path, hub.inbox()) {
                eprintln!("cannot listen on {}: {e}", path.display());
                return 1;
            }
            eprintln!("agent API listening on {}", path.display());
            while hub.process_blocking(&mut host) {}
            0
        }
    }
}
```

```rust
use std::path::PathBuf;
use std::sync::Arc;

use api::{Hub, listen_unix};
use glam::DVec2;
use render::{Renderer, Snapshotter};
use winit::application::ApplicationHandler;
use winit::dpi::LogicalSize;
use winit::event::{ElementState, MouseButton, MouseScrollDelta, WindowEvent};
use winit::event_loop::{ActiveEventLoop, EventLoop};
use winit::keyboard::{Key, KeyCode, ModifiersState, NamedKey, PhysicalKey};
use winit::window::{Window, WindowId};

use crate::editor::Editor;
use crate::host::WindowHost;
use crate::navigation::Button;

/// Sent to the event loop when an agent API request arrives.
#[derive(Debug)]
pub struct ApiWake;

/// Trackpad pixel deltas per zoom step.
const PIXELS_PER_SCROLL_STEP: f64 = 50.0;

struct State {
    window: Arc<Window>,
    surface: wgpu::Surface<'static>,
    device: wgpu::Device,
    queue: wgpu::Queue,
    config: wgpu::SurfaceConfiguration,
    renderer: Renderer,
    snapshotter: Snapshotter,
    editor: Editor,
    /// Document revision the renderer's model buffers were built from.
    drawn_revision: Option<u64>,
    modifiers: ModifiersState,
}

impl State {
    fn new(window: Arc<Window>) -> Self {
        let size = window.inner_size();
        let instance = wgpu::Instance::default();
        let surface = instance
            .create_surface(window.clone())
            .expect("create surface");
        let adapter = pollster::block_on(instance.request_adapter(&wgpu::RequestAdapterOptions {
            compatible_surface: Some(&surface),
            ..Default::default()
        }))
        .expect("no compatible GPU adapter");
        let (device, queue) =
            pollster::block_on(adapter.request_device(&wgpu::DeviceDescriptor::default()))
                .expect("request device");

        let mut config = surface
            .get_default_config(&adapter, size.width.max(1), size.height.max(1))
            .expect("surface not supported by adapter");
        // Colors are authored as sRGB values, so prefer a non-sRGB target that writes them as-is.
        // Keep the default format's channel layout when its non-sRGB twin is available.
        let caps = surface.get_capabilities(&adapter);
        let linear = config.format.remove_srgb_suffix();
        config.format = if caps.formats.contains(&linear) {
            linear
        } else {
            caps.formats
                .iter()
                .copied()
                .find(|f| !f.is_srgb())
                .unwrap_or(config.format)
        };
        surface.configure(&device, &config);

        let renderer = Renderer::new(&device, &queue, config.format);
        let snapshotter = Snapshotter::with_device(&device, &queue);
        let editor = Editor::new(
            DVec2::new(config.width as f64, config.height as f64),
            window.scale_factor(),
        );
        Self {
            window,
            surface,
            device,
            queue,
            config,
            renderer,
            snapshotter,
            editor,
            drawn_revision: None,
            modifiers: ModifiersState::empty(),
        }
    }

    fn resize(&mut self, width: u32, height: u32) {
        if width == 0 || height == 0 {
            return;
        }
        self.config.width = width;
        self.config.height = height;
        self.surface.configure(&self.device, &self.config);
        self.editor.resize(DVec2::new(width as f64, height as f64));
    }

    fn render(&mut self) {
        let frame = match self.surface.get_current_texture() {
            wgpu::CurrentSurfaceTexture::Success(frame)
            | wgpu::CurrentSurfaceTexture::Suboptimal(frame) => frame,
            wgpu::CurrentSurfaceTexture::Outdated | wgpu::CurrentSurfaceTexture::Lost => {
                self.surface.configure(&self.device, &self.config);
                self.window.request_redraw();
                return;
            }
            _ => return, // Timeout or occluded: skip this frame.
        };
        let view = frame
            .texture
            .create_view(&wgpu::TextureViewDescriptor::default());
        let revision = self.editor.doc().revision();
        if self.drawn_revision != Some(revision) {
            self.renderer.set_model(self.editor.doc().model());
            self.drawn_revision = Some(revision);
        }
        self.renderer.render(
            &view,
            (self.config.width, self.config.height),
            &self.editor.doc().camera,
            &self.editor.overlay(),
        );
        self.window.pre_present_notify();
        self.queue.present(frame);
    }

    /// Handles waiting API requests; redraws if they changed the model or camera.
    fn process_api(&mut self, hub: &mut Hub) {
        let before = (
            self.editor.doc().revision(),
            self.editor.doc().camera.clone(),
        );
        let mut host = WindowHost {
            editor: &mut self.editor,
            snapshotter: &mut self.snapshotter,
        };
        hub.process(&mut host);
        if (
            self.editor.doc().revision(),
            self.editor.doc().camera.clone(),
        ) != before
        {
            self.window.request_redraw();
        }
    }

    /// Tells API subscribers about edits made in the window.
    fn notify_api(&mut self, hub: &mut Hub) {
        let host = WindowHost {
            editor: &mut self.editor,
            snapshotter: &mut self.snapshotter,
        };
        hub.notify(&host);
    }
}

fn map_button(button: MouseButton) -> Button {
    match button {
        MouseButton::Left => Button::Left,
        MouseButton::Middle => Button::Middle,
        _ => Button::Other,
    }
}

pub struct App {
    state: Option<State>,
    hub: Hub,
    /// Socket the agent API listens on, removed on exit (None if listening failed).
    socket: Option<PathBuf>,
}

impl App {
    pub fn new(event_loop: &EventLoop<ApiWake>, socket: PathBuf) -> Self {
        let proxy = event_loop.create_proxy();
        let hub = Hub::new(move || {
            let _ = proxy.send_event(ApiWake);
        });
        let socket = match listen_unix(&socket, hub.inbox()) {
            Ok(()) => {
                eprintln!("agent API listening on {}", socket.display());
                Some(socket)
            }
            Err(e) => {
                eprintln!(
                    "agent API disabled: cannot listen on {}: {e}",
                    socket.display()
                );
                None
            }
        };
        Self {
            state: None,
            hub,
            socket,
        }
    }
}

impl ApplicationHandler<ApiWake> for App {
    fn user_event(&mut self, _event_loop: &ActiveEventLoop, _event: ApiWake) {
        if let Some(s) = self.state.as_mut() {
            s.process_api(&mut self.hub);
        }
    }

    fn resumed(&mut self, event_loop: &ActiveEventLoop) {
        if self.state.is_some() {
            return;
        }
        let attrs = Window::default_attributes()
            .with_title("tenon")
            .with_inner_size(LogicalSize::new(1280.0, 800.0));
        let window = Arc::new(event_loop.create_window(attrs).expect("create window"));
        let mut state = State::new(window);
        state.window.request_redraw();
        // Requests that arrived before the window existed.
        state.process_api(&mut self.hub);
        self.state = Some(state);
    }

    fn window_event(&mut self, event_loop: &ActiveEventLoop, _id: WindowId, event: WindowEvent) {
        let Some(s) = self.state.as_mut() else { return };
        let changed = match event {
            WindowEvent::CloseRequested => {
                if let Some(path) = self.socket.take() {
                    let _ = std::fs::remove_file(path);
                }
                event_loop.exit();
                false
            }
            WindowEvent::Resized(size) => {
                s.resize(size.width, size.height);
                true
            }
            WindowEvent::ScaleFactorChanged { scale_factor, .. } => {
                s.editor.set_scale_factor(scale_factor);
                false
            }
            WindowEvent::RedrawRequested => {
                s.render();
                false
            }
            WindowEvent::ModifiersChanged(m) => {
                s.modifiers = m.state();
                s.editor
                    .set_modifiers(m.state().shift_key(), m.state().alt_key());
                false
            }
            WindowEvent::Focused(false) => {
                s.editor.focus_lost();
                false
            }
            WindowEvent::CursorMoved { position, .. } => {
                s.editor.cursor_moved(DVec2::new(position.x, position.y))
            }
            WindowEvent::MouseInput { state, button, .. } => s
                .editor
                .button(map_button(button), state == ElementState::Pressed),
            WindowEvent::MouseWheel { delta, .. } => {
                let steps = match delta {
                    MouseScrollDelta::LineDelta(_, y) => y as f64,
                    MouseScrollDelta::PixelDelta(p) => p.y / PIXELS_PER_SCROLL_STEP,
                };
                s.editor.scroll(steps)
            }
            WindowEvent::KeyboardInput { event, .. } if event.state == ElementState::Pressed => {
                let command_key = s.modifiers.super_key() || s.modifiers.control_key();
                // Use the physical Z key only when the layout's character is not ASCII (e.g.
                // Arabic or Cyrillic), so Cmd+W on AZERTY does not undo.
                let is_z = match &event.logical_key {
                    Key::Character(c) if c.is_ascii() => c.eq_ignore_ascii_case("z"),
                    _ => event.physical_key == PhysicalKey::Code(KeyCode::KeyZ),
                };
                if event.logical_key == Key::Named(NamedKey::Escape) {
                    s.editor.cancel()
                } else if command_key && is_z {
                    if s.modifiers.shift_key() {
                        s.editor.redo()
                    } else {
                        s.editor.undo()
                    }
                } else {
                    false
                }
            }
            _ => false,
        };
        if changed {
            s.window.request_redraw();
            s.notify_api(&mut self.hub);
        }
    }
}
```

```markdown
# Agent API

Every edit the window can make is also a command agents can send. The API is JSON-RPC 2.0 with one
JSON object per line (UTF-8, `\n`-terminated).

## Starting

| Command | Where the API is |
|---|---|
| `cargo run -p app` | Window, plus a Unix socket (path printed on stderr: `agent API listening on ...`) |
| `cargo run -p app -- --socket PATH` | Window, socket at `PATH` |
| `cargo run -p app -- --headless --stdio` | No window; requests on stdin, replies on stdout; exits when stdin closes |
| `cargo run -p app -- --headless --socket PATH` | No window; socket at `PATH` |

The socket is readable only by the current user. Try it by hand with `nc -U PATH`.

## Methods

Call `describe` first: it returns every method, notification, error code and the JSON Schemas of
all commands and results.

| Method | Params | Result |
|---|---|---|
| `execute` | a Command, e.g. `{"type": "add_edge", "start": [0,0,0], "end": [1,0,0]}` | `{changes, revision}` |
| `batch` | `{"commands": [...], "atomic": true}` | `{outcomes, revision}`; atomic = one undo step, all or nothing |
| `query` | a Query, e.g. `{"type": "stats"}`, `{"type": "entities"}`, `{"type": "events", "since": 3}` | the QueryResult |
| `render_view` | `{"width": 640, "height": 400, "camera": {"eye": [...], "target": [...]}}` (camera optional) | `{width, height, png_base64}` |
| `subscribe` | none | `{revision}`, then `changed` notifications after every model change |
| `describe` | none | the API description |

Commands: `add_edge`, `undo`, `redo`, `set_camera`. Units are meters, Z is up, angles in degrees,
coordinates within +/-1,000,000 m. Entity ids are strings: `v12` (vertex), `e3` (edge), `f7` (face).

## Example

```
-> {"jsonrpc":"2.0","id":1,"method":"execute","params":{"type":"add_edge","start":[0,0,0],"end":[2,0,0]}}
<- {"jsonrpc":"2.0","id":1,"result":{"changes":{"created":["v0","v1","e2"],"deleted":[],"modified":[]},"revision":1}}
-> {"jsonrpc":"2.0","id":2,"method":"query","params":{"type":"stats"}}
<- {"jsonrpc":"2.0","id":2,"result":{"type":"stats","vertices":2,"edges":1,"faces":0,"revision":1}}
```

## Errors

Standard JSON-RPC codes (-32700 parse, -32600 invalid request, -32601 unknown method, -32602 bad
params) plus `-32000` command failed (`data` is `{kind, message, ids?}`), `-32001` batch failed
(`data` is `{index, error, completed, rolled_back}`) and `-32002` rendering unavailable.
```
