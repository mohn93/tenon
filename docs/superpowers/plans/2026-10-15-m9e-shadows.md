# M9e Light Shadows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The lights of M9c cast shadows: up to 64 lights (the strongest at the camera, by M9c's ranking) each get a cube shadow map (256 px faces, 16-bit depth, one cube-map array), kept between frames and redrawn only when the casters change or a light enters the shadowed set or moves; glowing faces cast none; lookups are filtered and biased; a golden image shows a wall shading the floor behind it from a lamp.

**Architecture:**
- `render::shadows` (new, CPU only): `MAX_SHADOWS` = 64, `SHADOW_SIZE` = 256, `SHADOW_FORMAT` = `Depth16Unorm`, `ShadowKey` (a light as uploaded: position and range), `ShadowSlots` (which slot of the array holds which light's map, drawn for which caster generation; `assign` keeps slots and lists the stale ones), `capacity_for`, `cube_faces` (the six view-projections matching WebGPU's cube-face selection) and `face_sees` (box against a cube face's view).
- `scene_base` also lists the casters: the root-coordinate corners of every triangle of a face with no glowing side (`SceneBase.casters`), in a chunk per placement with its bounding box (`SceneBase.caster_chunks`, `CasterChunk::reaches`).
- `render::shadow_maps` (new, GPU): the `Depth16Unorm` array texture (six layers a slot, viewed as a cube-map array for lookups and layer by layer for drawing), a depth-only pipeline (`shaders/shadow.wgsl`) writing each caster's distance from the light over its range as `frag_depth`, a dynamic-offset uniform per cube face; it starts with one slot and grows by powers of two up to 64. Each face draws only the chunks that reach the light and lie in its view, neighbours merged into one draw.
- `Renderer`: each frame it takes M9c's 128 strongest lights, the strongest 64 of those are shadowed; `ShadowSlots::assign` decides which maps to draw (recorded in the frame's encoder before the main pass); each light's slot goes to the shader in its color's w (-1: no shadow). The casters' generation bumps in `set_model` only when their corners differ from the last ones, so `render_view` (which rebuilds the scene every call), selection, opening a group or repainting do not redraw maps. The scene shader is `scene.wgsl` followed by `shadow_lookup.wgsl` (bindings 4 and 5: the cube-map array and a comparison sampler; normal offset, bias, four filtered taps) or, on devices that cannot have cube-map arrays, `no_shadows.wgsl` (no extra bindings, `shadow` returns 1). `render::required_limits(adapter)` asks for the array layers the maps need; the window, `Snapshotter::new_headless` and the headless tests use it.

**Tech Stack:** Rust 2024; wgpu 30, glam 0.34. No new dependencies, no new wgpu features.

**Spec:** `docs/superpowers/specs/2026-10-10-tenon-design.md` ("Post-v1 milestones", M9e; M9c for the lights).

## Spec notes (rulings made in this plan)

- **Depth format and what the maps hold.** `Depth16Unorm` (core in WebGPU, no feature), 256 x 256 per face, one `D2` texture of `6 x slots` layers viewed as `CubeArray` for lookups and as single `D2` layers for drawing. The shadow pass writes each caster's straight-line distance from the light divided by the light's range as `frag_depth` (depth test `Less`, cleared to 1), not the hardware's perspective depth: the precision is even over the range (range / 65535, 0.1 mm for a 6 m light), and a lookup compares its own distance in any direction without per-face depth math. The projection still clips at 2 cm (`SHADOW_NEAR`) along the face's axis and at the range, so a caster nearer a light than 2 cm casts no shadow from it.
- **Device limits and features.** No wgpu features are needed: depth formats, comparison samplers and cube-map arrays are core WebGPU; cube-map arrays are a downlevel flag (`CUBE_ARRAY_TEXTURES`) that Metal has on every Mac wgpu 30 supports, and the headless golden-image path uses the same Metal adapter, so goldens show shadows. The one limit that matters is `max_texture_array_layers`: the default 256 holds only 42 cube maps, so `render::required_limits(adapter)` asks for the default limits with `max_texture_array_layers` raised to `min(384, the adapter's)` (Metal reports 2048); the window (`app.rs`), `Snapshotter::new_headless` and `tests/headless.rs` request devices with it. A device given by a caller with fewer layers gets `min(64, layers / 6)` slots.
- **Falling back.** wgpu-core does not reject a cube-array view on devices without the downlevel flag; naga rejects a shader declaring `texture_depth_cube_array`. So `Renderer::new` compiles the shadowed scene shader inside a validation error scope: if the device rejects it, or allows no slot, the renderer uses `no_shadows.wgsl` and a bind group layout without bindings 4 and 5, and lights light as in M9c (`Renderer::casts_shadows` is false). `Renderer::without_shadows` builds that path on purpose, so a test covers it on this machine.
- **The shadowed set.** Each frame the renderer ranks as M9c does (`strongest`: strength over 1 + d^2, d the eye's distance): the 128 used lights, then the strongest `slots` (64) of those are shadowed; with 64 or fewer lights all are. Lights 65 to 128 light without shadows.
- **Slots and caching.** A light has no id, so its identity is its `ShadowKey`: its position and range as uploaded (f32). A moved or resized light, or a light whose placement changed, is a new light. `ShadowSlots` keeps, per slot, the key and caster generation it was drawn for. Each frame a light already held keeps its slot; new lights take slots no light of this frame holds, empty ones first; a slot is drawn again when it changes hands or its generation is old. Slots not used this frame keep their maps, so a light leaving the set and coming back (the camera moving among more than 64 lights) finds its map unless the slot was taken. Two lights at the same place with the same range share a slot. The array starts with one slot (768 KiB) and grows to the next power of two as more lights are shadowed, up to 64 (48 MiB); it never shrinks; growing draws every map again.
- **When the geometry changes.** `Renderer` keeps a copy of the last casters' corners; `set_model` bumps the generation only when the new corners differ (one comparison of a `Vec<[f32; 3]>`). So a camera move, a selection change, opening or closing a group, repainting with a non-glowing material, or `render_view` (whose `Snapshotter::capture` sets the scene on every call) draws no shadow map; any edit moving a casting face draws all shadowed lights' maps again in the next frame.
- **Per-light culling.** The casters are grouped by placement: each placement of a mesh contributes one chunk of its own casting triangles (the root's loose geometry is one chunk), with their root-coordinate bounding box. A cube face draws a chunk when its box comes nearer the light than the range (`CasterChunk::reaches`) and lies at least partly in the face's 90-degree view (`face_sees`); consecutive chunks are drawn with one call. Nothing finer: a root holding a whole house is drawn into every face that sees part of it.
- **Glowing faces.** A triangle of a face with a glowing side (its own material or the nearest painted instance's, as for the light itself) casts nothing: a lamp's glowing shade does not hide its own light, nor another lamp's. Everything else casts, from both sides (the shadow pipeline culls nothing), including see-through faces (the spec says everything else; a window pane stops lamp light).
- **Bias and filter.** In the lookup the point moves 1.5 shadow-map texels (a texel is 2d / 256 at distance d) along the shaded side's normal, then its distance is shortened by 2 cm before comparing; the comparison sampler (`LessEqual`, linear filtering) gives 2 x 2 texel filtering per lookup, and four lookups 1.5 texels apart across the direction are averaged. Only lit points look up: a point out of range or facing away from the light takes nothing from it as before.
- **Day and night.** The shadowed term is the lamp light only; the headlight and ambient light are unchanged, so shadows show by day too (fainter) and at night.
- **Uniforms.** No layout change: `LightUniform.color.w` carries the light's slot, or -1 without a shadow map. Bind group 0 gains binding 4 (`texture_depth_cube_array`) and 5 (`sampler_comparison`) when shadows are on.
- **Golden images.** New `shadow.png`: a lamp lower than a wall's top lights the wall's near side and the floor around it, and the floor behind the wall stays dark in a wedge. Every existing golden image still matches (in `night` the box's shadows fall behind it, out of view, within the tolerance).

```rust
//! Shadows of the lights (see `lights`): the strongest lights at the camera each get a cube
//! shadow map, a layer of one cube-map array, holding how far the nearest caster is in every
//! direction. A map is kept between frames and drawn again only when the casters change or
//! its slot is given to another light (see `ShadowSlots`).

use glam::{Mat4, Vec3, Vec4};

use crate::lights::Light;

/// The most lights that cast shadows: the strongest at the camera of those lit.
pub const MAX_SHADOWS: usize = 64;

/// The side of a cube shadow map's faces, in pixels.
pub const SHADOW_SIZE: u32 = 256;

/// Shadow maps hold the distance to the nearest caster over the light's range, 0 to 1.
pub const SHADOW_FORMAT: wgpu::TextureFormat = wgpu::TextureFormat::Depth16Unorm;

/// How near a caster can come to its light, in meters, and still cast.
pub const SHADOW_NEAR: f32 = 0.02;

/// A light as its shadow map was drawn for it: where it is and how far it reaches, as the
/// renderer uploads them. A light that keeps both keeps its map.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct ShadowKey {
    pub position: [f32; 3],
    pub range: f32,
}

impl ShadowKey {
    pub fn of(light: &Light) -> Self {
        Self {
            position: light.position.as_vec3().to_array(),
            range: light.range() as f32,
        }
    }
}

/// Which slot of the cube-map array holds which light's shadow map, and for which casters.
#[derive(Clone, Debug, Default, PartialEq)]
pub struct ShadowSlots {
    /// What each slot holds: the light and the casters' generation it was drawn for.
    held: Vec<Option<(ShadowKey, u64)>>,
}

/// What `ShadowSlots::assign` decided for a frame.
#[derive(Clone, Debug, Default, PartialEq)]
pub struct Assignment {
    /// Each shadowed light's slot, in the order given.
    pub slots: Vec<usize>,
    /// The slots to draw again, in increasing order.
    pub redraw: Vec<usize>,
}

impl ShadowSlots {
    /// `capacity` empty slots.
    pub fn new(capacity: usize) -> Self {
        Self {
            held: vec![None; capacity],
        }
    }

    pub fn capacity(&self) -> usize {
        self.held.len()
    }

    /// Gives each of `lights` (at most the capacity) a slot for casters of `generation`. A
    /// light keeps the slot already holding it; the others take slots no light of this frame
    /// holds, empty ones first. A slot is drawn again when it changes hands or was drawn for
    /// other casters. Slots left over keep their maps, so a light that comes back finds its
    /// map unless the slot was taken meanwhile.
    pub fn assign(&mut self, lights: &[ShadowKey], generation: u64) -> Assignment {
        assert!(
            lights.len() <= self.capacity(),
            "more shadowed lights than slots"
        );
        let mut slots: Vec<Option<usize>> = vec![None; lights.len()];
        let mut taken = vec![false; self.capacity()];
        // Lights already held keep their slots (a light given twice shares one).
        for (k, key) in lights.iter().enumerate() {
            if let Some(s) = self
                .held
                .iter()
                .position(|h| h.is_some_and(|(h, _)| h == *key))
            {
                slots[k] = Some(s);
                taken[s] = true;
            }
        }
        for k in 0..lights.len() {
            if slots[k].is_some() {
                continue;
            }
            if let Some(j) = (0..k).find(|&j| lights[j] == lights[k]) {
                slots[k] = slots[j];
                continue;
            }
            let free = (0..self.capacity())
                .filter(|&s| !taken[s])
                .min_by_key(|&s| self.held[s].is_some())
                .expect("a free slot");
            slots[k] = Some(free);
            taken[free] = true;
        }
        let slots: Vec<usize> = slots.into_iter().map(|s| s.expect("assigned")).collect();
        let mut redraw = Vec::new();
        for (key, &s) in lights.iter().zip(&slots) {
            if self.held[s] != Some((*key, generation)) {
                self.held[s] = Some((*key, generation));
                redraw.push(s);
            }
        }
        redraw.sort_unstable();
        redraw.dedup();
        Assignment { slots, redraw }
    }
}

/// How many slots to make room for `needed` shadowed lights: the next power of two, at most
/// `max`, so a scene gaining lights reallocates the array only a few times.
pub fn capacity_for(needed: usize, max: usize) -> usize {
    needed.max(1).next_power_of_two().min(max)
}

/// The cube faces in array-layer order (+x, -x, +y, -y, +z, -z): the face's axis, then the
/// directions a lookup reads as the face's s (right) and t (down) coordinates, as WebGPU
/// picks cube faces.
const CUBE_FACES: [[Vec3; 3]; 6] = [
    [Vec3::X, Vec3::NEG_Z, Vec3::NEG_Y],
    [Vec3::NEG_X, Vec3::Z, Vec3::NEG_Y],
    [Vec3::Y, Vec3::X, Vec3::Z],
    [Vec3::NEG_Y, Vec3::X, Vec3::NEG_Z],
    [Vec3::Z, Vec3::X, Vec3::NEG_Y],
    [Vec3::NEG_Z, Vec3::NEG_X, Vec3::NEG_Y],
];

/// The view-projections drawing the six faces of a cube shadow map around a light at
/// `position` reaching `range`, in array-layer order. Each puts a point where a cube-map
/// lookup in its direction from the light reads; clip depth runs from 0 at SHADOW_NEAR along
/// the face's axis to 1 at the range, so casters nearer or beyond are clipped.
pub fn cube_faces(position: Vec3, range: f32) -> [Mat4; 6] {
    let (n, f) = (SHADOW_NEAR, range.max(2.0 * SHADOW_NEAR));
    let (a, b) = (f / (f - n), -f * n / (f - n));
    CUBE_FACES.map(|[axis, s, t]| {
        let row = |v: Vec3, w: f32| Vec4::new(v.x, v.y, v.z, w - v.dot(position));
        // x = s, y = -t (clip y runs up, t down), w = the distance along the axis.
        Mat4::from_cols(row(s, 0.0), row(-t, 0.0), row(a * axis, b), row(axis, 0.0)).transpose()
    })
}

/// Whether any of the box from `lo` to `hi` lies in the view of cube face `face` (in
/// array-layer order) of a light at `light`: a box wholly outside one of the four planes
/// bounding the face's view is not, and need not be drawn into it.
pub fn face_sees(face: usize, light: Vec3, lo: Vec3, hi: Vec3) -> bool {
    let [axis, s, t] = CUBE_FACES[face];
    let corners: [Vec3; 8] = std::array::from_fn(|k| {
        let pick = |bit: usize, a: f32, b: f32| if k & bit == 0 { a } else { b };
        Vec3::new(
            pick(1, lo.x, hi.x),
            pick(2, lo.y, hi.y),
            pick(4, lo.z, hi.z),
        ) - light
    });
    // Inside the view: |s.v| <= axis.v and |t.v| <= axis.v.
    [s, -s, t, -t]
        .iter()
        .all(|&side| corners.iter().any(|&v| v.dot(axis) - v.dot(side) >= 0.0))
}

        let mut s = ShadowSlots::new(4);

        let a = s.assign(&[key(1.0), key(2.0), key(3.0)], 0);
        assert_eq!(a.slots, vec![0, 1, 2]);

        let c = s.assign(&[key(1.0), key(3.0), key(4.0)], 0);

    #[test]
    fn each_direction_lands_on_its_cube_face_where_a_lookup_reads_it() {
        let light = Vec3::new(1.0, -2.0, 3.0);
        let faces = cube_faces(light, 10.0);
        // Directions from the light, each with its face and the (s, t) a lookup reads.
        let cases = [
            (Vec3::new(2.0, 0.5, -1.0), 0),
            (Vec3::new(-2.0, -0.5, 1.0), 1),
            (Vec3::new(0.5, 2.0, 1.0), 2),
            (Vec3::new(-0.5, -2.0, 1.0), 3),
            (Vec3::new(1.0, -0.5, 2.0), 4),
            (Vec3::new(1.0, 0.5, -2.0), 5),
        ];
        for (v, face) in cases {
            let [axis, s, t] = CUBE_FACES[face];
            let major = v.dot(axis);
            assert!(major > 0.0 && major >= v.abs().max_element() - 1e-6);
            let expected = Vec3::new(v.dot(s) / major, -v.dot(t) / major, 0.0);
            let clip = faces[face] * (light + v).extend(1.0);
            assert!((clip.w - major).abs() < 1e-5, "face {face}: w {}", clip.w);
            let ndc = clip.truncate() / clip.w;
            assert!(
                ndc.x.abs() <= 1.0 && ndc.y.abs() <= 1.0,
                "face {face}: {ndc}"
            );
            assert!(
                (ndc.truncate() - expected.truncate()).length() < 1e-5,
                "face {face}"
            );
            assert!(ndc.z > 0.0 && ndc.z < 1.0, "face {face}: depth {}", ndc.z);
        }
        // Depth is 0 at the near distance and 1 at the range along the axis.
        let near = faces[4] * (light + Vec3::Z * SHADOW_NEAR).extend(1.0);
        let far = faces[4] * (light + Vec3::Z * 10.0).extend(1.0);
        assert!((near.z / near.w).abs() < 1e-4);
        assert!((far.z / far.w - 1.0).abs() < 1e-5);
```

```wgsl
// Drawing cube shadow maps (see shadows.rs): each face of a light's map keeps, in every
// direction, how far the nearest caster is over the light's range.

struct Face {
    view_proj: mat4x4<f32>,
    // xyz: the light; w: its range.
    light: vec4<f32>,
};

@group(0) @binding(0) var<uniform> face: Face;

struct Out {
    @builtin(position) pos: vec4<f32>,
    @location(0) world: vec3<f32>,
};

@vertex
fn vs_shadow(@location(0) pos: vec3<f32>) -> Out {
    var out: Out;
    out.pos = face.view_proj * vec4<f32>(pos, 1.0);
    out.world = pos;
    return out;
}

// The distance from the light rather than the depth along the face's axis, so a lookup in any
// direction compares like with like.
@fragment
fn fs_shadow(in: Out) -> @builtin(frag_depth) f32 {
    return min(distance(in.world, face.light.xyz) / face.light.w, 1.0);
}
```

```wgsl
// Shadow lookups (see shadows.rs), appended to scene.wgsl on devices with cube-map arrays.

// A cube shadow map per shadowed light, and a sampler comparing a distance with them.
@group(0) @binding(4) var shadow_maps: texture_depth_cube_array;
@group(0) @binding(5) var shadow_sampler: sampler_comparison;

// SHADOW_SIZE in shadows.rs.
const SHADOW_SIZE: f32 = 256.0;
// Against acne (a surface shadowing itself): the lookup point is moved this many shadow-map
// texels off the surface on its lit side, and a caster must be this many meters nearer the
// light than the point to hide it.
const SHADOW_NORMAL_OFFSET: f32 = 1.5;
const SHADOW_BIAS: f32 = 0.02;

// How much of `light`, with its shadow map in `slot`, reaches `p` on a surface facing `n` toward
// it: 1 lit, 0 hidden. Four lookups 1.5 texels apart, each filtered over 2 x 2 texels by the
// comparing sampler, soften the edge.
fn shadow(light: Light, slot: i32, p: vec3<f32>, n: vec3<f32>) -> f32 {
    let center = light.position.xyz;
    // A texel's width at the point's distance: a face spans twice the distance at its middle.
    let texel = 2.0 * distance(p, center) / SHADOW_SIZE;
    let v = p + n * (SHADOW_NORMAL_OFFSET * texel) - center;
    let reference = (length(v) - SHADOW_BIAS) / light.position.w;
    // Two directions across v, a texel long there.
    let other = select(vec3<f32>(0.0, 0.0, 1.0), vec3<f32>(1.0, 0.0, 0.0), abs(v.z) > 0.9 * length(v));
    let a = normalize(cross(v, other)) * texel;
    let b = normalize(cross(v, a)) * texel;
    var lit = 0.0;
    for (var k = 0; k < 4; k++) {
        let s = select(-0.75, 0.75, (k & 1) == 1);
        let t = select(-0.75, 0.75, (k & 2) == 2);
        lit += textureSampleCompareLevel(shadow_maps, shadow_sampler, v + a * s + b * t, slot, reference);
    }
    return 0.25 * lit;
}
```

```rust
    fn allocate(
        device: &wgpu::Device,
        face_layout: &wgpu::BindGroupLayout,
        stride: u64,
        capacity: usize,

    /// map is then drawn again, and the scene's bind group must take the new view).
    pub fn grow(&mut self, device: &wgpu::Device, needed: usize) -> bool {
        let capacity = capacity_for(needed, self.max);
        if capacity <= self.slots.capacity() {
            return false;
        }
        let (faces, face_group, cubes, layers) =
            Self::allocate(device, &self.face_layout, self.stride, capacity);
        self.faces = faces;
        self.face_group = face_group;
        self.cubes = cubes;
        self.layers = layers;
        self.slots = ShadowSlots::new(capacity);
        true
    }

    /// Records drawing the maps of `slots` (each given with its light) from `casters`: each
    /// face draws only the placements whose bounds reach the light and lie in its view.
    pub fn draw(
        &mut self,
        queue: &wgpu::Queue,
        encoder: &mut wgpu::CommandEncoder,
        slots: &[(usize, ShadowKey)],
        casters: &Casters,
    ) {
        for &(slot, key) in slots {
            let position = glam::Vec3::from(key.position);
            let [x, y, z] = key.position;
            for (k, view_proj) in cube_faces(position, key.range).iter().enumerate() {
                let face = FaceUniform {
                    view_proj: view_proj.to_cols_array(),
                    light: [x, y, z, key.range],
                };
                let layer = 6 * slot + k;
                let offset = self.stride * layer as u64;
                queue.write_buffer(&self.faces, offset, bytemuck::bytes_of(&face));
                let mut pass = encoder.begin_render_pass(&wgpu::RenderPassDescriptor {
                    label: Some("shadow face"),
                    color_attachments: &[],
                    depth_stencil_attachment: Some(wgpu::RenderPassDepthStencilAttachment {
                        view: &self.layers[layer],
                        depth_ops: Some(wgpu::Operations {
                            load: wgpu::LoadOp::Clear(1.0),
                            store: wgpu::StoreOp::Store,
                        }),
                        stencil_ops: None,
                    }),
                    ..Default::default()
                });
                self.drawn += 1;
                let Some(buffer) = casters.buffer else {
                    continue;
                };
                pass.set_pipeline(&self.pipeline);
                pass.set_bind_group(0, &self.face_group, &[offset as u32]);
                pass.set_vertex_buffer(0, buffer.slice(..));
                // Placements next to each other in the buffer are drawn in one call.
                let mut run: Option<std::ops::Range<u32>> = None;
                for chunk in casters.chunks {
                    let (lo, hi) = (chunk.lo.into(), chunk.hi.into());
                    if !chunk.reaches(position, key.range) || !face_sees(k, position, lo, hi) {
                        continue;
                    }
                    match &mut run {
                        Some(r) if r.end == chunk.vertices.start => r.end = chunk.vertices.end,
                        _ => {
                            if let Some(r) = run.replace(chunk.vertices.clone()) {
                                pass.draw(r, 0..1);
                            }
                        }
                    }
                }
                if let Some(r) = run {
                    pass.draw(r, 0..1);
                }
            }
        }
    }
}
```
