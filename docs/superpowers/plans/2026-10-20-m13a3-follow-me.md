# M13a3 Follow Me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SketchUp's Follow Me: sweep a profile face along a path of connected edges (an open path, a closed loop, or the edges of a circle around the profile to lathe it), as a command and a tool agents can drive.

**Architecture:** A pure sweep function in the kernel computes, for each path vertex, the profile section on that vertex's miter plane (profile carried along by a rotation-minimising frame: each segment's rotation is the previous one turned from the previous direction to the next), checks that sections never fold back, and returns the side faces (one planar quad strip per profile side and path segment) and the two caps of an open path. The `follow_me` command draws them in the open context with sticky geometry, removes the profile face (it becomes the start cap), and softens joints along curves the way Push/Pull does. The tool follows the Paint/Push-Pull pick pattern.

**Tech Stack:** Rust 2024, glam. No new dependencies.

**Spec:** `docs/superpowers/roadmap.md` row M13a3; the M13a bullet in `docs/superpowers/specs/2026-10-10-tenon-design.md` ("Follow Me (face along a path or around a circle's edges)").

## Spec notes (rulings)

1. **Command:** `follow_me {face, path}`: `face` is the profile face; `path` is edges forming one connected chain (open or closed; branching is `invalid_input`) that does not include the profile's own edges unless `path` is exactly the outer loop of another face (the lathe case is given as edges of a circle, which are ordinary edges here). Path segments shorter than `10 * LENGTH_TOL` are `invalid_input`. One undo step, label `follow_me`.
2. **Where the sweep starts:** the path end nearest the profile's plane (for a closed path, the path vertex nearest that plane; ties go to the first in chain order) is the start; the path is walked from there. The profile is carried as it is (not moved onto the path), so a profile drawn away from the path (lathe) sweeps around it.
3. **Sections** (`crates/kernel/src/sweep.rs`, pure): `pub fn sweep(profile: &[Vec<DVec3>], profile_normal: DVec3, path: &[DVec3], closed: bool) -> Result<Sweep, SweepError>` with `pub struct Sweep { pub sections: Vec<Vec<Vec<DVec3>>> /* per path vertex, per profile loop */, pub caps: bool }`. Segment k's frame is the previous frame turned by the rotation taking direction `d_{k-1}` to `d_k` (rotation-minimising; the first frame is the identity). At an interior vertex `i` the section is segment `i-1`'s carried profile projected along `d_{i-1}` onto the miter plane through `P_i` with normal `normalize(d_{i-1} + d_i)`; at an open path's start the section is the profile projected along `d_0` onto the plane through `P_0` perpendicular to `d_0`, and at its end onto the plane through `P_n` perpendicular to `d_{n-1}`; a closed path's last joint meets the first section (the frame must close: when the accumulated rotation does not return to the identity within 1e-9 the remaining twist is spread evenly over the segments). `SweepError::{Folds, Degenerate}`: a profile point's distance along a segment between its two sections is negative or below `LENGTH_TOL` (the profile is too big for that turn), or a section is degenerate (a U-turn: `d_{i-1} + d_i` near zero).
4. **Geometry drawn:** for every profile loop side and every segment, the quad between the two sections (planar by construction); for an open path, the start and end caps (each a face with the profile's holes); the profile face itself is removed (its edges stay only where they bound new faces). Faces are drawn with sticky geometry, so they merge with what they touch. Softening: an edge along the path (between two side quads of one segment pair) is soft when the two path segments meeting there belong to one non-polygon curve; an edge across the sweep (between two quads of adjacent profile sides) is soft when those two profile sides belong to one non-polygon curve — the same rule Push/Pull applies to pulled curves. Front faces point outward (orient side faces away from the path; caps away from the solid).
5. **Tool:** Follow Me tool, key `j` (check it is free; SketchUp has no default), label "Follow Me", icon an existing egui-phosphor glyph that reads as a path (e.g. `ph::PATH`), modify group after Offset. Flow: with path edges selected, clicking a face runs `follow_me` with the selection as the path; with one face selected (and nothing else), clicking another face uses the selected face's outer loop as the path (the lathe gesture); with nothing usable selected, the tool says "Select the path edges, then click the profile face". Refusals show the command's message.
6. **tool_input:** the tool works through `tool_input` (select via commands, then click a face point).

## Review Focus

1. A square profile swept along an L-shaped path makes a closed solid (every edge bounds two faces) with a mitred corner. Test in Task 1.
2. A rectangle profile beside a circle (24 segments) swept around the circle's edges makes a ring (torus-like) with soft joints and no caps. Test in Task 1.
3. A profile too large for a sharp turn is refused (`Folds`), never drawn self-intersecting. Test in Task 1.
4. A circle profile swept along a path gives soft sides; a polygon profile gives hard sides. Test in Task 1.
5. The tool's lathe gesture (a face selected, another face clicked) runs `follow_me` with the selected face's loop. Test in Task 2.
