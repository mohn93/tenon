# M5c Files Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Models are saved and opened as `.skr` files, by agents and in the window. Definitions can be renamed, and unused ones purged.

**Architecture:**
- **kernel:**
  - A scene converts to and from plain data (`SceneData`) that keeps every id and the id counter (`data.rs`).
  - Loading validates the result.
  - `Scene::rename_definition` adds an invertible `Step::RenameDefinition`.
  - `Scene::purge` removes definitions no instance places.
- **session:**
  - A `.skr` file is a zip archive holding `document.json`: format name, schema version, camera, and model (`file.rs`).
  - New commands:
    - `new`, `open`, `save` (not undo steps; `new` and `open` reset history and tell subscribers to resync);
    - `rename_definition`, `purge_definitions` (undo steps).
  - New query: `file` (path, modified).
- **app:**
  - `app [options] [FILE]` opens a file at start; headless mode exits with code 1 if it cannot.
  - The window gets a File menu and Cmd+N/O/S, Shift+Cmd+S, using native dialogs (rfd).
  - The title shows the file name and an unsaved-changes marker.
  - Unsaved changes prompt before New, Open and closing the window.
- **api/docs:** the methods need no change, since the new commands and query come through the schemas. Tests cover `describe` and the resync after `open`, and `agent-api.md` gets a Files section.

**Tech Stack:** Rust 2024. New dependencies, pinned like the others:
- `zip = "=9.0.2"`, with default features off and only `deflate-flate2-zlib-rs` (pure Rust). MIT. Used in session.
- `rfd = "=0.17.2"` (native dialogs). MIT. Used in app.

**Spec:** `docs/superpowers/specs/2026-10-10-tenon-design.md`:
- section 4 (native format `.skr`: zip with versioned JSON, schema version field);
- section 5 (commands: file new, open, save);
- the milestones. Task 3 splits M5 files work into M5c (this plan) and M5d (export).

## Global Constraints

- Every new capability is a `session::Command` or `Query` reachable through the API, covered by a command-driven test. The window only issues commands.
- Each modeling command is one undo step. `new`, `open` and `save` are not undo steps; `new` and `open` clear history.
- Dependencies: only `zip` (session) and `rfd` (app) are added, at the exact versions above. `Cargo.lock` changes only as cargo resolves them.
- Git:
  - work on `dev`;
  - stage only the files you changed (including `Cargo.lock` when a task adds a dependency);
  - short plain commit messages, no emoji;
  - run `cargo fmt --all` before each commit;
  - `cargo clippy --workspace --all-targets -- -D warnings` stays clean.
- Do not launch the app window. Dialog code is a thin layer over editor methods, which tests drive directly.

## Spec notes (rulings made in this plan)

- **Scope split.** File work splits into M5c (native files, this plan) and M5d (export to OBJ, STL and glTF). Import of OBJ and STL is in M8 per the roadmap.
- **Format.**
  - A `.skr` file is a zip with one entry, `document.json`, deflated.
  - That entry holds `{format: "tenon", schema_version: 1, camera: {eye, target, fov_y_deg}, model: SceneData}`.
  - `SceneData` keeps:
    - every vertex, edge, face, instance and definition under its id, with ids as plain numbers;
    - `next_id`, so ids used before saving (even by undone edits) are never handed out again after opening.
  - Reading checks `format` and `schema_version` before the rest, so a file from a newer version fails with a clear message.
  - Unknown fields are rejected. Loading validates the scene: model invariants, missing definitions, cycles, ids unique across meshes, finite numbers.
- **Saving** writes `<path>.partial` and renames it over the target, so a failed save never leaves a half-written model behind.
- **Commands.**
  - `save` without a path saves to the file last opened or saved; for a model never saved, that is `invalid_input`.
  - `open` and `new` reset the undo history, selection and open context, and change the revision. They clear the event log, so `events` and `subscribe` report `truncated`/`resync`.
  - Failures are the new error kind `file`, with the path and the reason; the model is left as it was.
  - `new`, `open` and `save` are not allowed in atomic batches.
  - `Command::changes_model` is false for `save`.
- **"Modified"** is whether the revision differs from the one when the model was opened, saved or started. Undoing back to the saved state still counts as modified, which is simple and safe.
- **Opened camera.** A saved view the camera checks reject (eye straight above the target, say) opens with the default view instead of failing the open.
- **Purge** removes every definition no instance places, repeatedly, so a component used only by an unused component goes too. It is one undo step.
- **Rename** works on any definition. A component's name must not be empty; a group's may be.
- **Paths** in commands are used as given, relative to the app's working directory. The API is local and only the user's own processes can reach it, so no further path restrictions are applied.
- **Command line.** `FILE` is a positional argument in any mode, and a second positional argument is an error. Headless mode exits with code 1 if the file cannot be opened; the window shows an empty model and prints the error.
- **Window.**
  - The File menu is the first item of the toolbar row, with New (Cmd+N), Open... (Cmd+O), Save (Cmd+S) and Save As... (Shift+Cmd+S).
  - The title is `<name>[*] - tenon`.
  - With unsaved changes, New, Open and closing the window first ask "Save the changes to <name> first?" (Yes, No, Cancel). Yes saves, using a dialog when the model was never saved, and goes on only if the save worked.
  - Shortcut letters follow the layout when it types ASCII, and the physical key otherwise. This replaces the M2b Cmd+Z rule with one helper and keeps its behavior.

//! Scenes as plain data (for files): round trips, rejected data, renaming and purging.

use glam::DVec3;
use kernel::{DefinitionKind, KernelError, MeshId, Model, Scene, SceneData};

fn p(x: f64, y: f64, z: f64) -> DVec3 {
    DVec3::new(x, y, z)
}

/// A box grouped and made a component, copied twice, plus a loose edge in the root.
fn scene() -> Scene {
    let mut m = Model::new();
    m.add_polygon(&[
        p(0.0, 0.0, 0.0),
        p(2.0, 0.0, 0.0),
        p(2.0, 2.0, 0.0),
        p(0.0, 2.0, 0.0),
    ])
    .unwrap();
    let base = m.faces().next().unwrap().0;
    m.push_pull(base, 1.0).unwrap();
    let mut s = Scene::from_root(m);
    let edges: Vec<_> = s.root().edges().map(|(id, _)| id).collect();
    let faces: Vec<_> = s.root().faces().map(|(id, _)| id).collect();
    let (group, _) = s
        .make_group(MeshId::Root, &edges, &faces, &[], DefinitionKind::Group, "")
        .unwrap();
    let (crate_, _) = s
        .make_group(
            MeshId::Root,
            &[],
            &[],
            &[group],
            DefinitionKind::Component,
            "Crate",
        )
        .unwrap();
    s.copy_instances(MeshId::Root, &[crate_], p(3.0, 0.0, 0.0), 2)
        .unwrap();
    s.edit(MeshId::Root, |m| {
        m.add_edge(p(0.0, -2.0, 0.0), p(1.0, -2.0, 0.0))
    })
    .unwrap();
    s.validate().unwrap();
    s
}

fn round_trip(s: &Scene) -> Scene {
    let json = serde_json::to_string(&s.to_data()).unwrap();
    let data: SceneData = serde_json::from_str(&json).unwrap();
    Scene::from_data(&data).unwrap()
}

#[test]
fn a_scene_survives_a_round_trip_with_its_ids() {
    let s = scene();
    let back = round_trip(&s);
    assert_eq!(back, s);
    assert_eq!(back.to_data(), s.to_data());
}

#[test]
fn ids_after_loading_continue_where_they_stopped() {
    let mut s = scene();
    // Undoing an edit leaves its ids used: they must stay unused after a round trip too.
    let undone = s
        .edit(MeshId::Root, |m| {
            m.add_edge(p(5.0, 5.0, 0.0), p(6.0, 5.0, 0.0))
        })
        .unwrap();
    s.apply(&undone.inverse());
    let mut back = round_trip(&s);
    let fresh = back
        .edit(MeshId::Root, |m| {
            m.add_edge(p(7.0, 5.0, 0.0), p(8.0, 5.0, 0.0))
        })
        .unwrap()
        .summary()
        .created;
    for id in fresh {
        assert!(!undone.summary().created.contains(&id), "{id} reused");
    }
}

/// Plain data for `scene()`, changed by `f`, must be rejected with a message containing
/// `expected`.
fn rejects(f: impl FnOnce(&mut SceneData), expected: &str) {
    let mut data = scene().to_data();
    f(&mut data);
    let err = Scene::from_data(&data).unwrap_err();
    assert!(err.contains(expected), "{err:?} lacks {expected:?}");
}

#[test]
fn renaming_a_definition_undoes_exactly() {
    let mut s = scene();
    let (id, _) = s
        .definitions()
        .find(|(_, d)| d.kind == DefinitionKind::Component)
        .unwrap();
    let before = s.clone();
    let change = s.rename_definition(id, "Box").unwrap();
    assert_eq!(s.definition(id).unwrap().name, "Box");
    assert!(change.summary().created.is_empty() && change.summary().modified.is_empty());
    assert!(s.rename_definition(id, "Box").unwrap().is_empty());
    s.apply(&change.inverse());
    assert_eq!(s, before);
    assert_eq!(
        s.rename_definition(kernel::DefinitionId(999_999), "x"),
        Err(KernelError::DefinitionNotFound)
    );
}

#[test]
fn purging_removes_unused_definitions_and_what_only_they_place() {
    let mut s = scene();
    let instances: Vec<_> = s.root().instances().map(|(id, _)| id).collect();
    s.erase_instances(MeshId::Root, &instances);
    // The component stays without instances, and keeps its group alive.
    assert_eq!(s.definitions().count(), 2);
    let before = s.clone();
    let change = s.purge();
    assert_eq!(s.definitions().count(), 0);
    s.validate().unwrap();
    s.apply(&change.inverse());
    assert_eq!(s, before);
    let mut used = scene();
    assert!(used.purge().is_empty(), "everything is placed");
}

//! The model as plain data, for files: every entity, definition and id as stored.

use std::collections::BTreeMap;

use glam::{DAffine3, DVec3};
use serde::{Deserialize, Serialize};

use crate::ids::{DefinitionId, EdgeId, FaceId, InstanceId, VertexId};
use crate::model::{Edge, Face, Instance, Model, Vertex};
use crate::scene::{Definition, DefinitionKind, Scene};

/// A whole scene as plain data. Ids are the kernel's numbers (without the "v"/"e"/... prefix).
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct SceneData {
    /// The id the next new entity gets; never reused.
    pub next_id: u64,
    pub root: MeshData,
    pub definitions: Vec<DefinitionData>,
}

#[derive(Clone, Debug, Default, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct MeshData {
    pub vertices: Vec<VertexData>,
    pub edges: Vec<EdgeData>,
    pub faces: Vec<FaceData>,
    pub instances: Vec<InstanceData>,
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct VertexData {
    pub id: u64,
    pub position: [f64; 3],
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct EdgeData {
    pub id: u64,
    pub vertices: [u64; 2],
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct FaceData {
    pub id: u64,
    pub outer: Vec<u64>,
    pub holes: Vec<Vec<u64>>,
    pub normal: [f64; 3],
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct InstanceData {
    pub id: u64,
    pub definition: u64,
    /// Column-major 3x4: x axis, y axis, z axis, translation.
    pub transform: [f64; 12],
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct DefinitionData {
    pub id: u64,
    pub name: String,
    pub kind: DefinitionKind,
    pub mesh: MeshData,
}

impl Scene {
    /// The scene as plain data.
    pub fn to_data(&self) -> SceneData {
        SceneData {
            next_id: self.next_id(),
            root: mesh_data(self.root()),
            definitions: self
                .definitions()
                .map(|(id, d)| DefinitionData {
                    id: id.0,
                    name: d.name.clone(),
                    kind: d.kind,
                    mesh: mesh_data(&d.mesh),
                })
                .collect(),
        }
    }

    /// Rebuilds a scene from plain data, keeping every id. Fails, naming the problem, when an
    /// id is used twice, a number is not finite, or the result breaks a model invariant
    /// (see [`Scene::validate`]).
    pub fn from_data(data: &SceneData) -> Result<Scene, String> {
        let root = mesh(&data.root)?;
        let mut definitions = BTreeMap::new();
        for d in &data.definitions {
            let definition = Definition {
                name: d.name.clone(),
                kind: d.kind,
                mesh: mesh(&d.mesh)?,
            };
            if definitions.insert(DefinitionId(d.id), definition).is_some() {
                return Err(format!("definition d{} appears twice", d.id));
            }
        }
        let scene = Scene::from_meshes(root, definitions, data.next_id);
        scene.validate()?;
        Ok(scene)
    }
}

fn mesh_data(m: &Model) -> MeshData {
    MeshData {
        vertices: m
            .vertices()
            .map(|(id, v)| VertexData {
                id: id.0,
                position: v.pos.to_array(),
            })
            .collect(),
        edges: m
            .edges()
            .map(|(id, e)| EdgeData {
                id: id.0,
                vertices: e.v.map(|v| v.0),
            })
            .collect(),
        faces: m
            .faces()
            .map(|(id, f)| FaceData {
                id: id.0,
                outer: f.outer.iter().map(|v| v.0).collect(),
                holes: f
                    .holes
                    .iter()
                    .map(|h| h.iter().map(|v| v.0).collect())
                    .collect(),
                normal: f.normal.to_array(),
            })
            .collect(),
        instances: m
            .instances()
            .map(|(id, i)| InstanceData {
                id: id.0,
                definition: i.definition.0,
                transform: i.transform.to_cols_array(),
            })
            .collect(),
    }
}

fn mesh(data: &MeshData) -> Result<Model, String> {
    let finite = |xs: &[f64], what: String| {
        if xs.iter().all(|x| x.is_finite()) {
            Ok(())
        } else {
            Err(format!("{what} has a number that is not finite"))
        }
    };
    let mut vertices = BTreeMap::new();
    for v in &data.vertices {
        finite(&v.position, format!("vertex v{}", v.id))?;
        let vertex = Vertex {
            pos: DVec3::from(v.position),
        };
        if vertices.insert(VertexId(v.id), vertex).is_some() {
            return Err(format!("vertex v{} appears twice", v.id));
        }
    }
    let mut edges = BTreeMap::new();
    for e in &data.edges {
        let edge = Edge {
            v: e.vertices.map(VertexId),
        };
        if edges.insert(EdgeId(e.id), edge).is_some() {
            return Err(format!("edge e{} appears twice", e.id));
        }
    }
    let mut faces = BTreeMap::new();
    for f in &data.faces {
        finite(&f.normal, format!("face f{}", f.id))?;
        let ring = |l: &Vec<u64>| l.iter().map(|v| VertexId(*v)).collect();
        let face = Face {
            outer: ring(&f.outer),
            holes: f.holes.iter().map(ring).collect(),
            normal: DVec3::from(f.normal),
        };
        if faces.insert(FaceId(f.id), face).is_some() {
            return Err(format!("face f{} appears twice", f.id));
        }
    }
    let mut instances = BTreeMap::new();
    for i in &data.instances {
        finite(&i.transform, format!("instance i{}", i.id))?;
        let instance = Instance {
            definition: DefinitionId(i.definition),
            transform: DAffine3::from_cols_array(&i.transform),
        };
        if instances.insert(InstanceId(i.id), instance).is_some() {
            return Err(format!("instance i{} appears twice", i.id));
        }
    }
    let ids = vertices.len() + edges.len() + faces.len() + instances.len();
    let distinct: std::collections::BTreeSet<u64> = vertices
        .keys()
        .map(|k| k.0)
        .chain(edges.keys().map(|k| k.0))
        .chain(faces.keys().map(|k| k.0))
        .chain(instances.keys().map(|k| k.0))
        .collect();
    if distinct.len() != ids {
        return Err("two entities of different kinds share an id".into());
    }
    Ok(Model::from_parts(vertices, edges, faces, instances))
}

//! The native file format (`.skr`): a zip archive holding `document.json`, which records the
//! format name, a schema version, the camera and the model with every id.

use std::io::{Read, Write};
use std::path::Path;

use glam::DVec3;
use kernel::{Scene, SceneData};
use serde::{Deserialize, Serialize};
use serde_json::Value;

use crate::camera::Camera;

/// The `format` every file records.
pub const FORMAT: &str = "tenon";
/// The schema version this build writes and the newest it reads.
pub const SCHEMA_VERSION: u32 = 1;
/// The archive entry holding the document.
const ENTRY: &str = "document.json";

#[derive(Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
struct Stored {
    format: String,
    schema_version: u32,
    camera: StoredCamera,
    model: SceneData,
}

#[derive(Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
struct StoredCamera {
    eye: [f64; 3],
    target: [f64; 3],
    fov_y_deg: f64,
}

/// Writes the model and camera to `path`, replacing it only once the whole file is written.
pub(crate) fn write(path: &Path, scene: &Scene, camera: &Camera) -> Result<(), String> {
    let stored = Stored {
        format: FORMAT.into(),
        schema_version: SCHEMA_VERSION,
        camera: StoredCamera {
            eye: camera.eye.to_array(),
            target: camera.target.to_array(),
            fov_y_deg: camera.fov_y.to_degrees(),
        },
        model: scene.to_data(),
    };
    let json = serde_json::to_vec(&stored).map_err(|e| e.to_string())?;
    let mut name = path.as_os_str().to_owned();
    name.push(".partial");
    let partial = Path::new(&name);
    let result = (|| -> Result<(), String> {
        let file = std::fs::File::create(partial).map_err(|e| e.to_string())?;
        let mut zip = zip::ZipWriter::new(file);
        let options = zip::write::SimpleFileOptions::default()
            .compression_method(zip::CompressionMethod::Deflated);
        zip.start_file(ENTRY, options).map_err(|e| e.to_string())?;
        zip.write_all(&json).map_err(|e| e.to_string())?;
        zip.finish().map_err(|e| e.to_string())?;
        std::fs::rename(partial, path).map_err(|e| e.to_string())
    })();
    if result.is_err() {
        let _ = std::fs::remove_file(partial);
    }
    result
}

/// Reads a file written by [`write`]: the model and the camera's eye, target and field of view
/// (degrees).
pub(crate) fn read(path: &Path) -> Result<(Scene, [DVec3; 2], f64), String> {
    let file = std::fs::File::open(path).map_err(|e| e.to_string())?;
    let mut zip = zip::ZipArchive::new(file).map_err(|_| "not a tenon file".to_string())?;
    let mut json = Vec::new();
    zip.by_name(ENTRY)
        .map_err(|_| "not a tenon file".to_string())?
        .read_to_end(&mut json)
        .map_err(|e| e.to_string())?;
    // Check the header first, so a newer file gets a clear message rather than a field error.
    let header: Value = serde_json::from_slice(&json).map_err(|e| e.to_string())?;
    if header["format"] != FORMAT {
        return Err("not a tenon file".into());
    }
    let version = header["schema_version"].as_u64().unwrap_or(0);
    if version > u64::from(SCHEMA_VERSION) {
        return Err(format!(
            "the file uses schema version {version}, newer than this app's {SCHEMA_VERSION}"
        ));
    }
    let stored: Stored = serde_json::from_slice(&json).map_err(|e| e.to_string())?;
    let scene = Scene::from_data(&stored.model)?;
    let c = &stored.camera;
    let camera = [DVec3::from(c.eye), DVec3::from(c.target)];
    if !c
        .eye
        .iter()
        .chain(&c.target)
        .chain([&c.fov_y_deg])
        .all(|x| x.is_finite())
    {
        return Err("the camera has a number that is not finite".into());
    }
    Ok((scene, camera, c.fov_y_deg))
}

use std::path::{Path, PathBuf};

use kernel::{DefinitionId, DefinitionKind, Scene, SceneChange};

use super::Document;
use crate::camera::Camera;

impl Document {
    /// An empty model with the default view.
    pub(super) fn new_model(&mut self) {
        let camera = Camera::new(self.camera.viewport);
        self.replace(Scene::new(), camera);
        self.path = None;
    }

    /// Replaces the model and view with a file's. A file whose view cannot be used (an eye
    /// straight above its target, say) opens with the default view.
    pub(super) fn open_file(&mut self, path: &str) -> Result<(), CommandError> {
        let (scene, [eye, target], fov) =
            file::read(Path::new(path)).map_err(|e| file_error(path, e))?;
        let camera = self
            .camera_for(eye.to_array(), target.to_array(), Some(fov))
            .unwrap_or_else(|_| Camera::new(self.camera.viewport));
        self.replace(scene, camera);
        self.path = Some(PathBuf::from(path));
        Ok(())
    }

    /// Saves to `path`, or to the file last opened or saved.
    pub(super) fn save_file(&mut self, path: Option<&str>) -> Result<(), CommandError> {
        let target = path
            .map(PathBuf::from)
            .or_else(|| self.path.clone())
            .ok_or_else(|| {
                CommandError::new(
                    ErrorKind::InvalidInput,
                    "give a path: the model was never opened or saved",
                )
            })?;
        file::write(&target, &self.scene, &self.camera)
            .map_err(|e| file_error(&target.display().to_string(), e))?;
        self.path = Some(target);
        self.clean_revision = self.revision;
        Ok(())
    }

    /// subscribers are told to read the model again.
