# M6a Circles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Circles can be drawn by agents (`add_circle`) and in the window (the Circle tool, `c`), with a chosen number of sides.

**Architecture:**
- **session:**
  - `circle.rs` computes a circle's corners: a regular polygon in the plane with a given normal, using the same in-plane axes as rectangles.
  - `Command::AddCircle` draws them with `Model::add_polygon` as one undo step.
- **tools:**
  - A `CircleTool`: click the center (on the face under the cursor, or a horizontal plane), then the rim, or type the radius.
  - `vcb::parse_segments` reads "24s" side counts.
  - The tool keeps its count for later circles.
- **app:**
  - `c` selects the Circle tool, as in SketchUp.
  - Make Component moves from `c` to Shift+G (`G`), and its toolbar tooltip says so.

**Tech Stack:** Rust 2024; no dependency changes.

**Spec:** `docs/superpowers/specs/2026-10-10-tenon-design.md`:
- section 2 (v1 tools include Circle; arcs/circles are edge chains tagged as curves);
- section 5 (commands include drawing circles).

## Spec notes (rulings made in this plan)

- **Scope split.** The spec wants circles to be edge chains *tagged as curves*: select one edge and get the circle, smooth sides after push/pull, Entity Info saying "circle". Tagging touches the kernel's edges, sticky splitting and merging, and the file format, so it becomes its own milestone, M6d (added to the roadmap). M6a draws circles as plain polygons; arcs come with M6d as well.
- **Geometry.**
  - A circle with `segments` sides is the regular polygon inscribed in the circle, so its corners lie on the circle.
  - The first corner lies along the plane's u axis (`rectangle_axes(normal).0`: X on horizontal planes). Corners run counter-clockwise around the normal.
  - The default is 24 sides; 3 to 360 are accepted.
  - The radius must be positive and large enough that each side is at least 10x the merge tolerance (`LENGTH_TOL`), so sticky geometry cannot merge neighboring corners.
  - The normal defaults to Z and must be non-zero.
- **The tool.**
  - The first click sets the center, on the face under the cursor if the point is on it, else on a horizontal plane (the Rectangle tool's rule, now shared as `pub(crate)` helpers).
  - The second click, or a typed length, sets the radius.
  - "24s" sets the side count, before or during a circle. The count is kept for later circles; the tool reports "Circles get 24 sides", or why the count was refused.
  - The preview shows the polygon and the radius line.
- **Shortcuts.** `c` was Make Component (M5b). It now selects the Circle tool, as in SketchUp, and Make Component is `G` (Shift+G).

  Tool shortcuts are matched case-insensitively, so `C` also selects Circle. `G` is checked before tool shortcuts, so it is never a tool.

  On keyboard layouts that do not type ASCII, the physical-key fallback gives `g` for the G key whether or not Shift is down, so Shift+G makes a group there. This is a known limitation of the character-based shortcut path.

```rust
    let cmd: Command = serde_json::from_value(v).expect("valid command json");
    d.execute(cmd)
        .map(|o| serde_json::to_value(o).unwrap())
```

```rust
//! Circle geometry shared by `Command::AddCircle` and the Circle tool.

use std::f64::consts::TAU;

use glam::DVec3;
use kernel::geom::LENGTH_TOL;

use crate::command::{CommandError, ErrorKind};
use crate::rectangle::rectangle_axes;

/// Sides a circle gets when none are asked for.
pub const DEFAULT_CIRCLE_SEGMENTS: u32 = 24;
/// Most sides a circle may have.
pub const MAX_CIRCLE_SEGMENTS: u32 = 360;

/// The corners, in order, of the regular polygon with `segments` sides inscribed in the circle
/// around `center` with `radius`, in the plane through `center` with `normal` (Z when absent).
/// The first corner lies along `rectangle_axes(normal).0` from the center, and the corners run
/// counter-clockwise around the normal.
pub fn circle_points(
    center: DVec3,
    radius: f64,
    normal: Option<DVec3>,
    segments: u32,
) -> Result<Vec<DVec3>, CommandError> {
    let invalid = |m: String| CommandError::new(ErrorKind::InvalidInput, m);
    let normal = match normal {
        None => DVec3::Z,
        Some(n) if n.is_finite() && n.length() > 1e-9 => n.normalize(),
        Some(_) => return Err(invalid("normal must be a non-zero vector".into())),
    };
    if !(3..=MAX_CIRCLE_SEGMENTS).contains(&segments) {
        return Err(invalid(format!(
            "segments must be between 3 and {MAX_CIRCLE_SEGMENTS}"
        )));
    }
    // Neighbouring corners must be farther apart than the merge tolerance.
    let side = 2.0 * radius * (std::f64::consts::PI / segments as f64).sin();
    if !radius.is_finite() || radius <= 0.0 || side < 10.0 * LENGTH_TOL {
        return Err(invalid(
            "radius must be a positive number large enough for the segments".into(),
        ));
    }
    let (u, v) = rectangle_axes(normal);
    Ok((0..segments)
        .map(|k| {
            let a = TAU * k as f64 / segments as f64;
            center + (u * a.cos() + v * a.sin()) * radius
        })
        .collect())
}
```

```rust
//! The Circle tool: click the center, then a point on the rim (or type the radius). The
//! circle lies on the face under the center click, or on a horizontal plane. Typing "24s" sets
//! the number of sides, before or during a circle; the count is kept for later circles.

use glam::DVec3;
use session::{Command, DEFAULT_CIRCLE_SEGMENTS, circle_points};

use crate::rectangle::{on_plane, plane_normal};
use crate::tool::{Tool, ToolContext, ToolEvent, ToolOutput};
use crate::vcb::{format_length, parse_length, parse_segments};

#[derive(Clone, Debug)]
pub struct CircleTool {
    /// The center and the normal of the plane the circle lies in.
    center: Option<(DVec3, DVec3)>,
    /// The point on the rim under the cursor, on that plane.
    hover: Option<DVec3>,
    segments: u32,
}

impl Default for CircleTool {
    fn default() -> Self {
        CircleTool {
            center: None,
            hover: None,
            segments: DEFAULT_CIRCLE_SEGMENTS,
        }
    }
}

impl CircleTool {
    pub fn new() -> Self {
        Self::default()
    }

    /// The radius from the center to the cursor.
    fn radius(&self) -> Option<f64> {
        let ((center, _), hover) = (self.center?, self.hover?);
        Some(center.distance(hover))
    }

    /// The command for the circle with `radius` around the center, if it can be drawn.
    fn finish(&mut self, radius: f64, out: &mut ToolOutput) {
        let Some((center, normal)) = self.center else {
            return;
        };
        match circle_points(center, radius, Some(normal), self.segments) {
            Ok(_) => {
                out.commands.push(Command::AddCircle {
                    center: center.to_array(),
                    radius,
                    normal: Some(normal.to_array()),
                    segments: Some(self.segments),
                });
                self.center = None;
                self.hover = None;
            }
            Err(e) => out.message = Some(e.message),
        }
    }
}

impl Tool for CircleTool {
    fn name(&self) -> &'static str {
        "Circle"
    }

    fn prompt(&self) -> &'static str {
        match self.center {
            None => "Click the center; type 24s for 24 sides",
            Some(_) => "Click a point on the circle, or type the radius",
        }
    }

    fn measurement(&self) -> (&'static str, Option<String>) {
        ("Radius", self.radius().map(format_length))
    }

    fn anchor(&self) -> Option<DVec3> {
        self.center.map(|(c, _)| c)
    }

    fn handle(&mut self, event: ToolEvent, ctx: &ToolContext) -> ToolOutput {
        let mut out = ToolOutput::default();
        match event {
            ToolEvent::Move(hit) => {
                if let Some((center, normal)) = self.center {
                    self.hover = on_plane(center, normal, &hit, ctx);
                }
            }
            ToolEvent::Click(hit) => match self.center {
                None => self.center = Some((hit.point, plane_normal(&hit, ctx))),
                Some((center, normal)) => {
                    if let Some(p) = on_plane(center, normal, &hit, ctx) {
                        self.finish(center.distance(p), &mut out);
                    }
                }
            },
            ToolEvent::Value(text) => {
                if let Some(n) = parse_segments(&text) {
                    match circle_points(DVec3::ZERO, 1.0, None, n) {
                        Ok(_) => {
                            self.segments = n;
                            out.message = Some(format!("Circles get {n} sides"));
                        }
                        Err(e) => out.message = Some(e.message),
                    }
                } else {
                    match (self.center, parse_length(&text)) {
                        (None, _) => {
                            out.message = Some("Click the center first, or type 24s".into());
                        }
                        (Some(_), Some(r)) => self.finish(r, &mut out),
                        (Some(_), None) => {
                            out.message = Some(format!("Not a radius or a side count: {text}"));
                        }
                    }
                }
            }
            ToolEvent::Release(_) | ToolEvent::DoubleClick(_) | ToolEvent::ToggleCopy => {}
            ToolEvent::Cancel => self.on_external_change(),
        }
        if let (Some((center, normal)), Some(r)) = (self.center, self.radius())
            && let Ok(points) = circle_points(center, r, Some(normal), self.segments)
        {
            let n = points.len();
            out.preview = (0..n).map(|i| [points[i], points[(i + 1) % n]]).collect();
            out.preview.push([center, self.hover.unwrap_or(center)]);
        }
        out
    }

    fn on_external_change(&mut self) {
        self.center = None;
        self.hover = None;
    }
}
```
