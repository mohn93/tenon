# M9a Soften and Smooth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Edges can be softened and hardened by command (`soften_edges`, `soften_by_angle`), faces are shaded smoothly across soft edges in the window and in glTF exports, and the window gets Edit > Soften Edges... and a Soft checkbox in Entity Info.

**Architecture:**
- Kernel `soften.rs`: `Model::soften_edges` / `soften_by_angle` set the existing `Edge.soft` flag through `set_edge` (`Op::ChangeEdge`, so undo, files and change summaries already work) and return a `SoftenReport { changed, skipped }`. Only an edge between exactly two faces is made soft, so the upkeep rule (a soft edge bounds at least two faces) holds.
- Kernel `smooth.rs`: `Model::smooth_normals` works out, once per mesh, the fans of faces joined through soft edges at each end of a soft edge (from the vertex-to-faces index) and their area-weighted normals; `Model::shaded_triangles` gives a face's triangles with a normal per corner. `Scene::triangles` carries them (`Triangle.normals`), so glTF writes them.
- Session: `Command::SoftenEdges` / `SoftenByAngle`, one undo step each, report in `Outcome.soften` (like `import`).
- Render: `MeshParts` keeps a normal per triangle corner, built when a mesh's parts are built; placements transform each by the inverse transpose. The shader already normalizes the interpolated normal.
- App: an `editor/soften.rs` submodule holds the window state and the soften/harden/checkbox actions; `ui.rs` draws the window and the checkbox.

**Tech Stack:** Rust 2024; wgpu 30, egui 0.36; no dependency changes.

## Spec notes (rulings made in this plan)

- **Report.** Both commands put `"soften": {"changed": n, "skipped": m}` in their outcome (absent for other commands, like `import`). `changed`: edges whose flag changed (also in `changes.modified`). `skipped`: edges left hard that were asked about: for `soften_edges` with `soft: true`, edges not between exactly two faces; for `soften_by_angle`, hard edges not between two faces or meeting at more than the angle. Edges already as asked count in neither. A command that changes nothing makes no undo step but still reports.
- **Exactly two faces.** An edge can be made soft when exactly two distinct faces use it, each once (`Model::faces_beside`). The upkeep rule stays "at least two faces", so edges softened earlier (pulled curves) and soft edges that later gain a third face keep their flag.
- **Angle.** `fold_angle` is the angle between the two faces' normals, 0 for faces in one plane. Faces oriented against each other (both loops run the same way along the edge) are compared with one turned over, so a model with flipped faces softens the same. A 1e-9 rad allowance lets 90 take a box's edges. `max_angle_deg` must be 0 to 180 (`invalid_input` otherwise).
- **soften_by_angle never hardens.** Edges over the angle, soft or hard, stay as they are (the spec: "others unchanged").
- **ids.** Edges and faces (a face stands for the edges around its outer loop and holes). Vertex, instance and guide ids are `invalid_input` naming them; unknown ids `not_found`. `soften_edges` with empty `ids` is `invalid_input`; `soften_by_angle` with empty or absent `ids` takes every edge of the open context.
- **Smooth normals.** At a vertex, faces that share a soft edge there are joined; the joined groups (fans) each get the area-weighted sum of their faces' normals (whole face area), each face's normal turned over where it is oriented against the face it was reached from. A face's corner normal is that sum (turned back for that face), normalized; it falls back to the face's own normal when the face is in no fan, the sum is zero, or it leans to the face's back. Caps of a pulled circle stay flat because the rim edges are hard.
- **Cost.** `smooth_normals` is one pass over the edges (empty result without soft edges), then per end vertex of a soft edge the faces around it (from `vertex_faces`), with face areas cached. Render builds it in `MeshParts::of`, i.e. once per mesh when the scene base is rebuilt, shared by every placement. Release timings on this machine (`time_shading_a_softened_twenty_thousand_face_terrain`): softening every edge of a 20,000-face terrain up to 60 degrees 50 ms; shading every face 62 ms (a first per-corner version took 670 ms).
- **Exports.** glTF writes the corner normals. OBJ (`vn` per face) and STL (one normal per triangle) keep face normals; the spec asks only for glTF.
- **Window.** Edit > Soften Edges... opens an egui window (not modal) with an angle slider (whole degrees 0 to 180, starting at 20, kept for the session, not saved) and Soften / Harden buttons. Soften runs `soften_by_angle` with the angle; Harden runs `soften_edges` with `soft: false` and ignores the angle. Both act on the selected edges and faces, or the whole open context when nothing is selected; other selected entities are left out, and a selection with no edges or faces says "Select edges or faces to soften or harden". The status line reports "Softened 4 edges" / "Hardened 12 edges" / "No edges changed".
- **Entity Info.** A Soft checkbox shows when the selection is edges only (one or more; soft edges are hidden and not clicked, but box selection and whole-curve clicks select them), checked when all are soft; toggling runs `soften_edges` on them. An edge that cannot be soft gives "Only an edge between two faces can be soft".
- **Goldens.** `soft_cylinder` changes under the tolerance (shading shifts only), and is regenerated anyway since the rendering changed on purpose. New `smooth_sphere`: two imported UV spheres, the right one softened by angle, so flat and smooth shading sit side by side.
- **Render reference.** The single-pass reference in `render::scene` tests is updated to the same corner normals (its forest has soft-sided curved solids).

//! Softening and hardening edges: a soft edge is hidden and the faces on its two sides are
//! shaded as one smooth surface (see `smooth`).

use std::collections::BTreeSet;

use serde::{Deserialize, Serialize};

use crate::ids::{EdgeId, FaceId, VertexId};
use crate::model::{ChangeSet, Model};

/// What a soften or harden edit did.
#[derive(
    Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize, schemars::JsonSchema,
)]
pub struct SoftenReport {
    /// Edges whose soft flag changed.
    pub changed: usize,
    /// Edges left as they were: not between exactly two faces when softening, or (by angle)
    /// between faces meeting at more than the angle. Edges already as asked are not counted.
    pub skipped: usize,
}

impl Model {
    /// The edges along a face's outer loop and holes, in id order.
    pub fn face_edges(&self, id: FaceId) -> Vec<EdgeId> {
        let Some(f) = self.face(id) else {
            return Vec::new();
        };
        let mut edges = BTreeSet::new();
        for l in std::iter::once(&f.outer).chain(&f.holes) {
            for i in 0..l.len() {
                edges.extend(self.edge_between(l[i], l[(i + 1) % l.len()]));
            }
        }
        edges.into_iter().collect()
    }

    /// The two faces an edge lies between, oldest first, when it bounds exactly two faces
    /// (each using it once).
    pub fn faces_beside(&self, id: EdgeId) -> Option<[FaceId; 2]> {
        let [a, b] = self.edge(id)?.v;
        let faces = self.faces_on_side(a, b);
        let [f, g] = faces[..] else { return None };
        let once = |f: FaceId| sides_in(self, f, a, b) == 1;
        (once(f) && once(g)).then_some([f, g])
    }

    /// The angle between the normals of the two faces beside an edge, in radians (0: they lie
    /// in one plane), with the second face turned over first if the two are oriented against
    /// each other (both loops run the same way along the edge).
    pub fn fold_angle(&self, id: EdgeId) -> Option<f64> {
        let [f, g] = self.faces_beside(id)?;
        let [a, b] = self.edge(id)?.v;
        let (nf, mut ng) = (self.face(f)?.normal, self.face(g)?.normal);
        if runs(self, f, a, b) == runs(self, g, a, b) {
            ng = -ng;
        }
        Some(nf.dot(ng).clamp(-1.0, 1.0).acos())
    }

    /// Sets (`soft`) or clears the soft flag of `edges`, as one ChangeSet. Only an edge between
    /// exactly two faces is made soft; others are left as they are and counted as skipped.
    /// Unknown ids are ignored.
    pub fn soften_edges(&mut self, edges: &[EdgeId], soft: bool) -> (ChangeSet, SoftenReport) {
        let mut report = SoftenReport::default();
        for &e in edges.iter().collect::<BTreeSet<_>>() {
            let Some(edge) = self.edge(e) else { continue };
            if edge.soft == soft {
                continue;
            }
            if soft && self.faces_beside(e).is_none() {
                report.skipped += 1;
                continue;
            }
            let curve = edge.curve;
            self.set_edge(e, curve, soft);
            report.changed += 1;
        }
        (self.take_changes(), report)
    }

    /// Softens each of `edges` that lies between exactly two faces meeting at no more than
    /// `max_angle` radians (see `fold_angle`), as one ChangeSet. Other edges stay as they are;
    /// hard ones are counted as skipped. Unknown ids are ignored.
    pub fn soften_by_angle(
        &mut self,
        edges: &[EdgeId],
        max_angle: f64,
    ) -> (ChangeSet, SoftenReport) {
        let mut report = SoftenReport::default();
        for &e in edges.iter().collect::<BTreeSet<_>>() {
            let Some(edge) = self.edge(e) else { continue };
            if edge.soft {
                continue;
            }
            // A small allowance, so 90 degrees takes the sides of a box.
            if self.fold_angle(e).is_some_and(|a| a <= max_angle + 1e-9) {
                let curve = edge.curve;
                self.set_edge(e, curve, true);
                report.changed += 1;
            } else {
                report.skipped += 1;
            }
        }
        (self.take_changes(), report)
    }
}

/// True when one of the face's loops runs from `a` straight to `b`.
fn runs(m: &Model, f: FaceId, a: VertexId, b: VertexId) -> bool {
    m.face(f).is_some_and(|f| {
        std::iter::once(&f.outer)
            .chain(&f.holes)
            .any(|l| (0..l.len()).any(|i| l[i] == a && l[(i + 1) % l.len()] == b))
    })
}

/// How many times the face's loops use the side a-b, either way round.
fn sides_in(m: &Model, f: FaceId, a: VertexId, b: VertexId) -> usize {
    m.face(f).map_or(0, |f| {
        std::iter::once(&f.outer)
            .chain(&f.holes)
            .map(|l| {
                (0..l.len())
                    .filter(|&i| {
                        let (x, y) = (l[i], l[(i + 1) % l.len()]);
                        (x, y) == (a, b) || (x, y) == (b, a)
                    })
                    .count()
            })
            .sum()
    })
}

//! Soft and hard edges, driven through JSON commands.

use glam::DVec2;
use serde_json::{Value, json};
use session::{Command, Document, ErrorKind, Query};

fn doc() -> Document {
    Document::new(DVec2::new(800.0, 600.0))
}

fn run(d: &mut Document, v: Value) -> Result<Value, (ErrorKind, String)> {
    let cmd: Command = serde_json::from_value(v).expect("valid command json");
    d.execute(cmd)
        .map(|o| serde_json::to_value(o).unwrap())
        .map_err(|e| (e.kind, e.message))
}

fn ask(d: &Document, q: Value) -> Value {
    let q: Query = serde_json::from_value(q).unwrap();
    serde_json::to_value(d.query(&q).unwrap()).unwrap()
}

fn soft(d: &Document) -> usize {
    ask(d, json!({"type": "entities", "kinds": ["edge"]}))["edges"]
        .as_array()
        .unwrap()
        .iter()
        .filter(|e| e["soft"] == true)
        .count()
}

/// A 2 x 2 x 1 m box; returns its top face.
fn add_box(d: &mut Document) -> Value {
    let out = run(
        d,
        json!({"type": "add_rectangle", "corner": [0, 0, 0], "opposite": [2, 2, 0]}),
    )
    .unwrap();
    let base = out["changes"]["created"]
        .as_array()
        .unwrap()
        .iter()
        .find(|id| id.as_str().unwrap().starts_with('f'))
        .unwrap()
        .clone();
    let down = ask(d, json!({"type": "entity", "id": base}))["normal"][2]
        .as_f64()
        .unwrap()
        < 0.0;
    let distance = if down { -1.0 } else { 1.0 };
    run(
        d,
        json!({"type": "push_pull", "face": base, "distance": distance}),

    .unwrap();

//! Soft and hard edges.

use std::collections::BTreeSet;

use kernel::{EdgeId, EntityId, SceneChange};

use super::Document;
use crate::command::{CommandError, ErrorKind};

impl Document {
    /// Softens or hardens the edges in `ids` and around the faces in `ids`. Other kinds of
    /// entity are invalid input, as is an empty list.
    pub(super) fn soften_changes(
        &mut self,
        ids: &[EntityId],
        soft: bool,
    ) -> Result<SceneChange, CommandError> {
        if ids.is_empty() {
            return Err(CommandError::new(
                ErrorKind::InvalidInput,
                "ids must list at least one edge or face",
            ));
        }
        let edges = self.edges_of(ids)?;
        let mut report = None;
        let change = self
            .edit_mesh(|m| {
                let (changes, r) = m.soften_edges(&edges, soft);
                report = Some(r);
                Ok(changes)
            })
            .expect("softening cannot fail");
        self.soften_report = report;
        Ok(change)
    }

    /// Softens the edges in `ids` and around the faces in `ids` (every edge of the open
    /// context when `ids` is empty) whose faces meet at no more than `max_angle_deg`.
    pub(super) fn soften_by_angle_changes(
        &mut self,
        ids: &[EntityId],
        max_angle_deg: f64,
    ) -> Result<SceneChange, CommandError> {
        if !(0.0..=180.0).contains(&max_angle_deg) {
            return Err(CommandError::new(
                ErrorKind::InvalidInput,
                format!("max_angle_deg must be a number from 0 to 180, not {max_angle_deg}"),
            ));
        }
        let edges = if ids.is_empty() {
            self.model().edges().map(|(id, _)| id).collect()
        } else {
            self.edges_of(ids)?
        };
        let mut report = None;
        let change = self
            .edit_mesh(|m| {
                let (changes, r) = m.soften_by_angle(&edges, max_angle_deg.to_radians());
                report = Some(r);
                Ok(changes)
            })
            .expect("softening cannot fail");
        self.soften_report = report;
        Ok(change)
    }

    /// The edges in `ids` and around the faces in `ids`, in id order. Vertices, instances and
    /// guides are invalid input (naming them); unknown ids are `not_found`.
    fn edges_of(&self, ids: &[EntityId]) -> Result<Vec<EdgeId>, CommandError> {
        let others: Vec<EntityId> = ids
            .iter()
            .copied()
            .filter(|id| !matches!(id, EntityId::Edge(_) | EntityId::Face(_)))
            .collect();
        if !others.is_empty() {
            return Err(CommandError::new(
                ErrorKind::InvalidInput,
                "only edges and faces can be softened or hardened",
            )
            .with_ids(others));
        }
        let parts = self.parts(ids)?;
        let m = self.model();
        let mut edges: BTreeSet<EdgeId> = parts.edges.into_iter().collect();
        for f in parts.faces {
            edges.extend(m.face_edges(f));
        }
        Ok(edges.into_iter().collect())
    }
}

//! Smooth shading across soft edges: the normal each face is shaded with at each corner.
//!
//! At a vertex, the faces around it that soft edges join form fans. Every face of a fan is
//! shaded there with the fan's area-weighted average normal, each face counted turned over
//! where it is oriented against the face it was reached from.

use std::collections::{BTreeSet, HashMap};

use glam::DVec3;

use crate::ids::{FaceId, VertexId};
use crate::model::Model;

/// A face's triangle with the normal it is shaded with at each corner.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct ShadedTriangle {
    /// Wound counter-clockwise around the face's normal.
    pub corners: [DVec3; 3],
    pub normals: [DVec3; 3],
}

/// The corner normals of a mesh that differ from their face's normal (corners on soft
/// edges), worked out once for the whole mesh; see `Model::smooth_normals`.
#[derive(Clone, Debug, Default, PartialEq)]
pub struct SmoothNormals(HashMap<(FaceId, VertexId), DVec3>);

impl SmoothNormals {
    /// The normal face `face` is shaded with at vertex `v`, if it is not the face's own.
    pub fn get(&self, face: FaceId, v: VertexId) -> Option<DVec3> {
        self.0.get(&(face, v)).copied()
    }

    /// True when every face is shaded flat.
    pub fn is_empty(&self) -> bool {
        self.0.is_empty()
    }
}

/// A fan: faces with the sign that turns each to agree with the first.
type Fan = Vec<(FaceId, f64)>;

impl Model {
    /// The smooth corner normals of every face (see the module comment). Linear in the faces
    /// around the ends of soft edges; empty, after one pass over the edges, without them.
    pub fn smooth_normals(&self) -> SmoothNormals {
        let ends: BTreeSet<VertexId> = self
            .edges()
            .filter(|(_, e)| e.soft)
            .flat_map(|(_, e)| e.v)
            .collect();
        let mut areas: HashMap<FaceId, f64> = HashMap::new();
        let mut out = HashMap::new();
        for v in ends {
            for fan in self.fans_at(v) {
                let mut area =
                    |f: FaceId| *areas.entry(f).or_insert_with(|| self.face_area(f).abs());
                let sum: DVec3 = fan
                    .iter()
                    .map(|&(f, sign)| self.face(f).unwrap().normal * area(f) * sign)
                    .sum();
                for &(f, sign) in &fan {
                    let own = self.face(f).unwrap().normal;
                    if let Some(n) = (sum * sign).try_normalize().filter(|n| n.dot(own) > 0.0) {
                        out.insert((f, v), n);
                    }
                }
            }
        }
        SmoothNormals(out)
    }

    /// The normal face `id` is shaded with at its corner `v`: the average normal of its fan
    /// there, or its own normal when it is in none (or the average leans to its back). None
    /// for an unknown face. For many corners, `smooth_normals` is faster.
    pub fn corner_normal(&self, id: FaceId, v: VertexId) -> Option<DVec3> {
        let own = self.face(id)?.normal;
        let Some(fan) = self
            .fans_at(v)
            .into_iter()
            .find(|fan| fan.iter().any(|(f, _)| *f == id))
        else {
            return Some(own);
        };
        let sign = fan.iter().find(|(f, _)| *f == id).unwrap().1;
        let sum: DVec3 = fan
            .iter()
            .map(|&(f, s)| self.face(f).unwrap().normal * self.face_area(f).abs() * s)
            .sum();
        Some(
            (sum * sign)
                .try_normalize()
                .filter(|n| n.dot(own) > 0.0)
                .unwrap_or(own),
        )
    }

    /// `triangulate`, with the normal at each corner: from `smooth` (this mesh's
    /// `smooth_normals`), else the face's own.
    pub fn shaded_triangles(
        &self,
        id: FaceId,
        smooth: &SmoothNormals,
    ) -> Option<Vec<ShadedTriangle>> {
        let own = self.face(id)?.normal;
        let tris = self.triangle_vertices(id)?;
        Some(
            tris.iter()
                .map(|t| ShadedTriangle {
                    corners: t.map(|v| self.pos(v)),
                    normals: t.map(|v| smooth.get(id, v).unwrap_or(own)),
                })
                .collect(),
        )
    }

    /// The fans of two or more faces at `v`, joined through soft edges at `v`.
    fn fans_at(&self, v: VertexId) -> Vec<Fan> {
        let soft: Vec<VertexId> = self
            .edges_at(v)
            .into_iter()
            .filter_map(|e| self.edge(e).filter(|e| e.soft))
            .map(|e| if e.v[0] == v { e.v[1] } else { e.v[0] })
            .collect();
        if soft.is_empty() {
            return Vec::new();
        }
        let faces: Vec<FaceId> = self.faces_at(v).collect();
        // Each use of a soft side v-w by a face: (w, face index, runs from v to w).
        let mut uses: Vec<(VertexId, usize, bool)> = Vec::new();
        for (i, f) in faces.iter().enumerate() {
            let face = self.face(*f).unwrap();
            for l in std::iter::once(&face.outer).chain(&face.holes) {
                let n = l.len();
                for k in (0..n).filter(|&k| l[k] == v) {
                    let (prev, next) = (l[(k + n - 1) % n], l[(k + 1) % n]);
                    if soft.contains(&next) {
                        uses.push((next, i, true));
                    }
                    if soft.contains(&prev) {
                        uses.push((prev, i, false));
                    }
                }
            }
        }
        uses.sort_unstable();
        // Faces sharing a soft side, with whether they are oriented alike (they then run
        // along it in opposite directions).
        let mut links: Vec<Vec<(usize, bool)>> = vec![Vec::new(); faces.len()];
        for side in uses.chunk_by(|a, b| a.0 == b.0) {
            for (k, &(_, i, di)) in side.iter().enumerate() {
                for &(_, j, dj) in &side[k + 1..] {
                    if i != j {
                        links[i].push((j, di != dj));
                        links[j].push((i, di != dj));
                    }
                }
            }
        }
        let mut sign = vec![0.0; faces.len()];
        let mut fans = Vec::new();
        for start in 0..faces.len() {
            if sign[start] != 0.0 || links[start].is_empty() {
                continue;
            }
            sign[start] = 1.0;
            let mut fan = vec![start];
            let mut k = 0;
            while let Some(&i) = fan.get(k) {
                k += 1;
                for &(j, alike) in &links[i] {
                    if sign[j] == 0.0 {
                        sign[j] = if alike { sign[i] } else { -sign[i] };
                        fan.push(j);
                    }
                }
            }
            fans.push(fan.into_iter().map(|i| (faces[i], sign[i])).collect());
        }
        fans
    }
}
