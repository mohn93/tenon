# M1 Viewport Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native window showing an empty 3D viewport with a ground grid and RGB axes, navigable with orbit, pan and zoom, redrawing only on demand.

**Architecture:** Cargo workspace. `render` crate holds pure camera math, grid/axis geometry, and a wgpu line renderer that draws into any `TextureView` (so it can be tested headless). `app` crate holds a pure input-to-camera navigation controller and the winit shell that owns the window and surface.

**Tech Stack:** Rust (edition 2024, stable), wgpu 30.0.1, winit 0.30.13, glam 0.34.1, bytemuck 1.25.2, pollster 1.0.1, log 0.4.34, env_logger 0.11.11.

**Spec:** `docs/superpowers/specs/2026-10-10-sketchup-alt-design.md` (this plan implements milestone M1 only; M2-M5 get their own plans).

## Global Constraints

- Coordinates are Z-up, right-handed. Red = X, green = Y, blue = Z. Model units are meters.
- Model-side math uses f64 (`DVec3`, `DMat4`); only data sent to the GPU is f32.
- Redraw on demand only: `ControlFlow::Wait`, `request_redraw()` only after input that changed the camera, a resize, or a lost surface.
- 4x MSAA; depth format `Depth32Float`.
- Colors are authored as sRGB values and written to a non-sRGB target format (surface picks a non-sRGB format when available).
- Crate versions are pinned exactly as listed in Tech Stack. The wgpu 30 API differs from older tutorials: `Queue::present(frame)`, `Surface::get_current_texture()` returns `CurrentSurfaceTexture`, `DepthStencilState.depth_write_enabled`/`depth_compare` are `Option`, `VertexState.buffers` is `&[Option<VertexBufferLayout>]`, `RenderPipelineDescriptor` has `multiview_mask`.
- Git: work on `dev`. Stage only files you changed (no `git add -A`). Commit messages: short, plain, no emoji.

## Out of scope for M1 (later plans)

`kernel` and `tools` crates, egui, orthographic camera, standard views, zoom extents, wide screen-space edge lines, faces.

```rust
use glam::{DMat4, DVec2, DVec3, Mat4};

pub const UP: DVec3 = DVec3::Z;

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Ray {
    pub origin: DVec3,
    pub dir: DVec3,
}

impl Ray {
    /// Intersection with the ground plane z = 0, if it lies in front of the origin.
    pub fn hit_ground(&self) -> Option<DVec3> {
        if self.dir.z.abs() < 1e-12 {
            return None;
        }
        let t = -self.origin.z / self.dir.z;
        (t > 0.0).then(|| self.origin + self.dir * t)
    }
}

/// Perspective camera looking from `eye` at `target`, Z-up.
#[derive(Clone, Debug, PartialEq)]
pub struct Camera {
    pub eye: DVec3,
    pub target: DVec3,
    /// Vertical field of view in radians.
    pub fov_y: f64,
    /// Viewport size in physical pixels.
    pub viewport: DVec2,
}

impl Camera {
    pub fn new(viewport: DVec2) -> Self {
        Self {
            eye: DVec3::new(-8.0, -12.0, 7.0),
            target: DVec3::ZERO,
            fov_y: 35f64.to_radians(),
            viewport,
        }
    }

    pub fn forward(&self) -> DVec3 {
        (self.target - self.eye).normalize()
    }

    pub fn right(&self) -> DVec3 {
        self.forward().cross(UP).normalize()
    }

    pub fn up(&self) -> DVec3 {
        self.right().cross(self.forward())
    }

    pub fn distance(&self) -> f64 {
        (self.target - self.eye).length()
    }

    pub fn aspect(&self) -> f64 {
        self.viewport.x / self.viewport.y.max(1.0)
    }

    pub fn view(&self) -> DMat4 {
        DMat4::look_at_rh(self.eye, self.target, UP)
    }

    pub fn proj(&self) -> DMat4 {
        let d = self.distance();
        DMat4::perspective_rh(self.fov_y, self.aspect(), (d * 1e-3).max(1e-4), d * 1e3)
    }

    pub fn view_proj_f32(&self) -> Mat4 {
        (self.proj() * self.view()).as_mat4()
    }

    /// World-space ray through a pixel (origin top-left, y down).
    pub fn ray(&self, px: DVec2) -> Ray {
        let ndc_x = 2.0 * px.x / self.viewport.x - 1.0;
        let ndc_y = 1.0 - 2.0 * px.y / self.viewport.y;
        let half_h = (self.fov_y * 0.5).tan();
        let dir = self.forward()
            + self.right() * (ndc_x * half_h * self.aspect())
            + self.up() * (ndc_y * half_h);
        Ray { origin: self.eye, dir: dir.normalize() }
    }

    /// Pixel position of a world point, or None if it is behind the camera.
    pub fn project(&self, p: DVec3) -> Option<DVec2> {
        let clip = self.proj() * self.view() * p.extend(1.0);
        if clip.w <= 0.0 {
            return None;
        }
        let ndc = clip.truncate() / clip.w;
        Some(DVec2::new(
            (ndc.x + 1.0) * 0.5 * self.viewport.x,
            (1.0 - ndc.y) * 0.5 * self.viewport.y,
        ))
    }
}
```

```rust
use glam::{DMat4, DQuat, DVec2, DVec3, Mat4};
use std::f64::consts::PI;

pub const UP: DVec3 = DVec3::Z;
/// Closest the view direction may get to straight up or down, in radians.
pub const MIN_POLAR: f64 = 0.01;
pub const ORBIT_RAD_PER_PX: f64 = 0.006;
/// Distance multiplier per zoom step (one scroll notch).
pub const ZOOM_STEP: f64 = 0.85;
pub const MIN_ZOOM_DISTANCE: f64 = 0.01;
/// Ground hits farther than distance() * this are ignored as anchors.
pub const MAX_ANCHOR_FACTOR: f64 = 50.0;
```

Add to `impl Camera`:
```rust
    pub fn orbit(&mut self, pivot: DVec3, delta_px: DVec2) {
        let yaw = -delta_px.x * ORBIT_RAD_PER_PX;
        // Rotating forward about right() by +a tilts it toward UP, reducing its polar angle by a.
        let polar = self.forward().angle_between(UP).clamp(MIN_POLAR, PI - MIN_POLAR);
        let pitch = (-delta_px.y * ORBIT_RAD_PER_PX)
            .clamp(polar - (PI - MIN_POLAR), polar - MIN_POLAR);
        let rot = DQuat::from_axis_angle(UP, yaw) * DQuat::from_axis_angle(self.right(), pitch);
        self.eye = pivot + rot * (self.eye - pivot);
        self.target = pivot + rot * (self.target - pivot);
    }

    pub fn pan(&mut self, anchor: DVec3, delta_px: DVec2) {
        let depth = (anchor - self.eye).dot(self.forward()).max(1e-6);
        let world_per_px = 2.0 * depth * (self.fov_y * 0.5).tan() / self.viewport.y;
        let offset = (self.up() * delta_px.y - self.right() * delta_px.x) * world_per_px;
        self.eye += offset;
        self.target += offset;
    }

    pub fn zoom(&mut self, anchor: DVec3, steps: f64) {
        let dist = (self.eye - anchor).length();
        if dist <= 0.0 {
            return;
        }
        let factor = (dist * ZOOM_STEP.powf(steps)).max(MIN_ZOOM_DISTANCE) / dist;
        self.eye = anchor + (self.eye - anchor) * factor;
        self.target = anchor + (self.target - anchor) * factor;
    }

    pub fn anchor_at(&self, px: DVec2) -> DVec3 {
        let ray = self.ray(px);
        let max = self.distance() * MAX_ANCHOR_FACTOR;
        match ray.hit_ground() {
            Some(p) if (p - ray.origin).length() <= max => p,
            _ => ray.origin + ray.dir * self.distance(),
        }
    }
```

```rust
use bytemuck::{Pod, Zeroable};

#[repr(C)]
#[derive(Clone, Copy, Debug, PartialEq, Pod, Zeroable)]
pub struct LineVertex {
    pub pos: [f32; 3],
    pub color: [f32; 4],
}

// sRGB-authored colors.
pub const BACKGROUND: [f32; 4] = [0.96, 0.96, 0.96, 1.0];
pub const GRID_COLOR: [f32; 4] = [0.84, 0.84, 0.84, 1.0];
pub const AXIS_X: [f32; 4] = [0.85, 0.15, 0.15, 1.0];
pub const AXIS_Y: [f32; 4] = [0.15, 0.65, 0.20, 1.0];
pub const AXIS_Z: [f32; 4] = [0.15, 0.30, 0.85, 1.0];

fn faded(c: [f32; 4]) -> [f32; 4] {
    let mix = |a: f32, b: f32| a + (b - a) * 0.6;
    [mix(c[0], BACKGROUND[0]), mix(c[1], BACKGROUND[1]), mix(c[2], BACKGROUND[2]), 1.0]
}

/// Ground grid on z = 0 as line-list vertex pairs. Lines on the axes are omitted.
pub fn grid_lines(half_extent: f32, spacing: f32) -> Vec<LineVertex> {
    assert!(spacing > 0.0 && half_extent >= spacing);
    let n = (half_extent / spacing).floor() as i32;
    let e = n as f32 * spacing;
    let v = |x: f32, y: f32| LineVertex { pos: [x, y, 0.0], color: GRID_COLOR };
    let mut out = Vec::with_capacity(8 * n as usize);
    for i in (-n..=n).filter(|&i| i != 0) {
        let o = i as f32 * spacing;
        out.extend([v(o, -e), v(o, e), v(-e, o), v(e, o)]);
    }
    out
}

/// Red/green/blue axes from the origin; negative halves are faded.
pub fn axis_lines(length: f32) -> Vec<LineVertex> {
    let axes = [([1.0, 0.0, 0.0], AXIS_X), ([0.0, 1.0, 0.0], AXIS_Y), ([0.0, 0.0, 1.0], AXIS_Z)];
    let mut out = Vec::with_capacity(12);
    for (dir, color) in axes {
        for (sign, c) in [(1.0, color), (-1.0, faded(color))] {
            let end = [dir[0] * length * sign, dir[1] * length * sign, dir[2] * length * sign];
            out.push(LineVertex { pos: [0.0, 0.0, 0.0], color: c });
            out.push(LineVertex { pos: end, color: c });
        }
    }
    out
}

/// Everything the M1 viewport draws.
pub fn scene_lines() -> Vec<LineVertex> {
    let mut lines = grid_lines(100.0, 1.0);
    lines.extend(axis_lines(1000.0));
    lines
}
```

```rust
use wgpu::util::DeviceExt;

use crate::Camera;
use crate::grid::{BACKGROUND, LineVertex, scene_lines};

pub const SAMPLE_COUNT: u32 = 4;
pub const DEPTH_FORMAT: wgpu::TextureFormat = wgpu::TextureFormat::Depth32Float;

const LINE_ATTRIBS: [wgpu::VertexAttribute; 2] =
    wgpu::vertex_attr_array![0 => Float32x3, 1 => Float32x4];

/// Multisampled color and depth attachments matching the output size.
struct Targets {
    size: (u32, u32),
    msaa: wgpu::TextureView,
    depth: wgpu::TextureView,
}

pub struct Renderer {
    device: wgpu::Device,
    queue: wgpu::Queue,
    format: wgpu::TextureFormat,
    pipeline: wgpu::RenderPipeline,
    uniforms: wgpu::Buffer,
    bind_group: wgpu::BindGroup,
    lines: wgpu::Buffer,
    line_vertex_count: u32,
    targets: Option<Targets>,
}

impl Renderer {
    pub fn new(device: &wgpu::Device, queue: &wgpu::Queue, format: wgpu::TextureFormat) -> Self {
        let shader = device.create_shader_module(wgpu::include_wgsl!("shaders/line.wgsl"));
        let pipeline = device.create_render_pipeline(&wgpu::RenderPipelineDescriptor {
            label: Some("lines"),
            layout: None,
            vertex: wgpu::VertexState {
                module: &shader,
                entry_point: Some("vs_main"),
                compilation_options: Default::default(),
                buffers: &[Some(wgpu::VertexBufferLayout {
                    array_stride: std::mem::size_of::<LineVertex>() as u64,
                    step_mode: wgpu::VertexStepMode::Vertex,
                    attributes: &LINE_ATTRIBS,
                })],
            },
            primitive: wgpu::PrimitiveState {
                topology: wgpu::PrimitiveTopology::LineList,
                ..Default::default()
            },
            depth_stencil: Some(wgpu::DepthStencilState {
                format: DEPTH_FORMAT,
                depth_write_enabled: Some(true),
                depth_compare: Some(wgpu::CompareFunction::Less),
                stencil: Default::default(),
                bias: Default::default(),
            }),
            multisample: wgpu::MultisampleState { count: SAMPLE_COUNT, ..Default::default() },
            fragment: Some(wgpu::FragmentState {
                module: &shader,
                entry_point: Some("fs_main"),
                compilation_options: Default::default(),
                targets: &[Some(wgpu::ColorTargetState {
                    format,
                    blend: None,
                    write_mask: wgpu::ColorWrites::ALL,
                })],
            }),
            multiview_mask: None,
            cache: None,
        });

        let uniforms = device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("camera uniforms"),
            size: std::mem::size_of::<[f32; 16]>() as u64,
            usage: wgpu::BufferUsages::UNIFORM | wgpu::BufferUsages::COPY_DST,
            mapped_at_creation: false,
        });
        let bind_group = device.create_bind_group(&wgpu::BindGroupDescriptor {
            label: Some("camera"),
            layout: &pipeline.get_bind_group_layout(0),
            entries: &[wgpu::BindGroupEntry { binding: 0, resource: uniforms.as_entire_binding() }],
        });

        let vertices = scene_lines();
        let lines = device.create_buffer_init(&wgpu::util::BufferInitDescriptor {
            label: Some("scene lines"),
            contents: bytemuck::cast_slice(&vertices),
            usage: wgpu::BufferUsages::VERTEX,
        });

        Self {
            device: device.clone(),
            queue: queue.clone(),
            format,
            pipeline,
            uniforms,
            bind_group,
            lines,
            line_vertex_count: vertices.len() as u32,
            targets: None,
        }
    }

    pub fn render(&mut self, target: &wgpu::TextureView, size: (u32, u32), camera: &Camera) {
        if self.targets.as_ref().map(|t| t.size) != Some(size) {
            self.targets = Some(self.make_targets(size));
        }
        let targets = self.targets.as_ref().expect("targets just created");

        let view_proj = camera.view_proj_f32().to_cols_array();
        self.queue.write_buffer(&self.uniforms, 0, bytemuck::cast_slice(&view_proj));

        let [r, g, b, a] = BACKGROUND.map(f64::from);
        let mut encoder = self
            .device
            .create_command_encoder(&wgpu::CommandEncoderDescriptor { label: Some("frame") });
        {
            let mut pass = encoder.begin_render_pass(&wgpu::RenderPassDescriptor {
                label: Some("main"),
                color_attachments: &[Some(wgpu::RenderPassColorAttachment {
                    view: &targets.msaa,
                    depth_slice: None,
                    resolve_target: Some(target),
                    ops: wgpu::Operations {
                        load: wgpu::LoadOp::Clear(wgpu::Color { r, g, b, a }),
                        store: wgpu::StoreOp::Discard,
                    },
                })],
                depth_stencil_attachment: Some(wgpu::RenderPassDepthStencilAttachment {
                    view: &targets.depth,
                    depth_ops: Some(wgpu::Operations {
                        load: wgpu::LoadOp::Clear(1.0),
                        store: wgpu::StoreOp::Discard,
                    }),
                    stencil_ops: None,
                }),
                ..Default::default()
            });
            pass.set_pipeline(&self.pipeline);
            pass.set_bind_group(0, &self.bind_group, &[]);
            pass.set_vertex_buffer(0, self.lines.slice(..));
            pass.draw(0..self.line_vertex_count, 0..1);
        }
        self.queue.submit([encoder.finish()]);
    }

    fn make_targets(&self, size: (u32, u32)) -> Targets {
        let texture = |label, format| {
            self.device
                .create_texture(&wgpu::TextureDescriptor {
                    label: Some(label),
                    size: wgpu::Extent3d {
                        width: size.0.max(1),
                        height: size.1.max(1),
                        depth_or_array_layers: 1,
                    },
                    mip_level_count: 1,
                    sample_count: SAMPLE_COUNT,
                    dimension: wgpu::TextureDimension::D2,
                    format,
                    usage: wgpu::TextureUsages::RENDER_ATTACHMENT,
                    view_formats: &[],
                })
                .create_view(&wgpu::TextureViewDescriptor::default())
        };
        Targets { size, msaa: texture("msaa color", self.format), depth: texture("depth", DEPTH_FORMAT) }
    }
}
```

```rust
use glam::{DVec2, DVec3};
use render::Camera;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Button {
    Left,
    Middle,
    Other,
}

#[derive(Clone, Copy, Debug, PartialEq)]
enum Drag {
    Orbit { pivot: DVec3 },
    Pan { anchor: DVec3 },
}

/// Turns raw pointer input into camera moves. Middle drag orbits, Shift+middle pans,
/// Alt+left does the same for trackpads, scroll zooms toward the cursor.
#[derive(Default)]
pub struct Navigation {
    cursor: DVec2,
    shift: bool,
    alt: bool,
    drag: Option<Drag>,
}

impl Navigation {
    pub fn set_modifiers(&mut self, shift: bool, alt: bool) {
        self.shift = shift;
        self.alt = alt;
    }

    pub fn button(&mut self, cam: &Camera, button: Button, pressed: bool) {
        if !pressed {
            if matches!(button, Button::Left | Button::Middle) {
                self.drag = None;
            }
            return;
        }
        let navigates = button == Button::Middle || (button == Button::Left && self.alt);
        if !navigates {
            return;
        }
        let point = cam.anchor_at(self.cursor);
        self.drag = Some(if self.shift {
            Drag::Pan { anchor: point }
        } else {
            Drag::Orbit { pivot: point }
        });
    }

    pub fn cursor_moved(&mut self, cam: &mut Camera, pos: DVec2) -> bool {
        let delta = pos - self.cursor;
        self.cursor = pos;
        match self.drag {
            Some(Drag::Orbit { pivot }) => cam.orbit(pivot, delta),
            Some(Drag::Pan { anchor }) => cam.pan(anchor, delta),
            None => return false,
        }
        true
    }

    pub fn scroll(&mut self, cam: &mut Camera, steps: f64) -> bool {
        if steps == 0.0 {
            return false;
        }
        let anchor = cam.anchor_at(self.cursor);
        cam.zoom(anchor, steps);
        true
    }
}
```

```rust
use std::sync::Arc;

use glam::DVec2;
use render::{Camera, Renderer};
use winit::application::ApplicationHandler;
use winit::dpi::LogicalSize;
use winit::event::{ElementState, MouseButton, MouseScrollDelta, WindowEvent};
use winit::event_loop::ActiveEventLoop;
use winit::window::{Window, WindowId};

use crate::navigation::{Button, Navigation};

/// Trackpad pixel deltas per zoom step.
const PIXELS_PER_SCROLL_STEP: f64 = 50.0;

struct State {
    window: Arc<Window>,
    surface: wgpu::Surface<'static>,
    device: wgpu::Device,
    queue: wgpu::Queue,
    config: wgpu::SurfaceConfiguration,
    renderer: Renderer,
    camera: Camera,
    nav: Navigation,
}

impl State {
    fn new(window: Arc<Window>) -> Self {
        let size = window.inner_size();
        let instance = wgpu::Instance::default();
        let surface = instance.create_surface(window.clone()).expect("create surface");
        let adapter = pollster::block_on(instance.request_adapter(&wgpu::RequestAdapterOptions {
            compatible_surface: Some(&surface),
            ..Default::default()
        }))
        .expect("no compatible GPU adapter");
        let (device, queue) =
            pollster::block_on(adapter.request_device(&wgpu::DeviceDescriptor::default()))
                .expect("request device");

        let mut config = surface
            .get_default_config(&adapter, size.width.max(1), size.height.max(1))
            .expect("surface not supported by adapter");
        // Colors are authored as sRGB values, so prefer a non-sRGB target that writes them as-is.
        let caps = surface.get_capabilities(&adapter);
        config.format = caps.formats.iter().copied().find(|f| !f.is_srgb()).unwrap_or(config.format);
        surface.configure(&device, &config);

        let renderer = Renderer::new(&device, &queue, config.format);
        let camera = Camera::new(DVec2::new(config.width as f64, config.height as f64));
        Self { window, surface, device, queue, config, renderer, camera, nav: Navigation::default() }
    }

    fn resize(&mut self, width: u32, height: u32) {
        if width == 0 || height == 0 {
            return;
        }
        self.config.width = width;
        self.config.height = height;
        self.surface.configure(&self.device, &self.config);
        self.camera.viewport = DVec2::new(width as f64, height as f64);
    }

    fn render(&mut self) {
        let frame = match self.surface.get_current_texture() {
            wgpu::CurrentSurfaceTexture::Success(frame)
            | wgpu::CurrentSurfaceTexture::Suboptimal(frame) => frame,
            wgpu::CurrentSurfaceTexture::Outdated | wgpu::CurrentSurfaceTexture::Lost => {
                self.surface.configure(&self.device, &self.config);
                self.window.request_redraw();
                return;
            }
            _ => return, // Timeout or occluded: skip this frame.
        };
        let view = frame.texture.create_view(&wgpu::TextureViewDescriptor::default());
        self.renderer.render(&view, (self.config.width, self.config.height), &self.camera);
        self.window.pre_present_notify();
        self.queue.present(frame);
    }
}

fn map_button(button: MouseButton) -> Button {
    match button {
        MouseButton::Left => Button::Left,
        MouseButton::Middle => Button::Middle,
        _ => Button::Other,
    }
}

#[derive(Default)]
pub struct App {
    state: Option<State>,
}

impl ApplicationHandler for App {
    fn resumed(&mut self, event_loop: &ActiveEventLoop) {
        if self.state.is_some() {
            return;
        }
        let attrs = Window::default_attributes()
            .with_title("sketchup-alt")
            .with_inner_size(LogicalSize::new(1280.0, 800.0));
        let window = Arc::new(event_loop.create_window(attrs).expect("create window"));
        self.state = Some(State::new(window));
    }

    fn window_event(&mut self, event_loop: &ActiveEventLoop, _id: WindowId, event: WindowEvent) {
        let Some(s) = self.state.as_mut() else { return };
        let changed = match event {
            WindowEvent::CloseRequested => {
                event_loop.exit();
                false
            }
            WindowEvent::Resized(size) => {
                s.resize(size.width, size.height);
                true
            }
            WindowEvent::RedrawRequested => {
                s.render();
                false
            }
            WindowEvent::ModifiersChanged(m) => {
                s.nav.set_modifiers(m.state().shift_key(), m.state().alt_key());
                false
            }
            WindowEvent::CursorMoved { position, .. } => {
                s.nav.cursor_moved(&mut s.camera, DVec2::new(position.x, position.y))
            }
            WindowEvent::MouseInput { state, button, .. } => {
                s.nav.button(&s.camera, map_button(button), state == ElementState::Pressed);
                false
            }
            WindowEvent::MouseWheel { delta, .. } => {
                let steps = match delta {
                    MouseScrollDelta::LineDelta(_, y) => y as f64,
                    MouseScrollDelta::PixelDelta(p) => p.y / PIXELS_PER_SCROLL_STEP,
                };
                s.nav.scroll(&mut s.camera, steps)
            }
            _ => false,
        };
        if changed {
            s.window.request_redraw();
        }
    }
}
```
